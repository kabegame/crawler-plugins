## 사용 방법

### Git Submodule로

이 저장소는 메인 프로젝트의 Git submodule로 사용합니다:

```bash
# submodule 초기화(최초 클론 시)
git submodule update --init --recursive

# submodule 최신으로 업데이트
git submodule update --remote crawler-plugins

# 모든 submodule 업데이트
git submodule update --remote
```

### 플러그인 패키징

#### 플러그인 저장소 내에서

플러그인을 `.kgpg` 형식(ZIP)으로 패키징합니다.

**의존성 설치**(최초 1회):

```bash
bun install
```

**전체 플러그인 패키징**(CLI 사용을 위해 kabegame 메인 프로젝트 내에서 실행 필요):

```bash
bun run package
# 또는
node package-plugin.js
```

**출력 디렉터리 지정**(선택):

기본값: `crawler-plugins/packed/`. 다른 경로로 출력하려면:

```bash
node package-plugin.js --outDir ../.kabegame/debug/data/plugins-directory
```

**단일 플러그인 패키징**:

```bash
node package-plugin.js <플러그인명>
# 예:
node package-plugin.js anihonet-wallpaper
```

**지정 플러그인만 패키징**(개발 시 속도 향상):

```bash
node package-plugin.js --only single-file-import local-folder-import
```

**플러그인 인덱스(index.json) 생성**:

```bash
pnpm run generate-index
```

**패키징 및 인덱스 한 번에 실행**:

```bash
pnpm run release
```

**새 버전 배포**:

1. `package.json`의 `version` 수정
2. 커밋 후 `main`에 푸시
3. `pre-push` hook이 패키징·인덱스 생성·태그 생성 수행
4. GitHub Actions가 Release 생성 및 에셋 업로드

**Git Hooks**:

`pre-push` hook으로 패키징·인덱스 생성·태그 생성이 자동 실행됩니다. 활성화:

```bash
pnpm install
# 또는
pnpm prepare
```

#### 메인 프로젝트에서

메인 프로젝트 루트에서:

```bash
pnpm run package-plugin crawler-plugins/plugins/<플러그인명>
```

출력: `crawler-plugins/packed/<플러그인명>.kgpg`
