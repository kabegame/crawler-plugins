# PixAI 更新日志

## 0.7.4

- 任务日志与错误提示会跟随 Kabegame 的界面语言显示，支持简体中文、English、日本語、한국어与繁體中文。

## 0.7.3

- 作者模式的用户 ID、标签模式的标签 codeName 改为必填；爬取种类、榜单类型 / 范围、排序、作品类型等选择项也不能清空，留空时不再启动任务。
- 可选项留空时按未填写处理：清空页数类字段会回落到默认值，不再被当成 0 页。

## 0.7.2

- 新增元数据搜索文本：作者名称、所有标签（含各语言译名）、作品描述、评论者名称与评论内容，以及按逗号 / 换行切分去重后的提示词（含自然语言与参考图提示词，作者隐藏的不计）；已下载的图片升级后自动补齐。

## 0.7.1

- 画廊细分结果的倒序与分页改用 Kabegame 4.5.1 提供的 `_kb_desc` / `_kb_x<N>x/<page>` 全局解析，移除插件内重复且已失效的分页尾定义。

## 0.7.0

- 配合应用 4.5.1 调整「细分筛选」的内部写法：不再依赖应用投影的 `plugin_metadata` 列，细分条件可以用在高级查询的「或 / 非」组合里。需要应用 4.5.1 及以上。

## 0.6.0

- 下载新作品时把 PixAI tags 与作者写入应用标签，分别位于 `pixai/tag`、`pixai/artist`；升级后通过 `provideLabels` 为历史图片补齐。
- 画廊插件扩展移除旧 tag provider，改为按喜欢数与评论数提供累计 `N+` 分段，并支持 `N-M`、`N+`、`-N` 区间路径。
- 最低应用版本提升至 `4.5.0`。

## 0.5.0

- 支持全站作品流、按模型、按标签、排行榜和按作者五种爬取模式，可分别配置排序、起始页与分页上限。
- 支持静态图片与动态作品下载；入库时补充标题、作者、提示词、说明、标签、模型与 LoRA、点赞数、最近评论及 PixAI 原始链接。
- 标签 codeName 支持批量解析与本地缓存；模型、标签和作者作品流支持游标翻页与跳过前置页面。
- 新增全站趋势、每日全站日榜、趋势模型、今日作品榜和多标签示例五组推荐配置。
- 重写中文使用文档，新增英语、日语、韩语与繁体中文翻译，并加入首页、作品详情与下载结果横幅。
