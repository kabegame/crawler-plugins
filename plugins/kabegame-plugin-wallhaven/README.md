# wallhaven 插件说明

本插件按 [wallhaven.cc](https://wallhaven.cc) 的搜索条件或搜索页 URL 翻页抓取原图。站点的 [Latest](https://wallhaven.cc/latest) 与 [Toplist](https://wallhaven.cc/toplist) 页本质上就是预设好条件的搜索，插件把它们作为推荐配置提供。

## 推荐配置

- **最新**：综合 + 动漫、SFW，按上传时间从新到旧，与站点 Latest 页一致。
- **月度排行榜**：综合 + 动漫、SFW，近 1 个月排行，与站点 Toplist 页一致。

## 选项

- **模式**
  - **搜索条件**：在插件表单中逐项设置关键词、分类、分级、排序、分辨率与比例。
  - **搜索 URL**：在站点 [搜索页](https://wallhaven.cc/search) 设置好条件后，把地址栏中的完整 URL 粘贴进来。URL 自带的 `page` 参数会被忽略，实际页码以下方起止页为准。
- **关键词**：与站点搜索框相同，支持 `+标签`、`-标签`、`@用户名`、`id:123`、`type:png`、`like:<壁纸 ID>`。留空则不按关键词筛选。
  - 关键词按**标签名和标签别名**模糊匹配，`+标签` 也只是在这个范围内必须命中。例如 `+anime` 会搜到只带 car 标签的汽车图，因为 car 的别名里有「Anime Cars」。
  - 要精确按某个标签搜，用 `id:<标签 ID>`：在站点打开该标签，地址 `/tag/<ID>` 里的数字就是，如 anime 是 `id:1`。`id:` 不能与其他关键词组合。
  - 只想要动漫图时，也可以在「分类」里只勾动漫。
- **分类**：综合 / 动漫 / 人物，可多选。全不勾选时按全部分类搜索。
- **分级**：SFW / 擦边，可多选。两项都不勾选时站点会退回只搜 SFW，插件与之一致。NSFW 需要登录后的 API key，暂不提供。
- **排序**：上传时间、相关度、随机、浏览数、收藏数、排行榜、热门。「相关度」需要填关键词才有意义；「随机」翻页时沿用站点返回的随机种子，各页不会重复。
- **顺序**：降序 / 升序（随机排序时不显示）。
- **排行范围**：1 天 ~ 1 年，仅在排序为「排行榜」时显示。
- **最低分辨率**：任意 / 2K / 4K，按所选比例自动换算：
  - 横屏：2560×1440 / 3840×2160；竖屏：1440×2560 / 2160×3840；
  - 精确比例按「短边 1440（4K 为 2160）、长边按比例放大」计算，如 21×9 的 2K 为 3360×1440；
  - 选了多个比例时每条边取最小值，未选比例时只要求短边达标。
- **画面方向**：横屏 / 竖屏 / 方形，可多选。
  - 横屏即站点的 All Wide（宽 + 超宽），竖屏即 All Portrait，二者也包含表外比例（4:3、3:4 等）；
  - 方形对应站点比例表 Square 列：1:1、3:2、4:3、5:4；
  - 与方形或精确比例同时勾选时，站点只认精确比例，横屏 / 竖屏会收窄为表中的宽 + 超宽列（16:9、16:10、21:9、32:9、48:9）/ 竖屏列（9:16、10:16、9:18）。
- **精确比例**：站点比例表的原始选项，与画面方向取并集。
- **起始页 / 结束页**：两种模式共用的页码范围，每页 24 张。结束页超过总页数时自动截断。

## 抓取内容

- 原图（`w.wallhaven.cc/full/…`），与站点同条件搜索（未登录状态）显示的条目一致。
- 元数据：分辨率、来源链接、配色、上传者与上传时间、分类、纯度、文件大小与格式、浏览数、收藏数、短链，以及带纯度与分类的标签。
- 标签画册：站点标签统一挂到 `wallhaven/tag` 目录下。

## 使用前须知

- wallhaven API 匿名限流为每分钟 45 次，插件每张图要多读一次详情接口，因此每页约需 40 秒。
- 内容版权归原作者所有；请遵守站点服务条款，合理设置页数与使用频率。
