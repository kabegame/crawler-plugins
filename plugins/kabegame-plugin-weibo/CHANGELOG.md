# 微博更新日志

## 0.1.1

- 适配插件变量空值语义：模式改为必选；用户、超话、标签频道名、搜索关键词和单条微博输入改为必填，日期等可选项留空时按未填写处理。用户微博筛选与超话频道改为必选。

## 0.1.0

- 首个版本：用户相册、用户微博（全部 / 原创 / 图片，可含转发）、超话（热门 / 最新发帖 / 最新评论 / 精华 / 标签频道）、关键词搜索（热门、只看原创、日期区间）与单条微博五种模式。
- GIF 保存原动图；实况图可额外保存短视频。
- 按热度保存评论（含楼中楼预览）到图片详情，可一并下载评论区配图。
- 作者、超话、话题写入标签画册；正文、话题、作者、评论可在元数据中搜索。
