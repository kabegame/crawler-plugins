# 微博：怎么把图收进画册

从微博收图片：可以按**用户相册 / 用户微博**批量收、按**超话**的某个频道收、按**关键词搜索**收，或者只收**单条微博**。
GIF 原样保存；实况图（LivePhoto）除了静态图还会收一段短视频；评论区里贴的图也可以一起收。

## 先登录

所有模式都需要微博登录态：先在 Kabegame 的**畅游**里打开 `weibo.com` 并登录一次，插件会自动带上登录 Cookie（插件代码拿不到 Cookie 明文）。
没登录时，任务会直接失败并提示去畅游登录；登录过期也一样，重新登录即可。

## 五种模式

### 用户相册

填**用户**：UID（`6593199887`）、主页链接（`https://weibo.com/u/6593199887`、`https://weibo.com/个性域名`）或昵称（`原神`）都行。
按相册（图片墙）从新到旧收，同一条微博的多张图会一起收下。

### 用户微博

同样填**用户**，按时间线从新到旧收。

- **微博范围**：全部 / 原创 / 图片。默认「原创」。
- **包含转发**：打开后，转发微博会收**原帖**的图，详情里注明「由 @xx 转发」。

### 超话

填**超话**：超话名（`原神`、`原神超话` 都行）或超话链接（`https://weibo.com/p/100808…`）。

**频道**和超话页顶部的分栏一致：热门、最新发帖、最新评论、精华。选「标签频道」时再填频道标题，
比如原神超话的「同人」「原摄」；频道名填错时，任务会报错并列出这个超话有哪些频道。

### 关键词搜索

和 `s.weibo.com` 的搜索一致，只取带图片的微博。关键词两边加 `#` 就是按话题搜，例如 `#原神同人#`。

- **排序**：综合（时间）/ 热门。
- **只看原创**：不收转发。
- **起始 / 结束日期**：按发布日期过滤，可以只填一头。

微博搜索最多翻 50 页（约 500 条）。

### 单条微博

填**微博链接**：`https://weibo.com/<UID>/<微博ID>`、`https://m.weibo.cn/detail/<ID>`、`https://m.weibo.cn/status/<ID>`，或者只填微博 ID。
链接指向一条转发时，收的是原帖的图。

## 通用选项

| 选项 | 说明 |
| --- | --- |
| 最多微博条数 | 本次最多收几条**带图**微博（一条可能有多张图）。无图微博不计数。单条模式没有这个选项。 |
| 保存评论数 | 每条微博按热度保存前几条评论（带楼中楼预览），显示在图片详情里。0 = 不拉评论。 |
| 下载评论区图片 | 已保存评论（含楼中楼）里贴的图也一起下载，文件名带 `[comment_楼层]`。「保存评论数」为 0 时不会下载评论图。 |
| 下载实况图视频 | 实况图额外保存短视频，文件名带 `(live)`。 |

## 收下来的东西

- **图片**：原图（`large`），GIF 保持动图；视频微博里的视频不收。
- **详情面板**：作者、发布时间、来源与 IP 属地、正文（长微博自动补全）、话题与超话、转发 / 评论 / 点赞数，以及保存下来的评论。
- **标签画册**：作者（`weibo/user`，以 UID 区分）、超话（`weibo/supertopic`）、话题（`weibo/topic`）。中文名转成拼音作为 key，显示名不变。
- **元数据搜索**：正文、话题、作者昵称和 UID、IP 属地、发布日期、评论者与评论内容都能搜到。

## 注意

- 插件请求之间带有随机间隔，收得多会比较慢；短时间内收太多，微博可能要求验证，过一会儿再试即可。
- 仅粉丝可见、已删除或被屏蔽的微博会跳过并在任务日志里提示。
