# bilibili 影片

下載 bilibili 影片。分段抓取分離的影音串流，合流為 MP4 後存入媒體庫。

## 使用範例：下載番劇

以下示範下載《有頂天家族》第一季（`ss507`）的前 3 集。

1. 在 bilibili 開啟要下載的番劇，確認右側「正片」列表包含目標劇集。從瀏覽器網址列複製番劇連結；
   本例使用 [https://www.bilibili.com/bangumi/play/ss507](https://www.bilibili.com/bangumi/play/ss507)。

   ![bilibili 番劇播放頁與正片列表](banners/bangumi-page.jpg)

2. 在 Kabegame 新增下載任務，來源選擇「bilibili 影片」，然後填寫外掛設定：

   - 「模式」選擇「番劇 / 劇集」；
   - 在「番劇連結或編號」貼上完整連結，也可以只填 `ss507`；
   - 「起始集數」填 `1`，「最多下載數」填 `3`，代表從正片第 1 集開始下載 3 集；
   - 「畫質上限」選擇 `1080P`，並保持開啟「優先 H.264」，以獲得較好的播放相容性；
   - 「間隔秒數」與「重試次數」可先保留預設值 `10` 與 `1`。

   輸出目錄與輸出相簿可按需選擇；留空時使用 Kabegame 的預設位置。

   ![下載番劇的外掛參數範例](banners/bangumi-params.jpg)

3. 啟動任務。外掛會讀取番劇的正片列表，依序下載前 3 集，將分離的影音串流合流為 MP4，
   再加入畫廊。任務完成後，可以在來源頁面看到已下載的 3 部影片。

   ![下載完成後的三部番劇影片](banners/downloads.jpg)

4. 點選任一影片即可查看詳細資訊並直接播放。若影片只有縮圖、無法播放，請確認下載時已開啟
   「優先 H.264」；HEVC 或 AV1 的支援情況取決於目前平台。

   ![在 Kabegame 中播放已下載的番劇](banners/view.jpg)

## 模式

### 單個影片

在「影片 ID 或連結」填入以下任一形式：

- `BV13x41117TL`
- `av1074402`
- `https://www.bilibili.com/video/BV13x41117TL`

多分 P 影片可用「分 P 序號」選擇要下載的分 P，填 `0` 則下載全部分 P。

### UP 主投稿

在「UP 主 UID 或主頁連結」填入 UID（`3985676`）或主頁連結
（`https://space.bilibili.com/3985676`）。列表每頁有 30 部投稿，可用「起始頁 / 結束頁」選擇範圍。

**「最多下載數」預設為 5**，這是刻意保守的設定：每頁有 30 部影片，每部 1080P 影片可能有數百 MB，
單頁就可能達到數 GB。請先確認範圍再調高數量。

此模式**固定只下載每部投稿的 P1**，否則一部有 23 個分 P 的投稿會一次產生 23 個檔案。

### 合集 / 系列 / 收藏夾

在「列表頁連結」貼上完整連結，**類型會自動辨識**：

| 類型 | 連結形式 |
| --- | --- |
| 合集 | `space.bilibili.com/<UID>/lists/<ID>`（或 `?type=season`） |
| 合集（舊版） | `space.bilibili.com/<UID>/channel/collectiondetail?sid=<ID>` |
| 系列 | `space.bilibili.com/<UID>/lists/<ID>?type=series` |
| 系列（舊版） | `space.bilibili.com/<UID>/channel/seriesdetail?sid=<ID>` |
| 收藏夾 | `space.bilibili.com/<UID>/favlist?fid=<ID>` |
| 收藏夾（短連結） | `bilibili.com/medialist/detail/ml<ID>` |

合集與系列必須使用 **space 的完整連結**，因為介面需要同時取得 UP 主 UID 與列表 ID，只填 ID 無法請求。

收藏夾項目介面會一次傳回全部內容、不分頁。因此此模式會把「起始頁」按每頁 30 個項目換算成起始位置，
再以「最多下載數」限制結果。音訊、專欄等非影片項目會顯示提示並略過；若要存取私人收藏夾，
必須在 Kabegame 暢遊中以**擁有者身分**登入。

此模式同樣固定只下載每部投稿的 P1。

### 關鍵字搜尋

填寫「搜尋關鍵字」，效果等同 `search.bilibili.com` 的**影片**分頁。可選擇排序方式
（綜合 / 最多播放 / 最新發布 / 最多彈幕 / 最多收藏）與時長篩選；搜尋結果每頁 20 筆。

**建議搭配時長篩選。** 1080P 影片每小時可能超過 1 GB，而搜尋很容易找到長影片。
直播間、番劇等非一般投稿會自動過濾，跨頁重複的投稿也會去除。

此模式同樣固定只下載每部投稿的 P1。

### 番劇 / 劇集

在「番劇連結或編號」填入以下任一形式，**類型會自動辨識**：

| 類型 | 形式 |
| --- | --- |
| 單集 | `ep21495` 或 `bilibili.com/bangumi/play/ep21495` |
| 整季 | `ss26801` 或 `bilibili.com/bangumi/play/ss26801` |
| 劇集頁 | `md24097891` 或 `bilibili.com/bangumi/media/md24097891` |

番劇使用獨立的 PGC 播放介面，與一般投稿完全不同，也不需要 WBI 簽章。

- **單集（`ep`）**：只下載該集。花絮、PV、聲優節目等 section 項目也有獨立的 `ep` 頁面，同樣支援。
- **整季（`ss` / `md`）**：按**正片列表**批次下載，不含 PV 與花絮。以「起始集數」指定開始位置，
  再以「最多下載數」限制數量。劇集頁（`md`）會先轉換成對應的季度。

以下內容會明確略過或回報錯誤，不會下載成無法使用的檔案：

- **大會員專享集數**：沒有觀看權限時，介面只會傳回 6 分鐘試看片段。試看片段不會存入媒體庫，
  該集會顯示提示並略過。若已開通大會員，請先在 Kabegame 暢遊中登入 bilibili。
- **地區限制**：港澳台或海外限定內容，從不符合的地區存取時會直接回報錯誤。
- 免費集數與已解鎖集數可正常下載，畫質選擇規則與一般影片相同。

## 畫質與登入

bilibili 會依登入狀態提供不同畫質：

| 狀態 | 可用畫質 |
| --- | --- |
| 未登入 | 透過試看通常仍可取得 1080P |
| 已登入 | 穩定取得 1080P |
| 大會員 | 4K / HDR / Dolby |

Cookie 取自 **Kabegame 暢遊**。若要下載 4K 或 HDR，請先在暢遊中登入 bilibili，再執行此外掛。
「畫質上限」會選擇不超過該設定的最高可用畫質，因此實際取得的畫質可能更低。

「優先 H.264」預設開啟，會優先選擇 `avc1` 編碼，讓影片可在畫廊中直接播放。關閉後會以畫質優先，
可能取得 HEVC 或 AV1。視平台支援情況而定，這類檔案存入媒體庫後可能只顯示縮圖而無法直接播放。

## 間隔與重試

「間隔秒數」（預設 10）會套用於影片之間、列表翻頁之間，以及失敗後的重試之前。
「重試次數」（預設 1）是單部影片失敗後的重試上限；設為 `0` 則不重試。

UP 主投稿介面的風控比播放介面嚴格許多，縮短間隔很容易觸發限制。一旦傳回
`412` / `-401` / `-352`，外掛會立即終止本次任務，因為對這類攔截進行重試沒有作用。
請稍後再試，或先在 Kabegame 暢遊中登入 bilibili。合集、系列與收藏夾介面不需要簽章，限制較寬鬆。

## 限制

- **不支援課程與直播**（`/cheese/`、`live.bilibili.com`）。這些內容使用不同的播放介面；
  此外掛處理一般投稿影片與番劇。
- **略過隱藏模式合集。** UP 主投稿列表不會展開其中的影片，而所需的合集介面目前尚未支援。
  外掛會記錄一則警告並略過。
- 影音會以原始編碼進行 stream copy 合流，不會重新編碼，因此耗時主要取決於網路傳輸。
