# X（Twitter）媒体

通过真实浏览器页面抓取 X 上的**原图**和**视频**，有五种模式：

- **画师媒体**：某个画师主页「媒体」标签里的全部图片 / 视频。
- **搜索**：按搜索词抓结果，可以搜话题、关键词，或用 X 的高级搜索语法组合条件。
- **单条推文**：粘贴一条推文链接，抓它的图片 / 视频和回复。
- **我的书签** / **我的点赞**：当前登录账号收藏或点过赞的推文里的媒体（X 只允许看自己的），没有图的推文跳过。

## 使用前

1. 先在应用的「畅游」里打开 <https://x.com> 并登录。X 不登录几乎看不到任何内容。
2. 想抓到敏感内容，要在 X 的「设置 → プライバシーと安全 / 隐私与安全 → 你看到的内容」里打开
   「显示可能含有敏感内容的媒体」，否则这类推文不会出现在时间线里。
3. 中国大陆需要代理才能访问 x.com。

## 配置

| 配置 | 说明 |
|---|---|
| 模式 | 画师媒体 / 搜索 / 单条推文 / 我的书签 / 我的点赞 |
| 画师 | （画师媒体）`@用户名`、用户名或主页链接 |
| 搜索词 | （搜索）和 X 搜索框写法相同，见下方示例 |
| 排序 | （搜索）最新：按时间从新到旧；热门：X 搜索「媒体」标签的排序 |
| 推文 | （单条推文）推文链接或推文 id |
| 媒体类型 | 全部 / 仅图片 / 仅视频。画师模式对应「媒体」标签下拉；搜索模式自动补 `filter:media` / `filter:images` / `filter:videos` |
| 最多推文数 | 最多处理多少条带图推文，0 为不限（单条推文模式没有这项） |
| 最旧时间 | 翻到早于这一天的推文就停（热门排序、书签、点赞只跳过、不提前停） |
| 只补充上次之后的新推文 | 按画师和媒体类型（搜索按搜索词）记住上次抓到的最新推文，下次遇到就停；书签 / 点赞记住上次最前面几条；热门排序不支持 |
| 每条推文最多保存评论 | 有回复的推文会打开详情页保存回复，0 为不保存（更快） |
| 下载评论区图片 | 把已保存回复里的图片和视频也下载进图库，默认关闭 |

## 搜索词示例

| 想要 | 搜索词 |
|---|---|
| 某个话题下的热门图 | `#ブルアカ min_faves:1000` |
| 某个画师某段时间的图（补抓老图） | `from:karokaro6665 since:2025-01-01 until:2025-07-01` |
| 日文插画、排除回复 | `イラスト lang:ja -filter:replies` |
| 只要某人发的视频 | `from:用户名 filter:videos` |

搜索结果除了画师、话题标签外，还会挂一个以搜索词命名的标签画册；书签和点赞的结果分别挂「X 书签」「X 点赞」。

## 工作方式

插件不直接调用 X 的接口，而是打开画师的媒体页或搜索页、自动向下滚动，
截获页面自己加载的数据（`UserPhotoTimeline` / `UserVideoTimeline` / `SearchTimeline` / `Bookmarks` / `Likes`，单条推文为 `TweetDetail`）。
图片取 `name=orig` 原图，视频取码率最高的 MP4。
每条推文的正文、发布时间、点赞 / 转推 / 书签 / 浏览数会一并保存，话题标签和画师会挂成标签画册。

保存评论时，插件在同一页面里切到推文详情（不整页刷新），截获 `TweetDetail` 回复数据，
还有更多就向下滚动，直到达到上限。回复连同楼中楼、作者、时间、点赞数和配图链接存进推文详情，
在图片预览的「插件详情」里显示；回复者的名字和正文也能被搜索到。
X 折叠在「显示可能是垃圾信息的回复」里的回复不保存，所以已保存数可能少于推文上显示的回复数。
评论区图片和原推文共用同一份详情，但不挂画师和话题标签。

## 注意

- X 对每个接口有 15 分钟的请求配额，一次翻太多页可能被限流（日志会提示 429），稍后再试即可。
- 媒体时间线只包含画师自己发的推文，不含转推。
- 保存评论要逐条打开推文详情，推文多时明显变慢；只想要图可以把「每条推文最多保存评论」设为 0。
