# Konachan アニメ壁紙 - プラグイン説明

このプラグインは `konachan.net` からアニメ壁紙を取得し、ダウンロードキューに追加します。

## 設定項目

- **開始ページ（start_page）**：取得開始ページ（最小 1）
- **終了ページ（end_page）**：取得終了ページ。**1回あたり最大100ページ**まで。超過すると拒否されます
- **画質（quality）**：
  - **高（high）**：高解像度を優先、なければ中画質にフォールバック
  - **中（medium）**：中画質（デフォルト）

## 使い方

1. 取得するページ範囲（開始～終了）を指定
2. 画質を選択
3. 「クロール開始」をクリック
4. プラグインがリスト頁→各詳細頁の順で画像をダウンロードします

## 注意事項

- **マナーを守って**：1回最大100ページ。超過は拒否されます
- **終了ページは開始ページ以上**にしてください。そうでないとエラーになります
- 「高」を選んでも高解像度がない場合は自動で中画質になります
- サーバー負荷を考え、ページ範囲は適切に設定してください
