# Konachan 更新日志

## 1.5.0

- 新增「id 范围」爬取模式：填写起始 id 和结束 id（作品页地址 `/post/show/<id>` 里的数字），按 id 从小到大抓取区间内的全部作品。两个 id 最多相差 5000，超出会拒绝爬取；区间里已删除的作品自动跳过。「分级过滤」同样适用。

## 1.4.0

- 新增「排行榜」爬取模式，对应站点的人气榜：日榜、周榜、月榜可以指定日期看往期，并能往前连抓多期（站点每期只有一页、最多 40 张）；另有最近 24 小时、一周、一个月、一年的滚动榜。分级过滤在这个模式下由插件按每张图的分级筛选。konachan.net 只显示全年龄作品，同一期通常比 konachan.com 少。
- 修复源站选 R18 站（konachan.com）时第一页就 403：konachan.com 有 Cloudflare 验证，现在会自动借用「畅游」里通过验证后留下的 Cookie 与浏览器标识。使用前请先在畅游中打开 konachan.com 通过一次验证；没取到 Cookie 时任务会给出提示。
- 新增「分级过滤」配置（全年龄 / 存疑 / 限制级），「全部」和「标签」模式把站点的 `rating:` 元标签拼进搜索串，「排行榜」模式由插件按每张图的分级筛选。只在源站选 konachan.com 时显示——konachan.net 只收录全年龄内容。
- 「标签」模式的标签组合也接受用逗号或空格分隔的字符串，方便在命令行里传参。
- 移除「标签列表」爬取模式及其推荐配置。按标签浏览已由应用级标签取代，按标签抓图请用「标签」模式。之前保存的标签列表运行配置会报「未知的爬取模式」，需要改成其他模式。

## 1.3.0

- 下载时把侧栏的标签按颜色（类型）写入应用的「标签」分区：画师、版权、角色、社团、风格、通用分别在 `konachan/artist`、`konachan/copyright`、`konachan/character`、`konachan/circle`、`konachan/style`、`konachan/general` 下，可在画册页浏览、在搜索里按标签筛选。
- 标签 key 使用站点的标签名（如 `futaba_akane_(pentagon)`），显示名使用页面上的文字。
- 历史下载的图片会在元数据迁移时自动补上标签；早期版本没有记录标签的图片无法补。
- 最低应用版本提升至 `4.5.0`。
- 移除插件自带的「标签类型 → 标签」浏览（已由应用级标签取代），画廊插件扩展改为按 **分数 score**（`5+` … `1000+` 档位，路径段支持区间 `100-500`、`100+`、`-50`）与 **分级 rating**（Safe / Questionable / Explicit）筛选。
