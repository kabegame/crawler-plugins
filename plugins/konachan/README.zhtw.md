# Konachan 動漫壁紙 - 外掛說明

本外掛用於從 `konachan.net` 網站爬取動漫壁紙並加入下載佇列。

## 設定項

- **起始頁面（start_page）**：要爬取的起始頁面（最小值為 1）
- **結束頁面（end_page）**：要爬取的結束頁面。**請保持最多爬取 100 頁**，超過會拒絕執行
- **品質（quality）**：
  - **高（high）**：優先下載高解析度圖片，若不存在則降為中等品質
  - **中（medium）**：下載中等品質圖片（預設）

## 使用說明

1. 選擇要爬取的頁面範圍（起始頁到結束頁）
2. 選擇圖片品質偏好
3. 點擊「開始爬取」
4. 外掛會自動造訪列表頁，再進入每個詳情頁下載圖片

## 注意事項

- **請文明爬取**：單次最多 100 頁，超過會拒絕
- **結束頁必須大於等於起始頁**，否則會報錯
- 若選「高」品質但無高解析版本，會自動降為中等品質
- 建議合理設定頁面範圍，避免對伺服器造成過大負擔
