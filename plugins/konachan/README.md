# Konachan 动漫壁纸 - 插件说明

本插件用于从 `konachan.net` 网站爬取动漫壁纸并加入下载队列。

## 配置项

- **起始页面（start_page）**：要爬取的起始页面（最小值为 1）
- **结束页面（end_page）**：要爬取的结束页面。**请保持最多爬取 100 页，降低并发量文明爬取**，否则会拒绝爬取
- **质量（quality）**：
  - **高（high）**：优先下载高分辨率图片，如果不存在则降级为中等质量
  - **中（medium）**：下载中等质量图片（默认质量）

## 排行榜模式（popular）

- **榜单类型（popular_scale）**：日榜 / 周榜 / 月榜按自然日、周、月统计；最近 24 小时 / 一周 / 一个月 / 一年是截至现在的滚动窗口
- **排行榜日期（popular_date）**：日、周、月榜可以指定日期看往期，留空为当期
- **回溯期数（popular_periods）**：从该日期起往前连抓多少期，一次最多 100 期。站点每期只有一页、最多 40 张
- **分级过滤**在这个模式下由插件按每张图的分级筛选（榜单页不接受搜索参数）。konachan.net 只显示全年龄作品，所以同一期在 konachan.net 上通常比 konachan.com 少

## id 范围模式（id_range）

- **起始 id / 结束 id（id_start / id_end）**：作品 id 闭区间，即作品页地址 `/post/show/<id>` 里的数字。两者都要是正整数，结束 id 不小于起始 id，**最多相差 5000**，否则拒绝爬取
- 按 id 从小到大抓取区间内的全部作品，不需要填页数；区间里已删除的 id 会跳过，所以实际张数通常远少于区间宽度
- **分级过滤**与「全部」「标签」模式一样拼进站点搜索串

## 使用说明

1. 选择要爬取的页面范围（起始页面到结束页面）
2. 选择图片质量偏好
3. 点击"开始爬取"按钮
4. 插件会自动访问列表页，然后进入每个详情页下载图片

## 注意事项

- **请文明爬取**：一次最多只能爬取 100 页，超过限制会拒绝执行
- **结束页面必须大于等于起始页面**，否则会报错
- 如果选择"高"质量但图片不存在高分辨率版本，会自动降级为中等质量
- 建议合理设置页面范围，避免对服务器造成过大压力
