# Kemono 爬虫

本插件从 `kemono.cr` 获取作者帖子及其附件。内容可能包含成人内容，请遵守所在地法律、站点规则与内容授权要求。

## 五种爬取模式

### 链接

填写以下任一形式的完整链接：

- 作者全部帖子：`https://kemono.cr/<service>/user/<uid>`
- 单个帖子：`https://kemono.cr/<service>/user/<uid>/post/<pid>`

旧域名 `kemono.su` / `kemono.party` 的链接也能识别，但请求一律走当前域名 `kemono.cr`。指定单个帖子时，直接调用单帖接口，不会翻该作者的整个列表，也不受页数范围影响。

### 作者

分别选择“作者服务”并填写“作者 ID”。支持的服务为 `patreon`、`fanbox`、`gumroad`、`subscribestar`、`dlsite`、`discord`、`fantia`、`boosty`、`afdian`。

上游 `kemono-scraper` 还支持姊妹站 coomer（`onlyfans`、`fansly`），但那是成人订阅内容而非二次元图片，本插件不移植；收藏列表里若混有这类条目会被自动跳过。

### 收藏的作者

读取该账号在 kemono 收藏的作者，再逐个获取每位作者的帖子。**同时受两个页数范围约束**：先用“收藏作者页数范围”决定处理哪些收藏作者，再用“作者页数范围”决定每位作者取哪几页帖子。

### 收藏的帖子

读取该账号在 kemono 收藏的帖子，按“页数范围”截取后逐个下载。

### 标签

填写一个站点标签（如 `nsfw`、`wip`、`comic`、`nude`），按“页数范围”爬取全站带该标签的帖子。标签**区分大小写**，需与站点上的写法一致；全部标签可在 `kemono.cr/posts/tags` 查看。本模式不需要登录。

## 页数范围

所有模式都以“页”为单位限制爬取量，**每页 50 条**，页码从 1 开始，结束页填 `0` 表示一直到最后一页。

| 模式 | 生效的页数范围 |
|---|---|
| 作者 / 作者链接 | 作者页数范围（帖子列表） |
| 收藏的作者 | 收藏作者页数范围 **＋** 作者页数范围（叠加） |
| 收藏的帖子 | 页数范围 |
| 标签 | 页数范围 |
| 单帖链接 | 不适用，直接取该帖 |

插件是**流式**工作的：每翻一页就把该页帖子的附件下完，再翻下一页，不会先攒完整列表。因此中途取消任务，已下载的部分仍然保留。

收藏列表由接口一次性返回，其“页”是插件按每页 50 条在本地切分的，语义与帖子列表的页保持一致。

## 收藏模式与畅游登录

收藏接口需要登录 Cookie。插件不会读取 cookie 文件，也不会探测浏览器 Cookie；请先在 Kabegame 的“畅游”中打开并登录 `kemono.cr`，再运行收藏模式。

如果畅游中没有该站点 Cookie，任务会直接提示登录。如果收藏或后续列表请求返回 `401` / `403`，说明登录态已经失效，请回到畅游重新登录。

链接、作者、标签三种模式不需要登录。

## 图片来源：缩略图与原图

**默认下载缩略图，这是刻意的选择。**

kemono 把原图放在 `n1`～`n5`、`c1`～`c3` 这些独立的文件节点上。实测（2026-07）这些节点在很多网络环境下 **TCP 层就连不通**，无论是否走代理；而缩略图主机 `img.kemono.cr` 可以正常访问。因此：

- **缩略图（默认）**：长边上限 800px，单张约 30–40 KB，来自 `img.kemono.cr`。能稳定下到。
- **原图**：来自上述文件节点。如果你的网络确实能连上，画质完整；连不上则会全部失败。

800px 对壁纸用途是明显的降级，但在原图节点不可达的前提下，这是唯一能拿到图的路径。如果你的网络环境变了，可以在配置里切回原图试试。

**缩略图模式会自动跳过压缩包、视频等附件** —— 这类文件没有缩略图，请求一律 404，不跳过的话整帖都会刷失败。

## 附件说明

帖子附件不一定是图片，也可能是视频、音频、压缩包或其它文件。原图模式下，插件会把所有附件都交给 Kabegame 下载；能否预览取决于 Kabegame 和当前平台对该媒体类型的支持。

“包含 Banner／主文件”对应原下载器的 `--banner` 行为：把帖子的 `file` 字段加入附件。即使关闭此选项，非图片主文件仍会保留（缩略图模式下仍会因无缩略图而被跳过）。

同一帖子的所有附件共用一份精简帖子元数据。多附件会在帖子标题后追加 `(1)`、`(2)` 等序号；与原下载器一致，图片和非图片附件分别编号，因此不同类型可能出现相同序号。
