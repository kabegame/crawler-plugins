# Kemono 크롤러

이 플러그인은 `kemono.cr`에서 크리에이터 게시물과 첨부 파일을 가져옵니다. 성인 콘텐츠가 포함될 수 있으므로 거주 지역의 법률, 사이트 규칙 및 콘텐츠 이용 허가를 준수하세요.

## 다섯 가지 수집 모드

### 링크

다음 형식 중 하나의 전체 링크를 입력합니다.

- 크리에이터의 모든 게시물: `https://kemono.cr/<service>/user/<uid>`
- 단일 게시물: `https://kemono.cr/<service>/user/<uid>/post/<pid>`

이전 도메인인 `kemono.su` 또는 `kemono.party` 링크도 인식하지만 요청은 항상 현재 도메인 `kemono.cr`을 사용합니다. 단일 게시물을 지정하면 해당 게시물 API를 직접 호출하므로 크리에이터의 전체 목록을 탐색하지 않고 페이지 범위도 적용하지 않습니다.

### 크리에이터

**크리에이터 서비스**를 선택하고 **크리에이터 ID**를 입력합니다. 지원 서비스는 `patreon`, `fanbox`, `gumroad`, `subscribestar`, `dlsite`, `discord`, `fantia`, `boosty`, `afdian`입니다.

상위 프로젝트 `kemono-scraper`는 자매 사이트 Coomer(`onlyfans`, `fansly`)도 지원하지만, 해당 서비스는 애니메이션 이미지가 아닌 성인 구독 콘텐츠를 제공하므로 이 플러그인에는 포함하지 않았습니다. 즐겨찾기 목록에 이러한 항목이 섞여 있으면 자동으로 건너뜁니다.

### 즐겨찾기 크리에이터

현재 Kemono 계정이 즐겨찾기에 추가한 크리에이터를 불러온 다음 각 크리에이터의 게시물을 가져옵니다. **두 페이지 범위가 동시에 적용됩니다**. 먼저 **즐겨찾기 작가 페이지 범위**로 처리할 크리에이터를 정하고, **작가 페이지 범위**로 각 크리에이터에게서 가져올 게시물 페이지를 정합니다.

### 즐겨찾기 게시물

현재 Kemono 계정이 즐겨찾기에 추가한 게시물을 불러와 **페이지 범위**로 선택한 다음 하나씩 다운로드합니다.

### 태그

`nsfw`, `wip`, `comic`, `nude` 같은 사이트 태그를 입력하면 **페이지 범위**에 따라 사이트 전체에서 해당 태그가 붙은 게시물을 수집합니다. 태그는 **대소문자를 구분**하므로 사이트의 표기와 일치해야 합니다. 전체 태그는 `kemono.cr/posts/tags`에서 확인할 수 있습니다. 이 모드는 로그인이 필요하지 않습니다.

## 페이지 범위

해당하는 모든 모드는 **페이지당 50개 항목**을 기준으로 수집량을 제한합니다. 페이지 번호는 1부터 시작하며 끝 페이지를 `0`으로 설정하면 마지막 페이지까지 계속합니다.

| 모드 | 적용되는 페이지 범위 |
|---|---|
| 크리에이터 / 크리에이터 링크 | 작가 페이지 범위(게시물 목록) |
| 즐겨찾기 크리에이터 | 즐겨찾기 작가 페이지 범위 **＋** 작가 페이지 범위 |
| 즐겨찾기 게시물 | 페이지 범위 |
| 태그 | 페이지 범위 |
| 단일 게시물 링크 | 적용 안 함. 게시물을 직접 가져옴 |

플러그인은 **스트리밍 방식**으로 작동합니다. 전체 목록을 먼저 모으지 않고 현재 페이지 게시물의 첨부 파일을 모두 다운로드한 뒤 다음 페이지로 이동합니다. 따라서 작업을 중간에 취소해도 이미 다운로드한 파일은 유지됩니다.

즐겨찾기 API는 전체 목록을 한 번에 반환합니다. 플러그인은 이를 로컬에서 50개씩 페이지로 나눠 게시물 목록과 동일한 페이지 의미를 유지합니다.

## 즐겨찾기 모드와 畅游 로그인

즐겨찾기 API에는 로그인 Cookie가 필요합니다. 플러그인은 Cookie 파일을 읽거나 브라우저 Cookie를 탐색하지 않습니다. 먼저 Kabegame의 **畅游(Surf)**에서 `kemono.cr`을 열어 로그인한 다음 즐겨찾기 모드를 실행하세요.

畅游에 이 사이트의 Cookie가 없으면 작업이 즉시 로그인을 요청합니다. 즐겨찾기 또는 이후 목록 요청에서 `401`이나 `403`을 반환하면 로그인 상태가 만료된 것이므로 畅游로 돌아가 다시 로그인하세요.

링크, 크리에이터 및 태그 모드는 로그인이 필요하지 않습니다.

## 이미지 소스: 썸네일과 원본

**기본적으로 썸네일을 다운로드하며, 이는 의도적인 선택입니다.**

Kemono는 원본 파일을 `n1`～`n5`, `c1`～`c3`이라는 별도의 파일 노드에 저장합니다. 2026-07 테스트에서는 프록시 사용 여부와 관계없이 여러 네트워크 환경에서 이러한 노드에 **TCP 수준으로 연결할 수 없었지만**, 썸네일 호스트 `img.kemono.cr`에는 정상적으로 접근할 수 있었습니다. 따라서:

- **썸네일(기본값):** 긴 변 최대 800px, 파일당 약 30～40KB이며 `img.kemono.cr`에서 제공됩니다. 안정적으로 다운로드할 수 있습니다.
- **원본:** 위 파일 노드에서 제공됩니다. 네트워크에서 연결할 수 있으면 전체 화질로 받을 수 있지만, 연결할 수 없으면 모두 실패합니다.

800px는 벽지 용도로 분명한 화질 저하이지만 원본 파일 노드에 접근할 수 없다면 이미지를 얻는 유일한 방법입니다. 네트워크 환경이 바뀌면 설정에서 원본으로 되돌려 다시 시도할 수 있습니다.

**썸네일 모드는 압축 파일, 동영상 등의 첨부 파일을 자동으로 건너뜁니다.** 이러한 파일에는 썸네일이 없어 항상 404가 반환되며, 건너뛰지 않으면 게시물 전체에 실패가 쌓입니다.

## 첨부 파일 안내

게시물 첨부 파일은 이미지뿐 아니라 동영상, 오디오, 압축 파일 또는 기타 형식일 수 있습니다. 원본 모드에서는 플러그인이 모든 첨부 파일을 Kabegame에 전달하여 다운로드합니다. 미리보기 가능 여부는 Kabegame과 현재 플랫폼이 지원하는 미디어 형식에 따라 달라집니다.

**배너/기본 파일 포함**은 원본 다운로더의 `--banner` 동작에 대응하며 게시물의 `file` 필드를 첨부 파일에 추가합니다. 이 옵션을 꺼도 이미지가 아닌 기본 파일은 유지됩니다. 썸네일 모드에서는 썸네일이 없으므로 계속 건너뜁니다.

같은 게시물의 모든 첨부 파일은 하나의 간소화된 게시물 메타데이터를 공유합니다. 첨부 파일이 여러 개면 게시물 제목 뒤에 `(1)`, `(2)` 등의 번호가 붙습니다. 원본 다운로더와 마찬가지로 이미지와 이미지가 아닌 첨부 파일은 별도로 번호를 매기므로 서로 다른 파일 형식에 같은 번호가 붙을 수 있습니다.
