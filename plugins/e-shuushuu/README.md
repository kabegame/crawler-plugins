# e-shuushuu 插件说明

本插件从 [e-shuushuu.net](https://e-shuushuu.net)（可爱风动漫图库）按主页、排行榜或搜索结果翻页抓取原图。

## 选项

- **模式**
  - **主页**：按最新上传翻页，与站点首页一致。
  - **排行榜**：站点的 Top Rated 榜单，按评分排序。
  - **搜索 URL**：在站点 [搜索页](https://e-shuushuu.net/search) 设好标签、评分、尺寸、日期、排序等条件后，把地址栏的 URL 粘贴进来。
- **排行范围**（仅排行榜模式）：全部时间 / 今年 / 本月 / 本周，与站点四个范围一致。
- **起始页 / 结束页**：页码范围，每页 20 张。结束页超过总页数时自动截断；排行榜最多 20 页。

## 抓取内容

- 原图（`fullsize`），与站点主页 / 排行榜 / 搜索页显示的条目一致。
- 元数据：图片编号、原图尺寸与大小、出处链接、上传者、上传时间、收藏数与评分，以及按类别整理的标签。
- 标签画册：站点标签按 **artist / source / character / theme** 四类，挂到 `e-shuushuu/<类别>` 目录下。
