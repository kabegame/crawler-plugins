# anihonet 动漫壁纸

从 [anihonetwallpaper.com](https://anihonetwallpaper.com) 收集动漫与游戏壁纸的 Kabegame 插件，支持手机壁纸和桌面壁纸。

## 爬取模式

插件提供三种爬取模式，默认为「排行榜」。选择模式后，Kabegame 只会显示该模式需要的配置项。

### 排行榜

按排行榜周期、壁纸子类和页码范围抓取壁纸。

- 排行榜周期：日榜、周榜、月榜、年榜。
- 排行榜子类：综合、手机壁纸、高质量图片、高质量 PC 壁纸、PC 壁纸。
- 起始页面和结束页数均可设置为 `1`～`5`，默认抓取第 `1`～`5` 页。

例如，选择「日榜」和「手机壁纸」时，对应路径为 `ranking-daily-sp`。

### 单个作品

从插件内置的动漫、游戏作品列表中选择一个作品进行抓取。列表项对应站点的 `images/`、`category/` 或 `tag/` 路径。

选择「单个作品」模式后，在「作品」配置项中直接选择目标作品，并用「作品列表起始页」与「作品列表结束页」指定抓取范围。默认抓取第 `1`～`10` 页；插件会在日志中打印输入范围和站点实际范围，输入范围超出站点末页时会发出警告并跳过超出部分。

### 搜索

通过站点原生搜索 URL 按关键词抓取搜索结果，可控制排列方向、排序方式与页码范围。

- 搜索关键词作为 URL 的 `s` 参数；可输入作品名、角色名等站点可检索内容。
- 排列方向对应 `order=DESC|ASC`，默认降序。
- 排序方式对应 `orderby=post_date|rand`，默认按发布日期；随机排序时方向不影响结果。
- 搜索起始页与结束页默认为 `1`～`10`，结束页包含在抓取范围内。
- 插件会读取站点实际总页数，跳过超出末页的范围并写入 warning。

## 使用示例

### 抓取日榜高质量 PC 壁纸

1. 将「爬取模式」设为「排行榜」。
2. 将「排行榜周期」设为「日榜」。
3. 将「排行榜子类」设为「高质量 PC 壁纸」。
4. 设置起始页面和结束页面后运行任务。

### 抓取指定作品

1. 将「爬取模式」设为「单个作品」。
2. 在「作品」中选择目标动漫或游戏。
3. 设置作品列表的起始页和结束页后运行任务。

### 搜索壁纸

1. 将「爬取模式」设为「搜索」。
2. 输入搜索关键词，选择排列方向与排序方式。
3. 设置搜索起始页和结束页后运行任务。

## 开发

```bash
npm run build
```

构建产物入口为 `dist/main.js`。
