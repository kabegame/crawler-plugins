# anihonet アニメ壁紙

[anihonetwallpaper.com](https://anihonetwallpaper.com) からアニメ・ゲームの壁紙を収集する Kabegame プラグインです。スマホ壁紙とデスクトップ壁紙の両方に対応しています。

## 取得モード

3 種類の取得モードに対応し、既定値は「ランキング」です。モードを選択すると、Kabegame にはそのモードで必要な設定項目だけが表示されます。

### ランキング

ランキング期間、ランキング種別、ページ範囲を指定して壁紙を取得します。

- ランキング期間：日間、週間、月間、年間。
- ランキング種別：総合、スマホ壁紙、高品質画像、高品質 PC 壁紙、PC 壁紙。
- 開始ページと終了ページはどちらも `1`～`5` に設定でき、既定では `1`～`5` ページを取得します。

たとえば「日間」と「スマホ壁紙」を選択すると、パスは `ranking-daily-sp` になります。

### 作品指定

プラグインに内蔵されたアニメ・ゲーム作品一覧から、取得する作品を 1 つ選択します。各項目はサイトの `images/`、`category/`、または `tag/` パスに対応しています。

「作品指定」モードを選択した後、「作品」設定から目的の作品を選び、「作品一覧の開始ページ」と「作品一覧の終了ページ」で取得範囲を指定してください。既定値は `1`～`10` ページです。入力範囲とサイトから検出した実際の範囲はログに出力され、入力範囲がサイトの最終ページを超える場合は警告されます。

### 検索

サイトの標準検索 URL を使い、キーワード、並び方向、並び順、ページ範囲を指定して検索結果を取得します。

- 検索キーワードは URL の `s` パラメータになります。作品名やキャラクター名などを入力できます。
- 並び方向は `order=DESC|ASC` に対応し、既定値は降順です。
- 並び順は `orderby=post_date|rand` に対応し、既定値は投稿日です。ランダムでは並び方向は結果に影響しません。
- 検索開始ページと終了ページの既定値は `1`～`10` で、終了ページも取得対象に含まれます。
- サイトの実際の最終ページを検出し、それを超える範囲をスキップして warning を出力します。

## 使用例

### 日間ランキングの高品質 PC 壁紙を取得する

1. 「取得モード」を「ランキング」に設定します。
2. 「ランキング期間」を「日間」に設定します。
3. 「ランキング種別」を「高品質 PC 壁紙」に設定します。
4. 開始ページと終了ページを設定してタスクを実行します。

### 指定した作品を取得する

1. 「取得モード」を「作品指定」に設定します。
2. 「作品」から目的のアニメまたはゲームを選択します。
3. 作品一覧の開始ページと終了ページを設定してタスクを実行します。

### 壁紙を検索する

1. 「取得モード」を「検索」に設定します。
2. 検索キーワードを入力し、並び方向と並び順を選択します。
3. 検索開始ページと終了ページを設定してタスクを実行します。

## 開発

```bash
npm run build
```

ビルド出力のエントリーポイントは `dist/main.js` です。
