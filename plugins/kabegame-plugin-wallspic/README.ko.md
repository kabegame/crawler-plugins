# wallspic 플러그인

이 플러그인은 [wallspic.com](https://wallspic.com)의 배경화면 목록을 가져와 원본에 가까운 이미지를 다운로드합니다. Kabegame에서 앨범 또는 태그 단위로 일괄 수집할 때 적합합니다.

## 이럴 때 쓰면 좋음

- **앨범 모드**: 사이트 앨범 분류(Anime, Nature, Technology 등)로 목록 탐색.
- **태그 모드**: 태그 페이지 수집(사이트 `/tag/...`와 동일).
- **정렬**, **기기/해상도**, **페이지 범위**를 제한하고 싶을 때.

## 사용 전 참고

- 저작권은 사이트 및 저작자에게 있습니다. 약관을 준수하고 페이지 수·빈도를 적절히 설정하세요.
- **끝 페이지**는 스크립트가 읽은 사이트 최대 페이지와 비교해 더 작은 값으로 제한됩니다.

## 옵션 설명

### 모드

- **앨범**: 아래 **앨범 카테고리** 사용. 경로는 `/album/{슬러그}`. **모든 카테고리**는 홈 목록입니다.
- **태그**: **태그 키워드**에 태그명(태그 URL의 영문 슬러그). **비우면** 홈 목록(범위가 넓으므로 페이지 제한 권장).

### 앨범 카테고리(앨범 모드만)

wallspic 앨범과 동일: Brands, Anime, Games, Nature 등.

### 태그 키워드(태그 모드만)

예: `anime`. 브라우저 태그 페이지 URL의 태그 구간과 맞춥니다.

### 정렬

- **New**: 기본(최신. 경로에 `popular` 없음).
- **Popular**: 인기(`popular` 경로 포함).

### 해상도 모드

- **모든 배경화면**: 해상도 필터 없음.
- **모바일 / 데스크톱**: 사이트 모바일·데스크톱 경로 사용.
- **지정 해상도**: **해상도 프리셋 그룹**(Ultra HD / Apple / Android / Widescreen) 선택 후 구체 크기 선택. 목록 URL에 해당 슬러그가 붙습니다.

### 시작 페이지 / 끝 페이지

몇 페이지부터 몇 페이지까지(양끝 포함). 실제 상한은 플러그인 max와 사이트 페이지 수입니다.

## 팁

1. 처음에는 **앨범** + 자주 쓰는 카테고리, **끝 페이지**는 작게.
2. 특정 태그는 **태그** 모드로 URL 슬러그와 일치시키기.
3. 특정 해상도만 필요하면 **지정 해상도**에서 그룹과 크기 선택.
