# yande.re 애니메이션 벽지 - 플러그인 설명

`yande.re`에서 고해상도 애니메이션 벽지를 크롤링해 다운로드 큐에 추가합니다.
이 사이트는 Moebooru(konachan과 동일한 소프트웨어)로 돌아가므로 목록 페이지·
상세 페이지·태그 표의 구조가 konachan 플러그인과 동일합니다.

## 크롤 모드

- **전체(all)**: 사이트 전체의 최신 작품(`/post?page=N`)
- **태그(tags)**: 태그 조합으로 검색(`/post?tags=a+b&page=N`)
- **태그 목록(tag_list)**: 검색식으로 태그 표(`/tag?name=...`)를 훑은 뒤 태그마다 작품을 수집

## 설정 항목

- **태그 조합(mode_tag_value)**: 목록 입력. 실행 시 `+`로 결합하며 공백은 `_`로 변환
- **등급 필터(rating)**: 제한 없음 / 전체 이용가(Safe) / 애매함(Questionable) /
  노골적(Explicit). 구현은 사이트의 `rating:` 메타태그를 검색 문자열에 붙이는 것입니다
- **정렬(sort_order)**: 최신순 / 점수순 / 해상도순 / 무작위. 사이트의 `order:` 메타태그에 대응
- **시작 페이지 / 끝 페이지**: 실행당 최대 100페이지, **페이지당 40장 고정**
- **태그 검색식(tag)**: 태그 목록 모드에서 쓰는 이름 검색식. `*`는 와일드카드(예: `*genshin*`)
- **태그 타입(mode_tag_type)**: 임의 / 일반 / 작가 / 저작권 / 캐릭터 / 서클 / 결함
- **태그 순서(mode_tag_order)**: 이미지 수 / 이름 / 날짜
- **태그 스킵 수 / 크롤할 태그 수 / 태그당 페이지 수**: 태그 목록 모드의 폭과 깊이
- **화질(quality)**:
  - **고화질(high)**: Options 영역의 "View larger version" 원본 직링크. 원본이 없는
    게시물에서는 자동으로 낮은 화질로 내려갑니다
  - **중간(medium)**: 사이트가 축소한 `#image` sample

## 메타데이터

모든 이미지에는 상세 페이지에서 해석한 메타데이터가 붙으며, 이미지 상세 사이드바에서
`description.ejs`로 렌더링됩니다:

- `sidebar_tags`: 각 태그의 `name` / `display` / `type` / `count` / 사이트 내 검색 링크 / wiki 링크
- `stats`: `post_id`, `size`, `rating`, 게시 시각(상대 표현 + `title`의 절대 시각),
  즐겨찾기한 사용자(최대 24명, 전체 수는 `favorited_total`)
- `posted_by_name` / `posted_by_href`, `source_href`, `score`
- `related`: 상세 페이지의 Related Posts(이전 / 다음 / 무작위)
- **`comments`: 상세 페이지 하단의 댓글 영역** — 작성자, 아바타, 상대 시각
  (`title`의 절대 시각 포함), 본문을 최대 30개, 전체 수는 `comment_total`

또한 PathQL provider를 등록하므로 갤러리에서 **태그 타입 → 태그** 2단계로
다운로드한 이미지를 탐색할 수 있습니다.

## 주의 사항

- **태그 타입 파라미터는 숫자만 받습니다.** 사이트의 `/tag?type=`은 `0`(general),
  `1`(artist), `3`(copyright), `4`(character), `5`(circle), `6`(faults)를 받습니다.
  영어 이름을 넘겨도 오류가 나지 않고 조용히 `0`(일반)으로 처리되므로, 설정 항목의
  값은 이 숫자들로 되어 있습니다.
- **페이지당 40장은 사이트가 고정한 값**이며, 로그인하지 않은 상태에서는 쓸 수 있는
  페이지 크기 파라미터가 없습니다.
- **즐겨찾기 사용자와 댓글은 잘라냅니다**(24명 / 30개). 인기 게시물은 즐겨찾기 사용자가
  수천 명에 이를 수 있고, 메타데이터는 통째로 저장되어 앨범 목록 쿼리에도 실리므로
  제한하지 않으면 앨범 화면이 눈에 띄게 느려집니다.
- **예의 있게 크롤링하세요**: 실행당 최대 100페이지이며 초과하면 실행을 거부합니다.
  끝 페이지는 시작 페이지 이상이어야 합니다.
- 성인물과 전연령물이 섞여 있습니다. 건전한 이미지만 원하면 등급 필터를
  전체 이용가(Safe)로 설정하세요.
- 이 사이트의 원본은 7000px 이상, 수십 MB인 경우가 많으니 "고화질"에서는 디스크와
  대역폭에 유의하세요.
- 보통 사용 가능한 프록시가 필요합니다.

즐겁게 사용하세요~
