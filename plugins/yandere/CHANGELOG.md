# yande.re 更新日志

## 1.2.0

- 新增「id 范围」爬取模式：填写起始 id 和结束 id（作品页地址 `/post/show/<id>` 里的数字），按 id 从小到大抓取区间内的全部作品。两个 id 最多相差 5000，超出会拒绝爬取。站点仍保留在列表里的已删除作品取不到图，会记一条警告后跳过。「分级过滤」同样适用，「排序」在这个模式下固定为按 id。

## 1.1.0

- 新增「排行榜」爬取模式，对应站点的人气榜：日榜、周榜、月榜可以指定日期看往期，并能往前连抓多期（站点每期只有一页、最多 40 张）；另有最近 24 小时、一周、一个月、一年的滚动榜。分级过滤在这个模式下由插件按每张图的分级筛选；「排序」只对全部和标签模式有效，排行榜模式下不再显示。
- 下载时把侧栏的标签按颜色（类型）写入应用的「标签」分区：画师、版权、角色、社团、缺陷、通用分别在 `yandere/artist`、`yandere/copyright`、`yandere/character`、`yandere/circle`、`yandere/faults`、`yandere/general` 下，可在画册页浏览、在搜索里按标签筛选。
- 标签 key 使用站点的标签名（如 `hatsune_miku`），显示名使用页面上的文字。
- 历史下载的图片会在元数据迁移时自动补上标签。
- 最低应用版本提升至 `4.5.0`。
- 移除插件自带的「标签类型 → 标签」浏览（已由应用级标签取代），画廊插件扩展改为按 **分数 score**（`5+` … `1000+` 档位，路径段支持区间 `100-500`、`100+`、`-50`）与 **分级 rating**（Safe / Questionable / Explicit）筛选。
- 移除「标签列表」爬取模式及其推荐配置。按标签抓图请用「标签」模式。之前保存的标签列表运行配置会报「未知的爬取模式」，需要改成其他模式。

## 1.0.0

首个版本。

- 三种爬取模式：全部、标签、标签列表
- 分级过滤（Safe / Questionable / Explicit）与排序（最新 / 高分 / 分辨率 / 随机），
  实现上都是站点的 `rating:` / `order:` 元标签
- 质量分高（Options 区的原文件直链）/ 中（`#image` 的 sample）
- 元数据带侧栏标签、统计信息、相关作品，**并还原了详情页下方的评论区**
  （作者、头像、时间、正文），在图片详情侧栏一并渲染
- PathQL provider：画廊里按 标签类型 → 标签 两级浏览已下载的图

祝你使用愉快～
