# yande.re 更新日志

## 1.0.0

首个版本。

- 三种爬取模式：全部、标签、标签列表
- 分级过滤（Safe / Questionable / Explicit）与排序（最新 / 高分 / 分辨率 / 随机），
  实现上都是站点的 `rating:` / `order:` 元标签
- 质量分高（Options 区的原文件直链）/ 中（`#image` 的 sample）
- 元数据带侧栏标签、统计信息、相关作品，**并还原了详情页下方的评论区**
  （作者、头像、时间、正文），在图片详情侧栏一并渲染
- PathQL provider：画廊里按 标签类型 → 标签 两级浏览已下载的图

祝你使用愉快～
