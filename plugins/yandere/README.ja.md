# yande.re アニメ壁紙 - プラグイン説明

`yande.re` から高解像度のアニメ壁紙をクロールしてダウンロードキューに追加します。
このサイトは Moebooru（konachan と同じソフトウェア）で動いているため、一覧ページ・
詳細ページ・タグ表の構造は konachan プラグインと同型です。

## クロールモード

- **全部（all）**：サイト全体の新着作品（`/post?page=N`）
- **タグ（tags）**：タグの組み合わせで検索（`/post?tags=a+b&page=N`）
- **タグ一覧（tag_list）**：まず検索式でタグ表（`/tag?name=...`）を辿り、タグごとに作品を取得

## 設定項目

- **タグ組み合わせ（mode_tag_value）**：リスト入力。実行時に `+` で連結し、空白は `_` に変換
- **レーティング絞り込み（rating）**：指定なし / 全年齢(Safe) / 際どい(Questionable) /
  露骨(Explicit)。実装はサイトの `rating:` メタタグを検索文字列に付加するだけです
- **並び順（sort_order）**：新着順 / スコア順 / 解像度順 / ランダム。サイトの `order:` メタタグに対応
- **開始ページ / 終了ページ**：1回あたり最大100ページ、**1ページ40枚固定**
- **タグ検索式（tag）**：タグ一覧モードでの名前検索式。`*` はワイルドカード（例：`*genshin*`）
- **タグタイプ（mode_tag_type）**：任意 / ジェネラル / 作家 / 著作権 / キャラクター / 界隈 / 不備
- **タグ順序（mode_tag_order）**：画像数 / 名称 / 日付
- **タグスキップ数 / クロールするタグ数 / タグごとのページ数**：タグ一覧モードの広さと深さ
- **画質（quality）**：
  - **高（high）**：Options 欄の「View larger version」のオリジナル直リンク。
    オリジナルが無い投稿では自動的に降格します
  - **中（medium）**：サイトが縮小した `#image` の sample

## メタデータ

各画像には詳細ページから解析したメタデータが付き、画像詳細のサイドバーで
`description.ejs` により描画されます：

- `sidebar_tags`：各タグの `name` / `display` / `type` / `count` / サイト内検索リンク / wiki リンク
- `stats`：`post_id`、`size`、`rating`、投稿時刻（相対表記＋`title` の絶対時刻）、
  お気に入り登録者（最大24人、総数は `favorited_total`）
- `posted_by_name` / `posted_by_href`、`source_href`、`score`
- `related`：詳細ページの Related Posts（前へ / 次へ / ランダム）
- **`comments`：詳細ページ下部のコメント欄**——投稿者・アバター・相対時刻
  （`title` の絶対時刻付き）・本文を最大30件、総数は `comment_total`

さらに PathQL provider を登録するので、ギャラリーで **タグタイプ → タグ** の2段で
ダウンロード済み画像を辿れます。

## 注意事項

- **タグタイプのパラメータは数字しか受け付けません。** サイトの `/tag?type=` は
  `0`(general) / `1`(artist) / `3`(copyright) / `4`(character) / `5`(circle) /
  `6`(faults) を取ります。英語名を渡してもエラーにはならず、黙って `0`（ジェネラル）
  として扱われるため、設定項目の値はこれらの数字にしてあります。
- **1ページ40枚はサイト側の固定値**で、未ログインでは使えるページサイズ指定がありません。
- **お気に入り登録者とコメントは打ち切ります**（24人 / 30件）。人気投稿では登録者が
  数千人になることがあり、メタデータは丸ごと保存されてアルバム一覧のクエリにも
  乗るため、無制限にするとアルバム表示が目に見えて遅くなります。
- **礼儀正しくクロールしましょう**：1回あたり最大100ページ、超えると実行を拒否します。
  終了ページは開始ページ以上である必要があります。
- 成人向けと全年齢が混在しています。健全な画像だけが欲しい場合はレーティングを
  全年齢(Safe) にしてください。
- このサイトのオリジナルは7000px超・数十MBになることも多いので、「高」画質では
  ディスクと帯域にご注意ください。
- 通常は利用可能なプロキシが必要です。
