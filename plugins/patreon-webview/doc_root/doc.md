# Patreon 创作者内容（WebView）

从 patreon.com 抓取创作者帖子的**图片**与**压缩包附件**。压缩包不进图库——它们由宿主解压后，
把里面的图片逐个入库。

## 使用前提：先登录 Patreon

Patreon 的附件几乎全是会员可见。本插件跑在真实浏览器窗口里，直接沿用你在该窗口内的登录态。
首次运行若未登录，窗口会弹出让你完成登录（以及可能出现的 Cloudflare 验证）。

## 为什么这个插件是 WebView 后端

`patreon.com` 全站在 Cloudflare 的**客户端指纹识别**之后。实测（2026-07-28）：HTML 页返回
`cf-mitigated: challenge`，`/api/*` 返回 403，连 `/api/current_user` 都拒。逐项排除过 Cookie
完整性、User-Agent、`Content-Type`、`sec-ch-ua` / `sec-fetch-*` 全套浏览器头、HTTP/2——
剩下唯一变量是 TLS/HTTP 客户端指纹。

普通 HTTP 客户端（V8 后端的 `fetch` 走宿主 reqwest，以及 curl）都过不去，**只有真实浏览器
引擎能过**。所以本插件用 WebView 后端：先由真实页面过挑战并拿到 `campaign id`，之后所有
接口请求都用页面自己的 `fetch`（同源、自动带 Cookie、真浏览器指纹）。

## 配置项

| 配置 | 说明 |
| --- | --- |
| 创作者 | 主页地址里的名字，如 `https://www.patreon.com/c/foobar` 填 `foobar`。也可直接粘完整链接。 |
| 起始页 / 结束页 | 帖子列表每页约 10~20 个帖子，第 1 页最新。结束页填 `0` 表示一直下到最后一页。 |
| 压缩包内提取规则 | glob 模式，决定包里哪些文件被提取入库。默认只要常见图片格式。 |
| 压缩包密码 | 部分创作者会加密附件并把密码写在帖子正文里。 |
| 同时下载帖子正文图片 | 关闭则只处理压缩包附件。 |

### 关于「起始页」的一个提醒

Patreon 是**游标分页**，没有「第 N 页」这样的直接地址——要到第 50 页，必须先依次请求前 49 页
来推进游标。所以起始页填得越大，开始下载前的等待越久（那些页只请求、不下载）。

如果只是想续着上次的进度接着下，通常填「起始页 = 上次的结束页 + 1」即可。

### 关于「压缩包内提取规则」

Patreon 的压缩包里经常混着 PSD 源文件、字体、说明文本。这些文件进不了图库，不过滤的话会刷出
一串失败记录。默认规则 `**/*.{png,jpg,jpeg,webp,gif,avif,bmp}` 只挑图片。

留空表示全部提取——除非你确认包里全是图片，否则不建议。

## 支持的压缩格式

`.zip`、`.7z`、`.tar`、`.tar.gz` / `.tgz`、`.tar.bz2` / `.tbz2`。

**`.rar` 不支持**：没有可用的纯 Rust 解码器，且官方 unrar 的许可证禁止用于重建 RAR 压缩算法。
遇到 rar 附件会给一条提示后跳过。

## 已知限制

- **不解 DRM**。Patreon 的视频普遍带 DRM，本插件不处理视频。
- **不绕订阅墙**。只能下到当前账号本就有权限的内容；无权查看的帖子会被跳过。
- `campaign id` 需要从创作者主页解析。Patreon 前端改版频繁，若解析失败，可以先在浏览器里找到
  campaign id，然后把「创作者」填成 `id:<campaign_id>` 绕开这一步。
