# Safebooru 全年龄图库 - 插件说明

本插件从 `safebooru.org`（Gelbooru 的全年龄站）收集作品。与 Gelbooru 插件解析网页不同，
这里走站点**匿名可用的官方 API**（`index.php?page=dapi`），一页一次请求就能拿到全部帖子与
**带分类的全量标签**，比逐个打开详情页快得多，也更稳。

## 爬取模式

- **标签（tags）**：按标签组合检索，最常用
- **全部（all）**：全站最新作品
- **id 范围（id_range）**：按帖子 id 闭区间检索 `id:>=A id:<=B sort:id:asc`，按 id 从小到大抓完整个区间

## 配置项

- **标签组合（mode_tag_value）**：列表输入，运行时用 `+` 连接；标签里的空格自动转下划线 `_`。
  站点元标签可以直接写进来，例如：
  - `width:>=1920`、`height:<=1200`：按分辨率筛选，适合找壁纸
  - `score:>=100`：只要高分图
  - `-1boy`：排除某个标签
- **排序（sort_order）**：最新发布 / 高分优先 / 最近更新 / 随机（站点的 `sort:` 元标签）
- **起始页面 / 结束页数（start_page / end_page）**：每页固定 42 张，**页码与网页列表一一对应**；一次最多 100 页。
  站点（API 和网页都一样）只允许起始偏移不超过 20 万条，也就是直接翻页最多到第 4762 页：
  - **最新发布**排序：超过这一页时插件改用 `id:<` 游标继续往后翻，结果和直接翻页首尾相接。
    从更深的页开始时先跳转定位，每跳约 20 万条，比如第 20000 页约 5 个请求
  - **高分 / 最近更新 / 随机**排序：无法按 id 截断，超过这一页任务会报错并提示改用「最新发布」，
    或者收窄标签让结果总数落在上限以内
- **起始 id / 结束 id（id_start / id_end）**：id 范围模式用，帖子 id 闭区间（帖子页地址里 `id=` 后面的数字），
  **最多相差 5000**，否则拒绝爬取。不用填页数；已删除的帖子本来就不在结果里，会直接跳过。标签组合和排序不参与这个模式
- **质量（quality）**：高 = 原图；中 = 站点缩放后的 sample（长边约 850px），没有 sample 的小图两档都取原图
- **抓取评论（fetch_comments）**：有评论的帖子额外打开一次详情页，把评论存进元数据。大多数帖子没有评论，几乎不会多发请求

## 元数据

每张图都带上以下信息，图片详情的「插件详情」面板按 Safebooru 详情页侧栏的样子渲染：

- `tags`：每个标签的规范名、分类（copyright / character / artist / general / metadata）和站内作品数
- `tags_string`：按 版权 → 角色 → 作家 → 通用 → 元信息 排好序的**全量标签串**，可直接当 AI 生图 prompt
- `post_id`、`rating`、`score`、`width`、`height`、`md5`、`file_ext`、`source`
- `owner`（上传者）、`created_at`（发布时间，带站点时区）
- `comments`：评论者、评论编号、发布时间、评论分数和正文

下载时会把标签按分类写入应用的「标签」分区，路径为 `safebooru/<分类>/<标签>`。

## 网络

站点在中国大陆直连非常慢、经常超时，建议走代理。图片 CDN 不校验 Referer。
