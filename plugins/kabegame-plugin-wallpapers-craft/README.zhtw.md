# WallpapersCraft 桌布

本外掛從 [WallpapersCraft](https://wallpaperscraft.com)（wallpaperscraft.com）擷取桌布清單與下載連結，方便在 Kabegame 裡批次瀏覽或下載。

## 適用情境

- 想依網站上的**分類目錄**瀏覽（如 Anime、Nature 等）。
- 想依**標籤**篩選（與網站標籤頁一致）。
- 需要限定**排序**或**解析度**，減少無關結果。

## 使用前須知

- 內容版權歸原網站及作者所有，請遵守其服務條款與使用習慣，合理控制擷取頻率與頁數。
- **結束頁數**會與網站實際分頁上限取較小值，避免超出站點範圍。

## 選項說明

### 模式

- **目錄選擇**：從下方「目錄」裡選一個固定分類，與網站 `/catalog/...` 對應。
- **標籤輸入**：在「標籤」裡填寫標籤名，與網站 `/tag/...` 對應。若**留空**，則擷取全站彙總清單（相當於 `/all`），範圍較大，建議配合頁數限制使用。

### 目錄（僅「目錄選擇」模式）

與網站分類一致，例如 3D、Abstract、Anime、Nature、Technologies（網站路徑為 hi-tech）等，任選其一即可。

### 標籤（僅「標籤輸入」模式）

填寫網站上的標籤英文識別（與標籤頁 URL 一致）。留空表示不依標籤過濾，擷取 `/all`。

### 排序方式

- **預設**：站點預設順序。
- **下載數量**：依熱度／下載量相關排序。
- **日期**：依時間相關排序。

### 解析度類別與具體解析度

- **不指定**：不依解析度過濾，清單與網站預設一致。
- **行動／蘋果／全螢幕／寬螢幕**：先選類別，再在對應選項裡選具體解析度（如 1920×1080、3840×2160 等）。外掛會只擷取該解析度路徑下的清單頁。

### 起始頁數／結束頁數

從第幾頁擷取到第幾頁（含兩端），皆為正整數，上限以外掛設定為準。若網站總頁數更少，實際只會擷取到網站最後一頁為止。

## 簡要使用建議

1. 初次使用可選 **目錄選擇**＋常用分類（如 Anime），**結束頁數**先設小一點試跑。
2. 需要某標籤時改用 **標籤輸入**，標籤名與瀏覽器開啟該標籤頁時網址列中的片段一致較穩妥。
3. 只要某種桌面寬度桌布時，再開啟 **解析度類別** 並選對解析度，可縮小清單雜訊。
