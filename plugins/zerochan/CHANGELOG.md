# Zerochan 更新日志

## 1.0.0

首个版本。

- 三种爬取模式：浏览全部、单个站内标签、任意关键词搜索
- 两种排序：最新（按上传时间）/ 人气（按收藏数）
- 质量分高（原图直链）/ 中（站点 1024px webp 预览）
- 自动完成站点的 `xbotcheck` bot 校验，无需人工干预
- 网络容错：连接超时按退避重试，单张图打不开只记一条 WARN 跳过，不会中断整个任务
- **完整侧栏元数据**：分类标签（含添加者、fav / primary 标记）、来源 URL、
  分享三件套（直链 / BBCode / HTML）、尺寸与收藏统计
- 详情侧栏模板 `description.ejs`：按站点自身色板与 sprite 图标还原右侧栏，
  区块标题与文案随应用语言切换（简中 / 繁中 / 英 / 日 / 韩），浅色深色跟随应用主题，
  分享文本一键复制

祝你使用愉快～
