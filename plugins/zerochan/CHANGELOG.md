# Zerochan 更新日志

## 1.1.0

- 修复「浏览全部 + 人气」第一页就报 HTTP 500：站点首页人气榜的「全部时间」档本身返回 500（站点菜单里的链接也一样）。新增「人气时间范围」配置（近一周 / 近三个月，默认近三个月），只在浏览全部且排序选人气时显示。
- 新增「随机」排序。浏览全部时可以正常翻页；标签和搜索下站点只给一页。
- 下载时把侧栏标签按类型写入应用的「标签」分区：画师、作品、游戏、角色、服装、主题、来源等分别在 `zerochan/mangaka`、`zerochan/series`、`zerochan/game`、`zerochan/character`、`zerochan/outfit`、`zerochan/theme`、`zerochan/source` 等目录下，可在画册页浏览、在搜索里按标签筛选。
- 标签 key 由站点规范名派生（如 `Fate/Grand Order` → `fate grand order`），显示名保留规范名。超过 64 字节的超长标签名（多见于轻小说系列）不会建标签。
- 历史下载的图片会在元数据迁移时自动补上标签。
- 最低应用版本提升至 `4.5.0`。

## 1.0.0

首个版本。

- 三种爬取模式：浏览全部、单个站内标签、任意关键词搜索
- 两种排序：最新（按上传时间）/ 人气（按收藏数）
- 质量分高（原图直链）/ 中（站点 1024px webp 预览）
- 自动完成站点的 `xbotcheck` bot 校验，无需人工干预
- 网络容错：连接超时按退避重试，单张图打不开只记一条 WARN 跳过，不会中断整个任务
- **完整侧栏元数据**：分类标签（含添加者、fav / primary 标记）、来源 URL、
  分享三件套（直链 / BBCode / HTML）、尺寸与收藏统计
- 详情侧栏模板 `description.ejs`：按站点自身色板与 sprite 图标还原右侧栏，
  区块标题与文案随应用语言切换（简中 / 繁中 / 英 / 日 / 韩），浅色深色跟随应用主题，
  分享文本一键复制

祝你使用愉快～
