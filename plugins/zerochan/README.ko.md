# Zerochan 애니메이션 이미지 보드 - 플러그인 설명

이 플러그인은 `zerochan.net`에서 애니메이션 이미지를 수집해 다운로드 대기열에 추가합니다.
사이트가 **완전한 서버 사이드 렌더링**이라 목록과 상세가 모두 첫 HTML 응답에 들어 있어,
플러그인은 가벼운 `fetch` + DOM 파싱만으로 동작합니다(WebView 불필요).

Zerochan의 강점은 **사람이 정리한 태그 체계**입니다. 모든 태그가 분류되어 있고
(작가 / 작품 / 캐릭터 / 테마 / 출처), 누가 추가했는지도 기록되며, 원작이 어디에 게시되었는지
(Pixiv, Twitter, DeviantArt …)도 남아 있습니다. 이 정보는 모두 이미지 메타데이터에 저장되고,
이미지 상세 사이드바에서 사이트 본래의 색상 그대로 재현됩니다.

## 크롤 모드

- **전체 탐색(all)**: 태그 없이 사이트 전체 `/?s=…&p=N`
- **태그(tag)**: 사이트 태그 1개 `/<Tag+Name>?s=…&p=N`
- **검색(search)**: 임의의 검색어 `/search?q=…`. 사이트가 가장 일치하는 태그로 이동한 뒤
  나머지 단어로 계속 필터링합니다(예: `blue hair smile` → `Blue Hair` 태그 + 나머지 조건)

세 모드 모두 **정렬**을 고를 수 있습니다:

- **최신(id)**: 업로드 최신순
- **인기(fav)**: 즐겨찾기 많은 순

## 설정 항목

- **크롤 모드(crawl_mode)**: 전체 탐색 / 태그 / 검색
- **태그(tag)**: 사이트 태그의 정식 명칭(영문). 예: `Arknights`, `Hatsune Miku`, `Genshin Impact`
- **검색어(search_query)**: 임의의 검색어
- **정렬(sort_order)**: 최신 / 인기
- **시작 페이지 / 끝 페이지(start_page / end_page)**: 페이지당 48개, 실행당 최대 100페이지
- **화질(quality)**:
  - **고화질(high)**: 원본 직접 링크(`static.zerochan.net/….full.….jpg`)
  - **중간(medium)**: 사이트의 1024px webp 미리보기

## 메타데이터

각 이미지에는 상세 페이지에서 파싱한 메타데이터가 함께 저장되며, 이미지 상세 사이드바에서
`description.ejs`가 사이트의 오른쪽 칼럼을 그대로 재현합니다:

- `tags`: 태그별 정식명 `tag`, 표시명 `label`, 분류 `type`, 스프라이트 아이콘 `icon`,
  사이트 링크 `url`, 추가자 `by`, 그리고 `fav` / `primary` 플래그
- `tags_string`: 정식명을 이어 붙인 문자열. 재검색에 그대로 쓸 수 있습니다
- `source`: 원작 게시 페이지 URL과 사이트 아이콘 이름(pixiv / twitter / deviantart …)
- `share`: 사이트가 제공하는 직접 링크, BBCode 썸네일, HTML 썸네일 세 가지
- `stats`: 크기, 메가픽셀, 즐겨찾기 수, 태그 수
- `post_id`, `title`, `permalink`, `breadcrumbs`, `mangaka`, `uploader`, `uploaded_at`
- `file_size`, `file_ext`, `width`, `height`, `full_url`, `sample_url`

사이드바의 네 블록(태그 / 출처 URL / 공유 / 상태)은 **앱 언어를 따릅니다**
(간체 중국어 / 번체 중국어 / 영어 / 일본어 / 한국어). 태그 색상과 아이콘은 사이트 자체
스타일시트에서 가져왔고, 라이트/다크는 앱 테마를 따릅니다. 공유 문자열 세 개에는 원클릭 복사가 있습니다.

## 참고 사항

- **사이트에 봇 검사가 있습니다**: 첫 요청은 503 "Checking browser..."를 반환합니다.
  플러그인이 자동으로 통과해 `xbotcheck` 쿠키를 받고 재시도하므로 보통 수동 조작이 필요 없습니다.
- **비로그인 상태에서는 전부 보이지 않습니다**: 목록 페이지 하단에 "Some images on this page are
  for members only"라고 표시되며, 실제로 얻는 항목은 보통 48개보다 적습니다.
  전부 보려면 '서핑'에서 사이트에 로그인하세요.
- **태그는 사이트 정식 명칭으로**: 태그 칸은 자유 입력이 아니라 사이트 태그입니다.
  확실하지 않다면 **검색** 모드를 써서 사이트가 매칭하도록 맡기세요.
- **예의 있게 크롤하세요**: 실행당 최대 100페이지(초과 시 거부), 끝 페이지는 시작 페이지 이상이어야
  합니다. 이미지 사이에는 스로틀링이 들어갑니다.
- 보통 사용 가능한 프록시가 필요합니다.
