# Zerochan アニメ画像掲示板 - プラグイン説明

このプラグインは `zerochan.net` からアニメ画像を取得してダウンロードキューに追加します。
サイトは**完全なサーバーサイドレンダリング**で、一覧も詳細も最初の HTML にすべて含まれているため、
プラグインは軽量な `fetch` + DOM 解析だけで動きます（WebView は不要）。

Zerochan の強みは**人手で整備されたタグ体系**です。各タグはカテゴリ分けされ
（絵師 / 作品 / キャラクター / テーマ / ソース）、誰が追加したかも記録され、
原作がどこで公開されたか（Pixiv、Twitter、DeviantArt……）も分かります。
これらはすべて画像のメタデータに保存され、画像詳細のサイドバーでサイト本来の配色のまま再現されます。

## クロールモード

- **全部を閲覧（all）**：タグなしでサイト全体 `/?s=…&p=N`
- **タグ（tag）**：サイト内タグ1件 `/<Tag+Name>?s=…&p=N`
- **検索（search）**：任意のキーワード `/search?q=…`。サイトは最も一致するタグへ移動し、
  残りの語で絞り込みます（例：`blue hair smile` は `Blue Hair` タグに着地し、残りが条件として重なります）

3つのモードすべてで**並べ替え**を選べます:

- **新着（id）**：アップロード日時の新しい順
- **人気（fav）**：お気に入り数の多い順

## 設定項目

- **クロールモード（crawl_mode）**：全部を閲覧 / タグ / 検索
- **タグ（tag）**：サイト内タグの正式名称（英語）。例：`Arknights`、`Hatsune Miku`、`Genshin Impact`
- **検索キーワード（search_query）**：任意のキーワード
- **並べ替え（sort_order）**：新着 / 人気
- **開始ページ / 終了ページ（start_page / end_page）**：1ページ48件、1回あたり最大100ページ
- **画質（quality）**：
  - **高（high）**：オリジナルの直リンク（`static.zerochan.net/….full.….jpg`）
  - **中（medium）**：サイトの 1024px webp プレビュー

## メタデータ

各画像には詳細ページから解析したメタデータが付き、画像詳細のサイドバーでは
`description.ejs` がサイトの右カラムをそのまま再現します:

- `tags`：各タグの正式名 `tag`、表示名 `label`、カテゴリ `type`、スプライト図標 `icon`、
  サイト内リンク `url`、追加者 `by`、および `fav` / `primary` フラグ
- `tags_string`：正式名を連結した文字列。再検索にそのまま使えます
- `source`：原作公開ページの URL とサイトアイコン名（pixiv / twitter / deviantart …）
- `share`：サイトが提供する直リンク、BBCode サムネイル、HTML サムネイルの3種類
- `stats`：サイズ、メガピクセル、お気に入り数、タグ数
- `post_id`、`title`、`permalink`、`breadcrumbs`、`mangaka`、`uploader`、`uploaded_at`
- `file_size`、`file_ext`、`width`、`height`、`full_url`、`sample_url`

サイドバーの4ブロック（タグ / ソース URL / シェア / ステータス）は**アプリの言語に追従**します
（簡体字中国語 / 繁体字中国語 / 英語 / 日本語 / 韓国語）。タグの配色とアイコンはサイト自身の
スタイルシート由来で、ライト／ダークもアプリのテーマに追従します。
シェアの3つの文字列にはワンクリックコピーが付いています。

## 注意事項

- **サイトには bot チェックがあります**：最初のリクエストは 503「Checking browser...」を返します。
  プラグインが自動でクリアして `xbotcheck` cookie を取得し再試行するので、通常は手動操作は不要です。
- **未ログインではすべては見えません**：一覧ページの末尾に "Some images on this page are for
  members only" と表示され、実際に取得できる件数は48件より少なくなるのが普通です。
  すべて見るには「サーフ」でサイトにログインしてください。
- **タグはサイト内の正式名で**：タグ欄は自由入力ではなくサイト内タグです。
  自信がないときは**検索**モードにして、サイト側にマッチングを任せてください。
- **礼儀正しくクロールしましょう**：1回あたり最大100ページ（超えると拒否）、
  終了ページは開始ページ以上である必要があります。各画像の間にはスロットリングが入ります。
- 通常は利用可能なプロキシが必要です。
