# 小黑盒更新日志

## 0.1.13

- 修复新表情（如 `[cube_鳄鱼]`）在详情里只显示成文字：原先表情表写死在详情模板里，小黑盒上新表情后就认不出来。
- 表情表改存插件数据：爬取时发现帖子或评论里有没见过的表情，才拉一次官方表情列表并合并保存，每次任务最多拉一次；
  下架的旧表情仍保留，历史评论照常显示。拉取失败只告警，不影响下载。
- 详情先按内置表显示，内置表没有的表情再从插件数据补成图片。已下载图片无需重新下载，
  只要之后任意一次任务更新过表情表，重新打开详情即可看到。

## 0.1.12

- 添加自动评论功能，扩散，扩散！默认关闭，开启后每个爬到的帖子先点个赞，再自动发一条评论。
  点赞是幂等的，评论被去重跳过时也照点。
- 自动评论内置去重：帖子已抓到的评论里存在完全相同的内容时跳过，不重复刷屏。
- 评论失败（未登录、风控、接口报错）只记录告警，不中断图片下载。
- 评论接口只认帖子的数字 id，且必须带 Referer，否则一律回「非法的请求」。
- 修正「每页条数」：搜索接口的 limit 单位不是帖子数（返回结果里帖子与版块卡交替，实际帖子数只有 limit 的三分之一），
  之前填 5 只会爬到 1 篇。现在按帖子条数换算，填几就是几，翻页也不再重复。
- 拆分脚本为 consts / util / sign / post / image / comment 六个模块，md5 改用插件 SDK 的实现。

## 0.1.11

- 优化起始页、结束页、每页条数和评论区图片开关的表单宽度，使任务配置布局更紧凑。
- 更新关键词搜索参数截图，并将搜索、图片列表和图片预览横幅统一迁移为 JPG 资源。
- 重写截图资源声明，移除已被替代的旧 PNG 图片引用。
- 新增英语、日语、韩语和繁体中文使用文档，并接入插件多语言文档配置。
