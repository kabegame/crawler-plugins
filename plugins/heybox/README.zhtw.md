# 小黑盒（Heybox）怎麼把圖片收進畫冊

下面說明的是：**當你想把小黑盒裡喜歡的圖片收進 Kabegame 時，整體流程會怎麼進行**。照著做，心裡就有數啦。截圖來自 Kabegame Windows v3.4.3。

---

來源選擇小黑盒。

![選擇小黑盒來源](./src-xhh.png)

## 一、先選好「怎麼找貼文」

小黑盒這邊有兩種用法，二選一即可：

### 1. 依關鍵字搜尋（想找一類圖片時使用）

1. **爬取模式**選擇「關鍵字搜尋」。

![關鍵字搜尋模式](./mode-keyword.png)

2. 在**搜尋關鍵字**中填入想搜尋的詞（壁紙、遊戲名稱、cosplay 之類）。

3. 依需要填寫**起始頁／結束頁／每頁筆數**——數字越大，一次能查看越多貼文，但也會花更長時間。依經驗，約 5 篇貼文是容易觸發風控的門檻。

![關鍵字搜尋設定](./params.jpg)

4. 開始收集後，程式會逐頁搜尋，並依序處理能夠開啟的貼文。

![下載中](./downloading.png)
![收集到的圖片](./banners/images.jpg)
![圖片預覽](./banners/image-preview.jpg)

### 2. 只爬取一篇貼文（已經知道連結時使用）

1. **爬取模式**選擇「單篇貼文 URL」。
2. 在**貼文分享 URL**中貼上由小黑盒**分享貼文**按鈕複製的連結。一定要使用分享貼文按鈕複製的連結，直接從瀏覽器複製網址是不可行的，請參考截圖。

![分享貼文按鈕](./share-btn.png)

貼上：

![貼上 URL](./url-paste.png)

3. 程式只會處理這一篇貼文，不會翻閱搜尋頁面。

![單篇貼文圖片](./url-images.png)
![單篇貼文圖片預覽](./url-image-preview.png)

**個人小建議**  
我比較推薦第 2 種：先在小黑盒找到喜歡的貼文，複製分享連結後再收圖。一般來說**比較不容易被攔截**，也**更準確**，不會混入一堆無關貼文。

---

## 二、找到貼文後，圖片是怎麼收進來的

無論是搜尋出來的，還是你指定的，**每一篇貼文**都會經過下面這套流程：

1. **取得這篇貼文的「內文結構」**  
   內文中的文字和圖片以區塊排列，程式會依序掃描。

2. **只識別「圖片區塊」**  
   每個代表圖片的區塊會先取得一張**小預覽圖**，用來確認順序與圖片數量。

3. **再向小黑盒取得「大圖網址」**  
   每張預覽圖都會再詢問一次大圖在哪裡，取得網址後才下載到畫冊。

4. **多張圖片會分開儲存**  
   同一篇貼文中的多張圖片會用名稱區分，例如在標題後加上編號，不會混在一起。

5. **留言區（可選）**  
   開啟**下載留言區圖片**後，會依樓層收集留言中的圖片；有些貼文的留言圖片可能才是大宗。關閉後就只收集內文圖片。

---

## 三、偶爾可能遇到的情況

- 內文中**完全沒有圖片**時，該貼文會被跳過。
- 小黑盒有時會要求驗證或暫時阻擋存取；切換網路或稍後再試，通常就能恢復。
- 貼文之間、圖片之間會**稍微休息一下**，請耐心等候。

## 五、重要提醒（請多看一眼）

**Cookie（進階）**  
**Cookie** 是網站讓瀏覽器儲存的一小段資訊，用來維持登入狀態等。可在**開始收集 → 進階設定 → HTTP 標頭**中選擇「新增 Header」，名稱填入 `Cookie`，值填入從瀏覽器複製的字串；也可以在**設定 → 外掛預設值 → 爬蟲外掛預設設定**中，為此外掛儲存預設請求標頭，省去每次輸入的麻煩。**使用 Cookie 有封鎖帳號、限制登入等風險，請自行承擔。**

**帶上 Cookie 有什麼好處**  
小黑盒後端對於「未登入、看起來像腳本批次請求貼文詳情」的存取會更嚴格。即使使用官網 API，**不帶 Cookie**時，往往在取得**貼文內文／樓中樓（tree）**這一步就容易被要求進行人機驗證，甚至一篇貼文都無法完整開啟。**帶上已登入小黑盒的 Cookie**後，請求會以**登入使用者**身分進行。實際測試中，連續多篇貼文的詳情都能正常回傳，比匿名存取穩定許多。

因此，如果使用關鍵字翻閱很多頁，或總是「一開始就要求驗證」，可以試著在進階設定中加入 Cookie；如果只是偶爾收集一兩篇分享連結，有時不設定也能使用，但設定後通常比較省心。

**遇到風控或任務錯誤時**

![驗證畫面](./captcha.png)

在**任務**中開啟對應項目，再選擇**日誌**，即可在**任務日誌**視窗中查看詳情。**別灰心**，可以依序嘗試下列一項或多項方法：**更換代理節點**（多數情況這樣就足夠）、**稍等後再試**（休息半天、一天，或更換網路）、**帶上 Cookie**（請參考上面的 Cookie 段落，登入狀態通常比匿名存取穩定）。
