# 小黑盒（Heybox）怎么把图收进画册

下面说的是：**你想从小黑盒里把喜欢的图弄进 Kabegame 时，整体上会怎么走**，照着做心里就有数啦。截图来自 Kabegame windows v3.4.3 

---


源选择小黑盒

![src-xhh](./src-xhh.png)

## 一、先选好「怎么找帖子」

小黑盒这边有两种用法，二选一就行：

### 1. 按关键词搜（想找一类图时用）

1. **爬取模式** 选「关键词搜索」。

![mode-kw](./mode-keyword.png)

2. **搜索关键词** 里填你想搜的词（壁纸、游戏名、cosplay之类）。

3. 按需填 **起始页 / 结束页 / 每页条数**——数字越大，一次多看几篇帖子，也会更久啦（根据经验5条帖子大概是风控的阈值）。

![kw-kirei](./params.jpg)

4. 开始收集后，程序会按页去搜，把能打开的帖子一条条处理。

![downloading](./downloading.png)
![images](./banners/images.jpg)
![image-preview](./banners/image-preview.jpg)

### 2. 只抓一篇帖子（你已经知道链接时用）

1. **爬取模式** 选「单帖子 URL」。
2. **帖子分享 URL** 里贴上小黑盒 **分享帖子** 给的那串链接（一定是分享帖子按钮复制的，直接从浏览器复制链接可行不通哦，见截图）。

![share-btn](./share-btn.png)

粘贴：

![url-paste](./url-paste.png)

3. 就只处理这一篇，不会去翻搜索页啦。

![url-images](./url-images.png)
![url-image-preview](./url-image-preview.png)

**个人小建议**  
我更推荐第 2 种：先在小黑盒里翻到喜欢的帖，复制分享链接再收图。一般 **更不容易被拦**，也 **更准**，不会夹一堆无关帖咯。

## 二、找到帖子以后，图是怎么被收进来的

不管是搜出来的还是你指定的，**每一篇帖子**都会走下面这套（说人话版）：

1. **把这篇帖子的「正文结构」要过来**  
   正文里文字和图片是一块块排好的，程序会扫一遍。

2. **只认「图片块」**  
   每种「这是一张图」的块，会先拿到一张**小预览**，用来知道顺序和有几张。

3. **再向小黑盒要「大图地址」**  
   每张预览都会再问一遍大图在哪，问到才往画册里下。

4. **多张图会分开存**  
   同一篇里多张图会在名字上区分开（例如标题后加序号），不会糊成一团啦。

5. **评论区（可选）**  
   打开 **下载评论区图片** 时，会按楼层把评论里的图也收一收；比如有的帖子评论可能才是大头。关掉就只收正文咯。

---

## 三、偶尔可能会遇到的情况

- 正文里**根本没有配图**，这篇会跳过。
- 小黑盒有时会验证或暂时拦访问，换换网络、过会儿再试，往往就好啦。
- 帖与帖、图与图之间会**稍微歇一会儿**，耐心等一下咯。

## 四、参数一览

| 名称 | 何时出现 | 作用 | 默认 |
| --- | --- | --- | --- |
| 爬取模式 | 始终 | 关键词搜索 / 单帖子 URL | 关键词搜索 |
| 帖子分享 URL | 单帖子时 | 粘贴分享链接 | 空 |
| 搜索关键词 | 关键词搜索时 | 搜什么 | 美图 |
| 起始页（从 1 起） | 关键词搜索时 | 从第几页结果开始 | 1 |
| 结束页（含） | 关键词搜索时 | 翻到第几页（含） | 1 |
| 每页条数 | 关键词搜索时 | 每页拉多少条帖子 | 5 |
| 下载评论区图片 | 始终 | 正文+评论图 / 仅正文 | 开 |

## 五、重要提醒（多看一眼咯）

**Cookie（偏高级）**  
**Cookie**：网站让浏览器保存的一小段信息，用来维持登录之类。可在 **开始收集 → 高级设置 → HTTP 头** 里「添加 Header」，名填 `Cookie`，值填浏览器里复制的串；也可在 **设置 → 插件默认 → 爬虫插件默认配置** 里给该插件存默认请求头，省得每次手填。**有封号、限制登录等风险，自负咯。**

**带上 Cookie 有什么好处（为啥愿意折腾的人会填）**  
小黑盒后端对「没登录、像脚本在批量要帖子详情」会严一些：同样走官网接口，**不带 Cookie** 时，往往在拉**帖子正文/楼中楼（tree）**这一步就很容易被要求验证码（接口直接返回要人机验证），一篇都未必能完整打开。**带上你在小黑盒已登录的 Cookie**，请求会按**登录用户**的身份走，实测里连续多篇帖子的详情都能正常返回，比匿名访问稳得多。  
所以：**关键词翻页多、或总遇到「一上来就验证」**，可以试试在高级设置里配上 Cookie；**只偶尔收一两篇分享链接**，有时不配也能凑合，但配了通常更省心。

**被风控、任务报错**  

![captcha](./captcha.png)

在 **任务** 里点开对应条目，再点 **日志**，弹窗 **任务日志** 里能看到详情。**别灰心**，你可以依次试试下面三件里的一件或几件：**换代理节点**（多数情况这就够了）、**等一等再试**（歇半天、一天，或换网络）、**带上 Cookie**（见上文「Cookie」一节，登录态往往比匿名稳）。
