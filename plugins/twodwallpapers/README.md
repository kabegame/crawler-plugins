# 2dwallpaper 插件说明

爬取 [2dwallpapers.com](https://2dwallpapers.com) 站点的壁纸。现在任务只需要填写**作品**、**起始页数**、**结束页数**和**排序方式**。

## 作品

作品对应站点分类页中的具体作品入口，例如 `Genshin Impact`。插件会在站点的游戏、动漫目录中查找第一个匹配作品，然后只抓取该作品自己的分页列表。

未分类目录没有具体作品入口；如需抓取未分类目录，作品留空即可，插件会直接抓取 `https://2dwallpapers.com/uncategorized` 的分页列表，不再过滤子目录。

- 默认值：空
- 匹配方式：正则匹配作品名称或链接，例如 `Genshin` 会命中 `Genshin Impact`
- 建议一次只匹配一个作品，因为分页页码属于具体作品列表
- 未分类：作品留空直接抓取未分类分页

## 页码范围

`start_page` 和 `end_page` 控制要抓取的作品列表页范围。第一页是作品列表自身 URL，第二页以后使用站点的 `/page/{页码}` 分页路径。

插件会读取网站分页中的总页数，并在日志里打印站点总页数、用户请求范围、跳过页数、实际处理范围，以及每一页的 `当前页/总页数`。

## 排序方式

列表排序由 **orderby** 参数控制，决定同一作品下壁纸的展示顺序和爬取顺序。

| 界面名称 | 对应参数 | 说明 |
|----------|----------|------|
| 最新 | `date` | 按发布时间，最新在前 |
| 最多查看 | `views` | 按浏览量从高到低 |
| 最多喜欢 | `likes` | 按喜欢数从高到低 |
| 最多收藏 | `follow_num` | 按收藏数从高到低 |
| 最近更新 | `modified` | 按最近更新时间 |
| 随机 | `rand` | 随机顺序 |

## 使用示例

- 抓取 `Genshin` 最多查看的第 1 到 10 页：作品填 `Genshin`，起始页数 `1`，结束页数 `10`，排序选择「最多查看」。
- 抓取未分类目录第 1 到 10 页：作品留空，起始页数 `1`，结束页数 `10`，再选择排序方式。
- 抓取其他作品：作品填作品名称的一部分，例如 `Honkai`、`Blue Archive`，再设置页码范围和排序方式。
