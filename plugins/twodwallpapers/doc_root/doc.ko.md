# 2dwallpaper 플러그인 안내

[2dwallpapers.com](https://2dwallpapers.com)에서 벽지를 가져옵니다. 작업에는 **작품**, **시작 페이지**, **끝 페이지**, **정렬**만 지정하면 됩니다.

## 작품

작품은 사이트 카테고리 페이지에 있는 개별 작품 항목입니다. 예: `Genshin Impact`. 플러그인은 게임, 애니메이션, 미분류 섹션에서 처음 매칭되는 작품을 찾고, 그 작품의 페이지 목록만 수집합니다.

- 기본값: `Genshin`
- 매칭 방식: 작품 이름 또는 링크에 대한 정규식. 예: `Genshin`은 `Genshin Impact`와 매칭됩니다
- 페이지 번호는 특정 작품 목록에 속하므로 한 번에 한 작품만 매칭하는 것을 권장합니다

## 페이지 범위

`start_page`와 `end_page`는 수집할 작품 목록 페이지 범위를 지정합니다. 1페이지는 작품 목록 URL 자체를 사용하고, 2페이지 이후는 `/page/{페이지}` 경로를 사용합니다.

플러그인은 사이트 페이지네이션에서 전체 페이지 수를 읽고, 전체 페이지 수, 요청 범위, 건너뛴 페이지 수, 실제 처리 범위, 각 페이지의 `현재/전체`를 로그에 출력합니다.

## 정렬

**orderby** 옵션은 목록 정렬과 수집 순서를 제어합니다.

| 화면 이름 | 파라미터 | 설명 |
|----------|----------|------|
| 최신 | `date` | 최신순 |
| 최다 조회 | `views` | 조회수순 |
| 최다 좋아요 | `likes` | 좋아요순 |
| 최다 즐겨찾기 | `follow_num` | 즐겨찾기순 |
| 최근 업데이트 | `modified` | 최근 업데이트순 |
| 랜덤 | `rand` | 랜덤 |

## 사용 예

- `Genshin`의 최다 조회 1~10페이지 수집: 작품 `Genshin`, 시작 페이지 `1`, 끝 페이지 `10`, 정렬 “최다 조회”를 지정합니다.
- 다른 작품 수집: `Honkai`, `Blue Archive`처럼 작품 이름의 일부를 입력한 뒤 페이지 범위와 정렬을 설정합니다.
