# 2dwallpaper 플러그인 안내

[2dwallpapers.com](https://2dwallpapers.com)에서 벽지를 가져옵니다. 작업 생성 시 **대분류**를 선택하고 **소분류 키워드**(선택)와 **정렬**을 지정합니다.

## 대분류

사이트의 최상위 분류에 대응합니다.

| 화면 이름 | 설명 |
|----------|------|
| 애니메이션 벽지 | `anime-wallpapers` |
| 게임 벽지 | `game-wallpapers` (원신, 붕괴 등) |
| 미분류 | `uncategorized` |

선택하면 해당 대분류 목록 페이지를 연 뒤 「소분류 키워드」로 하위 분류를 필터링합니다.

![cate](./images/cate.png)

## 소분류(키워드)

대분류 페이지에 여러 **하위 분류**(Genshin, 붕괴, 명조 등)가 있습니다. 키워드로 크롤할 하위 분류를 지정합니다.

- **키워드 입력**: 이름이 매칭되는 하위 분류만 (정규식). 예: `Genshin` → Genshin만, `Genshin|Honkai` → 여러 개.
- **비움**: 이름 필터 없음. 스크립트상 첫 하위 분류부터 크롤.

**예**: 대분류 「게임 벽지」, 키워드 `Genshin` → 「게임 벽지 → Genshin」만 크롤.

![scate](./images/scate.png)

## 정렬

목록 정렬(**orderby**)에 따라 크롤 순서가 바뀝니다.

| 화면 이름 | 사이트 값 | 설명 |
|----------|-----------|------|
| 최신 | `Newest` | 게시일시 |
| 최다 조회 | `Popularity` | 조회수 |
| 최다 좋아요 | `Likex` | 좋아요 수 |
| 최다 즐겨찾기 | `Favorites` | 즐겨찾기 수 |
| 최근 업데이트 | `Update` | 업데이트일 |
| 랜덤 | `Random` | 랜덤 |

## 기타

- **크롤 총수**: 이번 작업 최대 다운로드 수(1～1000).

## 사용 예

- 「게임 벽지 → Genshin」을 「최다 조회」로 100장: 대분류 「게임 벽지」, 키워드 `Genshin`, 정렬 「최다 조회」, 크롤 총수 100.
- 「애니메이션 벽지」 아래 특정 소분류 최신: 대분류 「애니메이션 벽지」, 키워드에 해당 소분류 이름(일부), 정렬 「최신」, 크롤 총수 설정.
