# 2dwallpaper 插件说明

爬取 [2dwallpapers.com](https://2dwallpapers.com) 站点的壁纸。创建任务时需选择**大目录**、填写**小目录关键字**（可选）并选择**排序方式**。

## 大目录（目录）

大目录对应站点的一级分类，决定从哪一类壁纸开始爬取。

| 界面名称 | 说明 |
|----------|------|
| 动漫壁纸 | `anime-wallpapers`，动漫相关壁纸 |
| 游戏壁纸 | `game-wallpapers`，游戏相关壁纸（如原神、崩坏等） |
| 未分类 | `uncategorized`，未归入上述分类的壁纸 |

选择后，爬虫会先打开该大目录的列表页（例如「游戏壁纸」对应 `/game-wallpapers`），再在该页下的子分类中按「小目录关键字」过滤。

## 小目录（子目录关键字）

大目录页会列出多个**子分类**（如 Genshin、崩坏、鸣潮等），小目录通过**关键字**从中筛选要爬取的子分类。

- **填写关键字**：只爬取名称中包含该关键字的子目录（正则匹配）。例如填 `Genshin` 只爬「Genshin」相关；填 `Ganshin|Honkai` 可匹配多个。
- **留空**：不按名称过滤，会从当前脚本逻辑上匹配到的第一个子分类开始爬（若需爬全部分类，请依站点实际结构使用合适关键字或分次任务）。

**示例**：大目录选「游戏壁纸」、子目录关键字填 `Genshin`，即只爬「游戏壁纸 → Genshin」下的壁纸。

## 排序方式

列表页的排序由 **orderby** 参数控制，决定同一子目录下壁纸的展示顺序（进而影响爬取顺序）。

| 界面名称 | 对应于网站排序 | 说明 |
|----------|--------|------|
| 最新 | `Newest` | 按发布时间，最新在前 |
| 最多查看 | `Popularity` | 按浏览量从高到低 |
| 最多喜欢 | `Likex` | 按喜欢数从高到低 |
| 最多收藏 | `Favorites` | 按收藏数从高到低 |
| 最近更新 | `Update` | 按最近更新时间 |
| 随机 | `Random` | 随机顺序 |

例如想爬「游戏壁纸 → Genshin」下最热门的图，可将排序选为「最多查看」或「最多喜欢」。

## 其他参数

- **爬取总数**：本次任务最多下载的图片张数（1～1000），达到后停止爬取。

## 使用示例

- 爬取「游戏壁纸 → Genshin」下按「最多查看」排序的前 100 张：大目录选「游戏壁纸」，子目录关键字填 `Genshin`，排序选「最多查看」，爬取总数填 100。
- 爬取「动漫壁纸」下某子类最新图：大目录选「动漫壁纸」，子目录关键字填该子类名称或部分关键字，排序选「最新」，再设置爬取总数。
