# 2dwallpaper 外掛說明

爬取 [2dwallpapers.com](https://2dwallpapers.com) 站點的壁紙。現在任務只需要填寫**作品**、**起始頁數**、**結束頁數**和**排序方式**。

## 作品

作品對應站點分類頁中的具體作品入口，例如 `Genshin Impact`。外掛會在站點的遊戲、動漫和未分類目錄中查找第一個匹配作品，然後只抓取該作品自己的分頁列表。

- 預設值：`Genshin`
- 匹配方式：正則匹配作品名稱或連結，例如 `Genshin` 會命中 `Genshin Impact`
- 建議一次只匹配一個作品，因為分頁頁碼屬於具體作品列表

## 頁碼範圍

`start_page` 和 `end_page` 控制要抓取的作品列表頁範圍。第一頁是作品列表自身 URL，第二頁以後使用站點的 `/page/{頁碼}` 分頁路徑。

外掛會讀取網站分頁中的總頁數，並在日誌裡列印站點總頁數、使用者請求範圍、跳過頁數、實際處理範圍，以及每一頁的 `目前頁/總頁數`。

## 排序方式

列表排序由 **orderby** 參數控制，決定同一作品下壁紙的展示順序和爬取順序。

| 介面名稱 | 對應參數 | 說明 |
|----------|----------|------|
| 最新 | `date` | 依發布時間，最新在前 |
| 最多查看 | `views` | 依瀏覽量從高到低 |
| 最多喜歡 | `likes` | 依喜歡數從高到低 |
| 最多收藏 | `follow_num` | 依收藏數從高到低 |
| 最近更新 | `modified` | 依最近更新時間 |
| 隨機 | `rand` | 隨機順序 |

## 使用範例

- 抓取 `Genshin` 最多查看的第 1 到 10 頁：作品填 `Genshin`，起始頁數 `1`，結束頁數 `10`，排序選擇「最多查看」。
- 抓取其他作品：作品填作品名稱的一部分，例如 `Honkai`、`Blue Archive`，再設定頁碼範圍和排序方式。
