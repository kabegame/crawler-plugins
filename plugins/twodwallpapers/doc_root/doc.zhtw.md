# 2dwallpaper 外掛說明

爬取 [2dwallpapers.com](https://2dwallpapers.com) 站點的壁紙。建立任務時需選擇**大目錄**、填寫**小目錄關鍵字**（可選）並選擇**排序方式**。

## 大目錄

大目錄對應站點的一級分類，決定從哪一類壁紙開始爬取。

| 介面名稱 | 說明 |
|----------|------|
| 動漫壁紙 | `anime-wallpapers` |
| 遊戲壁紙 | `game-wallpapers`（如原神、崩壞等） |
| 未分類 | `uncategorized` |

選擇後，爬蟲會先開啟該大目錄的列表頁，再依「小目錄關鍵字」篩選子分類。

![cate](./images/cate.png)

## 小目錄（子目錄關鍵字）

大目錄頁會列出多個**子分類**（如 Genshin、崩壞、鳴潮等），小目錄透過**關鍵字**篩選要爬取的子分類。

- **填寫關鍵字**：只爬取名稱符合的子目錄（正則）。例如 `Genshin` 只爬 Genshin；`Genshin|Honkai` 可匹配多個。
- **留空**：不依名稱篩選，會從腳本邏輯上的第一個子分類開始爬。

**範例**：大目錄選「遊戲壁紙」、子目錄關鍵字填 `Genshin`，即只爬「遊戲壁紙 → Genshin」。

![scate](./images/scate.png)

## 排序方式

列表排序由 **orderby** 參數控制。

| 介面名稱 | 對應網站 | 說明 |
|----------|----------|------|
| 最新 | `Newest` | 按發布時間 |
| 最多查看 | `Popularity` | 按瀏覽量 |
| 最多喜歡 | `Likex` | 按喜歡數 |
| 最多收藏 | `Favorites` | 按收藏數 |
| 最近更新 | `Update` | 按最近更新 |
| 隨機 | `Random` | 隨機 |

## 其他參數

- **爬取總數**：本任務最多下載張數（1～1000）。

## 使用範例

- 爬「遊戲壁紙 → Genshin」按「最多查看」前 100 張：大目錄選「遊戲壁紙」，子目錄關鍵字 `Genshin`，排序「最多查看」，爬取總數 100。
- 爬「動漫壁紙」下某子類最新圖：大目錄選「動漫壁紙」，子目錄關鍵字填該子類名稱或部分關鍵字，排序選「最新」，再設爬取總數。
