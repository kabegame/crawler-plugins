# 2dwallpaper プラグイン説明

[2dwallpapers.com](https://2dwallpapers.com) から壁紙を取得します。タスクでは **作品**、**開始ページ**、**終了ページ**、**並び順**を指定します。

## 作品

作品はサイトのカテゴリページにある具体的な作品項目です。例：`Genshin Impact`。プラグインはゲーム、アニメ、未分類の各カテゴリから最初に一致した作品を探し、その作品のページ付きリストだけを取得します。

- 既定値：`Genshin`
- マッチ方法：作品名またはリンクに対する正規表現。例：`Genshin` は `Genshin Impact` に一致します
- ページ番号は作品リストごとのものなので、一度に 1 作品を指定するのがおすすめです

赤枠部分が作品入口です。

![work-entry](./images/work-entry.png)

## ページ範囲

`start_page` と `end_page` で取得する作品リストのページ範囲を指定します。1 ページ目は作品リスト URL そのもの、2 ページ目以降は `/page/{ページ番号}` を使います。

プラグインはサイトのページネーションから総ページ数を読み取り、総ページ数、要求範囲、スキップしたページ数、実際の処理範囲、各ページの `現在/総数` をログに出します。

赤枠部分が作品リストのページネーションです。

![work-pagination](./images/work-pagination.png)

## 並び順

**orderby** はリストの並び順と取得順を制御します。

| 表示名 | パラメータ | 説明 |
|--------|------------|------|
| 最新 | `date` | 新しい順 |
| 最多閲覧 | `views` | 閲覧数順 |
| 最多いいね | `likes` | いいね数順 |
| 最多お気に入り | `follow_num` | お気に入り数順 |
| 最近更新 | `modified` | 更新順 |
| ランダム | `rand` | ランダム |

## 使用例

- `Genshin` の最多閲覧 1〜10 ページを取得：作品に `Genshin`、開始ページ `1`、終了ページ `10`、並び順「最多閲覧」を指定します。
- 他の作品を取得：`Honkai` や `Blue Archive` など作品名の一部を入力し、ページ範囲と並び順を設定します。
