# 2dwallpaper プラグイン説明

[2dwallpapers.com](https://2dwallpapers.com) から壁紙を取得します。タスク作成時に**大カテゴリ**を選択し、**小カテゴリキーワード**（任意）と**並び順**を指定します。

## 大カテゴリ

サイトのトップレベル分類に対応します。

| 表示名 | 説明 |
|--------|------|
| アニメ壁紙 | `anime-wallpapers` |
| ゲーム壁紙 | `game-wallpapers`（原神、崩壊など） |
| 未分類 | `uncategorized` |

選択後、そのカテゴリのリスト頁を開き、「小カテゴリキーワード」でサブカテゴリを絞り込みます。

![cate](./images/cate.png)

## 小カテゴリ（キーワード）

大カテゴリ頁には複数の**サブカテゴリ**（Genshin、崩壊、鳴潮など）があります。キーワードで取得するサブカテゴリを指定します。

- **キーワードを指定**：名前にマッチするサブカテゴリのみ（正規表現）。例：`Genshin` で Genshin のみ、`Genshin|Honkai` で複数。
- **空欄**：名前で絞り込まない。スクリプト上の最初のサブカテゴリから取得。

**例**：大カテゴリ「ゲーム壁紙」、キーワード `Genshin` → 「ゲーム壁紙 → Genshin」のみ取得。

![scate](./images/scate.png)

## 並び順

リストの並び順（**orderby**）で取得順が変わります。

| 表示名 | サイト値 | 説明 |
|--------|----------|------|
| 最新 | `Newest` | 公開日時 |
| 最多閲覧 | `Popularity` | 閲覧数 |
| 最多いいね | `Likex` | いいね数 |
| 最多お気に入り | `Favorites` | お気に入り数 |
| 最近更新 | `Update` | 更新日時 |
| ランダム | `Random` | ランダム |

## その他

- **取得総数**：1タスクあたりの最大ダウンロード数（1～1000）。

## 使用例

- 「ゲーム壁紙 → Genshin」を「最多閲覧」で100枚：大カテゴリ「ゲーム壁紙」、キーワード `Genshin`、並び順「最多閲覧」、取得総数 100。
- 「アニメ壁紙」の某サブカテゴリの最新：大カテゴリ「アニメ壁紙」、キーワードにサブカテゴリ名（の一部）、並び順「最新」、取得総数を設定。
