# 蓝色大肥鱼 AI 娘档案

从[蓝色大肥鱼 AI 娘二创开放档案](https://xn--pssy23gqgbz2d718b.com/)收集原图。

- 归档 JSON 一次返回全部作品，插件在本地按写死的角色、类型和排序选项筛选，不做分页请求。
- “热度”和“下载量”分别使用源站公开统计快照里的浏览量和原图按钮点击量；统计不可用时回退到归档顺序。
- 角色与普通 Tag 会写入标签画册。角色 key 使用模型英文 ID；中文 Tag 使用 `tiny-pinyin` 生成稳定 key。
- 作品类型只写入 metadata，并通过插件 Provider 的固定列表筛选，不建立类型标签画册。
- 每张图都带源站详情 metadata、搜索文本和详情模板。

默认配置会拉取归档里的全部作品；需要缩小范围时请选择具体角色或类型。
