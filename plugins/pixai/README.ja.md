# PixAI

[PixAI](https://pixai.art) で公開されている AI 画像とうごイラを一括ダウンロードし、Kabegame のギャラリーへ
保存します。全サイト、モデル別、タグ別、ランキング、作者別の5種類の取得モードに対応しています。

![PixAI ホームページの作品フィード](banners/homepage.jpg)

## クイックスタート

1. Kabegame のネットワークまたはプロキシから `pixai.art` と画像配信ドメインへ接続できることを確認します。
2. ダウンロードタスクを新規作成し、ソースに「PixAI」を選択します。プラグイン付属のおすすめ設定を
   インポートして始めることもできます。
3. 「取得種類」を選び、並び順とページを設定します。少量で試す場合は「全サイト」と「トレンド」を選び、
   「開始ページ / 終了ページ」を `1 / 1` にしてください。通常、1ページには約24作品があります。
4. タスクを開始します。プラグインが各作品の詳細を取得し、公開されているメディアをギャラリーへ保存します。

## ダウンロードされる内容

PixAI の作品ページには画像のほか、タイトル、作者、プロンプト、説明、タグ、使用モデルと LoRA、
いいね数、コメントなどが含まれる場合があります。

![PixAI の作品詳細、プロンプト、モデル情報](banners/post.jpg)

ダウンロード時に作品の詳細と最近のコメントを補完し、PixAI の元作品へのリンクも保存します。うごイラでは
動的メディアを優先し、静止画では公開画像を使用します。保存後は Kabegame で結果を閲覧し、詳細画面から
元の作品ページへ戻れます。

![Kabegame のギャラリーへダウンロードした PixAI 作品](banners/images.jpg)

## 取得モード

### 全サイト

PixAI の全サイト作品フィードからダウンロードします。人気作品の閲覧やギャラリーの継続的な更新に適しています。

- 「作品並び順」は、トレンド、日間ランキング、人気、最新、作成時間などに対応します。
- 「開始ページ / 終了ページ」で、終了ページを含むダウンロード範囲を指定します。
- たとえば `1 / 5` は1～5ページ目をダウンロードします。`3 / 5` は最初の2ページを進めるだけで、
  3～5ページ目のみをダウンロードします。

### モデル別

「モデル並び順」に従ってモデル一覧を巡回し、各モデルの作品フィードをダウンロードします。

- 「モデルページ数」は1ページ目から数えた上限です。「スキップするモデルページ数」はページを進めるだけで、
  そこに含まれるモデルを処理しません。
- 「モデルごとの作品ページ数」は各モデルでアクセスする最終ページを制限し、「開始ページ」はその作品フィードで
  ダウンロードを始めるページを指定します。
- 「作品並び順」はモデルごとの作品フィードへ個別に適用されます。

このモードではダウンロード数が急増します。通常、モデル一覧の1ページには約24モデルがあり、各モデルの作品ページにも
約24作品があります。最初は「モデルページ数」と「モデルごとの作品ページ数」を小さくして試してください。

### タグ別

「タグ codeName」を順番に解決し、各タグの作品をダウンロードします。

- codeName は画面に表示されるタグ名ではなく、タグページ URL に含まれる識別子です。例：`genshin_impact`。
- 複数の codeName を一度に入力できます。無効または存在しないタグは通知してスキップします。
- 「タグごとのページ数」はページ上限で、「開始ページ」はダウンロードを始めるページです。
- たとえば開始ページが `3`、タグごとのページ数が `5` の場合、3～5ページ目をダウンロードします。
  3～7ページ目ではありません。

解決したタグはキャッシュされるため、以後の実行では同じタグを再問い合わせする必要がありません。

### ランキング

「ランキング種類」と「ランキング期間」で選択した PixAI ランキングを取得します。

| ランキング種類 | 動作 |
| --- | --- |
| 作品 | 日間、週間、月間ランキングの静止画をダウンロード。先頭から最大100件を要求 |
| うごイラ | 日間、週間、月間ランキングのうごイラをダウンロード。先頭から最大100件を要求 |
| SDモデル | ランクインした SD モデルを巡回し、各モデルのトレンド作品をダウンロード |
| LoRA | ランクインした LoRA を巡回し、各 LoRA のトレンド作品をダウンロード |

作品とうごイラのランキング自体にはページがないため、「開始ページ / 終了ページ」は適用されません。モデルと LoRA の
ランキングはそれぞれ最大100モデルを返し、さらに各モデルで「ランクインモデルごとの作品ページ数」に指定したページ数を
ダウンロードする場合があります。ダウンロード数が非常に多くなることがあります。

### 作者別

指定した PixAI 作者の画像またはうごイラをダウンロードします。

- 「作者 ID」には、ユーザーページ URL 内の数字 ID を入力します。表示名や `@username` ではありません。
- 「取得タイプ」で画像またはうごイラを選択します。画像モードには通常作品とアルバムが含まれます。
- 「作者ごとのページ数」はページ上限です。「開始ページ」と「作品並び順」を組み合わせて範囲を絞れます。

## ページ指定の規則

PixAI の作品一覧はカーソルページングを使用しているため、任意のページへ直接移動できません。N ページ目から始める場合でも、
カーソルを取得するために1～N−1ページ目を順番に要求しますが、そのページの作品はダウンロードしません。この処理には
少量の時間と通信が必要です。

- ページ番号は `1` から始まります。
- 全サイトモードでは「終了ページ」を最終ページとして使用します。
- モデル、タグ、作者モードでは、それぞれの作品ページ数を最終ページの上限として使用します。
- モデル別では「スキップするモデルページ数」はモデル一覧だけに適用され、「開始ページ」は各モデルの作品一覧に適用されます。
- 作品とうごイラのランキングでは、作品ページ設定を使用しません。

終了ページが開始ページより前の場合、全サイトモードは警告を表示して開始ページだけをダウンロードします。他のモードでは、
開始ページが対応するページ上限より大きいと有効なダウンロードページがなくなるため、設定を変更して再実行してください。

## おすすめ設定

プラグインには次の設定が付属しています。そのままインポートして実行するか、内容を変更して利用できます。

| 設定 | 用途 |
| --- | --- |
| 全サイトトレンド（5ページ） | 人気の公開作品をすばやく閲覧 |
| 毎日・全サイト日間ランキング（5ページ） | デフォルトで毎日 18:00 に実行し、ギャラリーを継続的に更新 |
| トレンドモデル（モデルごと1ページ） | トレンドモデルと代表作を取得。ダウンロード数は多め |
| ランキング・本日の作品 | 当日の作品ランキングをダウンロード |
| タグ例（原神・スタレ・ステラソラ） | 1つの設定で複数のタグ codeName を指定する例 |

おすすめ設定のページ数とスケジュールは、インポート後の実行設定で変更できます。

## 注意事項

- 現在のネットワークから公開アクセスできるメディアだけをダウンロードします。削除済み、非公開、または詳細を取得できない
  作品はスキップします。
- 全サイト、タグ、モデル、ランキングモードではセーフコンテンツフィルターを有効にします。作者モードは PixAI の作者フィードが
  返すデフォルトのフィルター結果を使用します。
- 同じ作品が複数のタグ、モデル、ランキングに含まれる場合があります。複数の範囲を組み合わせるときは、重複と総ダウンロード量に
  注意してください。
- PixAI API または画像ドメインへ接続できない場合は、まずプロキシとネットワークを確認してください。タグモードで結果がない場合は、
  codeName が URL と完全に一致するかも確認してください。
- PixAI の利用規約と各作品の作者が定めた利用許諾に従ってください。
