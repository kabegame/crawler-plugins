# PixAI 更新日志

## 0.6.0

- 下载新作品时把 PixAI tags 与作者写入应用标签，分别位于 `pixai/tag`、`pixai/artist`；升级后通过 `provideLabels` 为历史图片补齐。
- 画廊插件扩展移除旧 tag provider，改为按喜欢数与评论数提供累计 `N+` 分段，并支持 `N-M`、`N+`、`-N` 区间路径。
- 最低应用版本提升至 `4.5.0`。

## 0.5.0

- 支持全站作品流、按模型、按标签、排行榜和按作者五种爬取模式，可分别配置排序、起始页与分页上限。
- 支持静态图片与动态作品下载；入库时补充标题、作者、提示词、说明、标签、模型与 LoRA、点赞数、最近评论及 PixAI 原始链接。
- 标签 codeName 支持批量解析与本地缓存；模型、标签和作者作品流支持游标翻页与跳过前置页面。
- 新增全站趋势、每日全站日榜、趋势模型、今日作品榜和多标签示例五组推荐配置。
- 重写中文使用文档，新增英语、日语、韩语与繁体中文翻译，并加入首页、作品详情与下载结果横幅。
