# PixAI

[PixAI](https://pixai.art)에 공개된 AI 이미지와 움직이는 일러스트를 일괄 다운로드하여 Kabegame 갤러리에
저장합니다. 전체 작품, 모델별, 태그별, 랭킹, 작가별의 다섯 가지 크롤링 방식을 지원합니다.

![PixAI 홈페이지의 작품 피드](banners/homepage.jpg)

## 빠른 시작

1. Kabegame의 네트워크 또는 프록시에서 `pixai.art`와 이미지 도메인에 접속할 수 있는지 확인합니다.
2. 새 다운로드 작업을 만들고 소스로 「PixAI」를 선택합니다. 플러그인에 포함된 추천 설정을 가져와 시작해도 됩니다.
3. 「크롤링 유형」을 선택한 뒤 정렬과 페이지를 설정합니다. 소량으로 시험하려면 「전체」와 「트렌딩」을 선택하고
   「시작 페이지 / 끝 페이지」를 `1 / 1`로 설정하세요. 한 페이지에는 보통 작품이 약 24개 있습니다.
4. 작업을 시작합니다. 플러그인이 각 작품의 상세 정보를 읽고 공개적으로 접근 가능한 미디어를 갤러리에 저장합니다.

## 다운로드되는 내용

PixAI 작품 페이지에는 이미지뿐 아니라 제목, 작가, 프롬프트, 설명, 태그, 사용 모델과 LoRA, 좋아요 수,
댓글 등의 정보가 포함될 수 있습니다.

![PixAI 작품 상세 정보, 프롬프트, 모델 정보](banners/post.jpg)

다운로드할 때 각 작품의 상세 정보와 최근 댓글을 추가로 가져오고 PixAI 원본 작품 링크도 저장합니다. 움직이는
일러스트는 동적 미디어를 우선하며, 정지 이미지는 공개 이미지 리소스를 사용합니다. 저장한 뒤에는 Kabegame에서
결과를 둘러보고 상세 화면에서 원본 페이지로 돌아갈 수 있습니다.

![Kabegame 갤러리에 다운로드한 PixAI 작품](banners/images.jpg)

## 크롤링 모드

### 전체

PixAI 전체 작품 피드에서 다운로드합니다. 인기 작품을 둘러보거나 갤러리를 지속해서 채울 때 적합합니다.

- 「작품 정렬」은 트렌딩, 일간 랭킹, 인기순, 최신순, 생성 시간순 등을 지원합니다.
- 「시작 페이지 / 끝 페이지」로 끝 페이지를 포함하는 다운로드 범위를 지정합니다.
- 예를 들어 `1 / 5`는 1～5페이지를 다운로드합니다. `3 / 5`는 앞의 두 페이지에서 커서만 가져오고
  3～5페이지만 다운로드합니다.

### 모델별

「모델 정렬」에 따라 모델 목록을 탐색한 뒤 각 모델의 작품 피드를 다운로드합니다.

- 「모델 페이지 수」는 1페이지부터 센 상한입니다. 「건너뛸 모델 페이지 수」는 페이지 커서만 가져오고 그 안의
  모델을 처리하지 않습니다.
- 「모델당 작품 페이지 수」는 각 모델에서 접근할 마지막 페이지를 제한하며, 「시작 페이지」는 각 작품 피드에서
  다운로드를 시작할 페이지를 정합니다.
- 「작품 정렬」은 모델별 작품 피드에 각각 적용됩니다.

이 모드는 다운로드 수가 빠르게 늘어납니다. 모델 목록 한 페이지에는 보통 약 24개 모델이 있고, 각 모델의 작품
페이지에도 보통 약 24개 작품이 있습니다. 처음에는 「모델 페이지 수」와 「모델당 작품 페이지 수」를 작게 설정하세요.

### 태그별

「태그 codeName」을 순서대로 해석한 뒤 각 태그의 작품을 다운로드합니다.

- codeName은 화면에 표시되는 태그 이름이 아니라 태그 페이지 URL에 포함된 식별자입니다. 예: `genshin_impact`.
- codeName을 여러 개 입력할 수 있습니다. 잘못되었거나 존재하지 않는 태그는 안내 후 건너뜁니다.
- 「태그당 페이지 수」는 페이지 상한이고, 「시작 페이지」는 다운로드를 시작할 페이지입니다.
- 예를 들어 시작 페이지가 `3`, 태그당 페이지 수가 `5`라면 3～5페이지를 다운로드합니다. 3～7페이지가 아닙니다.

해석된 태그는 캐시되므로 다음 실행부터 같은 태그를 다시 조회할 필요가 없습니다.

### 랭킹

「랭킹 유형」과 「랭킹 기간」으로 선택한 PixAI 랭킹을 다운로드합니다.

| 랭킹 유형 | 동작 |
| --- | --- |
| 작품 | 일간, 주간, 월간 랭킹의 정지 작품을 다운로드하며 상위 최대 100개 항목을 요청 |
| 움직이는 일러스트 | 일간, 주간, 월간 랭킹의 동적 작품을 다운로드하며 상위 최대 100개 항목을 요청 |
| SD 모델 | 랭킹에 오른 SD 모델을 탐색한 뒤 각 모델의 트렌딩 작품을 다운로드 |
| LoRA | 랭킹에 오른 LoRA를 탐색한 뒤 각 LoRA의 트렌딩 작품을 다운로드 |

작품 및 움직이는 일러스트 랭킹 자체에는 페이지가 없으므로 「시작 페이지 / 끝 페이지」가 적용되지 않습니다. 모델과
LoRA 랭킹은 각각 최대 100개 모델을 반환하고, 다시 모든 모델에서 「랭킹 모델당 작품 페이지 수」로 지정한 페이지를
다운로드할 수 있습니다. 다운로드 양이 매우 커질 수 있습니다.

### 작가별

지정한 PixAI 작가의 이미지 또는 움직이는 일러스트를 다운로드합니다.

- 「작가 ID」에는 사용자 프로필 URL 안의 숫자 ID를 입력합니다. 표시 이름이나 `@username`이 아닙니다.
- 「작품 유형」에서 이미지 또는 움직이는 일러스트를 선택합니다. 이미지 모드에는 일반 작품과 앨범이 포함됩니다.
- 「작가당 페이지 수」는 페이지 상한이며 「시작 페이지」 및 「작품 정렬」과 함께 범위를 좁힐 수 있습니다.

## 페이지 규칙

PixAI 작품 목록은 커서 페이지네이션을 사용하므로 원하는 페이지로 바로 이동할 수 없습니다. N페이지부터 시작할 때도
커서를 얻기 위해 1～N−1페이지를 순서대로 요청하지만 해당 페이지의 작품은 다운로드하지 않습니다. 이 과정에는 약간의
시간과 네트워크 요청이 필요합니다.

- 페이지 번호는 `1`부터 시작합니다.
- 전체 모드는 「끝 페이지」를 마지막 페이지로 사용합니다.
- 모델, 태그, 작가 모드는 각각의 작품 페이지 수를 마지막 페이지 상한으로 사용합니다.
- 모델별 모드에서 「건너뛸 모델 페이지 수」는 모델 목록에만 적용되고, 「시작 페이지」는 각 모델의 작품 목록에 적용됩니다.
- 작품 및 움직이는 일러스트 랭킹은 작품 페이지 설정을 사용하지 않습니다.

끝 페이지가 시작 페이지보다 앞서면 전체 모드는 경고를 표시하고 시작 페이지만 다운로드합니다. 다른 모드에서 시작 페이지가
해당 페이지 상한보다 크면 실제로 다운로드할 페이지가 없으므로 설정을 조정한 뒤 다시 실행하세요.

## 추천 설정

플러그인에는 다음 설정이 포함되어 있습니다. 그대로 가져와 실행하거나 먼저 수정할 수 있습니다.

| 설정 | 용도 |
| --- | --- |
| 전체 트렌드(5페이지) | 인기 공개 작품을 빠르게 둘러보기 |
| 매일 전체 일간 랭킹(5페이지) | 기본으로 매일 18:00에 실행하여 갤러리를 지속적으로 갱신 |
| 트렌드 모델(모델당 작품 1페이지) | 트렌드 모델과 대표작을 탐색하며 다운로드 양이 많음 |
| 랭킹 · 오늘의 작품 | 오늘의 작품 랭킹 다운로드 |
| 태그 예시(원신·스타레일·스텔라 소라) | 하나의 설정에 여러 태그 codeName을 넣는 방법을 보여 줌 |

추천 설정의 페이지 수와 스케줄은 가져온 뒤 실행 설정에서 변경할 수 있습니다.

## 주의사항

- 현재 네트워크에서 공개적으로 접근할 수 있는 미디어만 다운로드합니다. 삭제되었거나 비공개인 작품, 상세 정보를 가져올 수
  없는 작품은 건너뜁니다.
- 전체, 태그, 모델, 랭킹 모드는 안전 콘텐츠 필터를 사용합니다. 작가별 모드는 PixAI 작가 피드가 반환하는 기본 필터 결과를
  사용합니다.
- 같은 작품이 여러 태그, 모델 또는 랭킹에 나타날 수 있습니다. 여러 범위를 조합할 때는 중복 콘텐츠와 전체 다운로드 양을
  확인하세요.
- PixAI API나 이미지 도메인에 접속할 수 없다면 프록시와 네트워크를 먼저 확인하세요. 태그별 모드에 결과가 없다면 codeName이
  URL과 정확히 일치하는지도 확인하세요.
- PixAI 이용 약관과 각 작품의 창작자가 정한 사용 허가 범위를 준수하세요.
