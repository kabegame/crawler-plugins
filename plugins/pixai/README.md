# PixAI

从 [PixAI](https://pixai.art) 批量下载公开的 AI 图片与动态作品，并保存到 Kabegame 画廊。
支持全站作品流、模型、标签、排行榜和作者五种爬取方式。

![PixAI 首页作品流](banners/homepage.jpg)

## 快速开始

1. 确保 Kabegame 的网络或代理可以正常访问 `pixai.art` 及其图片域名。
2. 新建下载任务并选择来源「PixAI」。初次使用也可以直接导入插件提供的推荐配置。
3. 选择「爬取种类」，再设置排序和页码。想先少量试跑，可以选择「全站」、趋势排序，
   将「起始页数 / 结束页数」设为 `1 / 1`；每页通常约有 24 个作品。
4. 启动任务。插件会读取作品详情并将可公开访问的媒体保存到画廊。

## 下载内容

PixAI 的作品页除了图片，还可能包含标题、作者、提示词、说明、标签、所用模型与 LoRA、
点赞数和评论等信息。

![PixAI 作品详情、提示词与模型信息](banners/post.jpg)

下载时，插件会为每个作品补充详情与最近的评论，并保存 PixAI 原始作品链接。动态作品会优先使用
动态媒体资源；静态作品使用公开图片资源。入库后可在 Kabegame 中浏览下载结果，并从详情返回原页面。

## 爬取模式

### 全站

按 PixAI 的全站作品流下载，适合浏览热门作品或持续补充图库。

- 「作品排序」支持趋势、日榜、人气、最新与创建时间等顺序。
- 「起始页数 / 结束页数」指定下载范围，结束页包含在内。
- 例如 `1 / 5` 表示下载第 1～5 页；`3 / 5` 表示先翻过前两页，只下载第 3～5 页。

### 按模型

先按「模型排序」遍历模型列表，再下载每个模型对应的作品流。

- 「模型分页数」是从第一页算起的模型页上限；「跳过模型页数」只翻页、不处理其中的模型。
- 「每个模型作品分页数」限制每个模型访问到第几页，「起始页数」决定从其中第几页开始下载。
- 「作品排序」分别应用于每个模型的作品流。

此模式的下载量会快速放大：一个模型页通常约有 24 个模型，每个模型的一个作品页又通常约有
24 个作品。请先使用较小的「模型分页数」和「每个模型作品分页数」试跑。

### 按标签

依次解析「标签 codeName」，再下载每个标签下的作品。

- codeName 不是页面显示名称，而是标签页 URL 中的标识，例如 `genshin_impact`。
- 可以一次输入多个 codeName；无效或不存在的标签会给出提示并跳过。
- 「每个标签作品分页数」是页码上限，「起始页数」决定从第几页开始下载。
- 例如起始页为 `3`、分页数为 `5` 时，实际下载第 3～5 页，而不是第 3～7 页。

标签解析结果会被缓存，之后再次运行相同标签时无需重复查询。

### 排行榜

按榜单类型和范围抓取 PixAI 排行榜。

| 榜单类型 | 行为 |
| --- | --- |
| 作品 | 下载日榜、周榜或月榜中的静态作品，最多请求榜单前 100 项 |
| うごイラ（动图） | 下载日榜、周榜或月榜中的动态作品，最多请求榜单前 100 项 |
| SD 模型 | 遍历榜单中的 SD 模型，再下载每个模型的趋势作品 |
| LoRA | 遍历榜单中的 LoRA，再下载每个 LoRA 的趋势作品 |

作品榜与动图榜本身不分页，因此「起始页数 / 结束页数」对它们不生效。模型榜和 LoRA 榜可能各返回
最多 100 个模型，再对每个模型下载「每个上榜模型作品分页数」指定的页数，下载量可能非常大。

### 按作者

下载指定 PixAI 作者的图片或动态作品。

- 「作者 ID」填写用户主页 URL 中的纯数字 ID，不是显示名称或 `@username`。
- 「爬取类型」选择图片或动图；图片模式包含普通作品与图集。
- 「作者作品分页数」是页码上限，可配合「起始页数」和「作品排序」缩小范围。

## 页码规则

PixAI 的作品列表使用游标分页，无法直接跳到任意页。因此从第 N 页开始时，插件仍需依次请求前
N−1 页来取得游标，只是不下载这些页面。这会消耗少量时间和网络请求。

- 页码从 `1` 开始。
- 全站模式使用「结束页数」作为末页。
- 模型、标签和作者模式使用各自的「作品分页数」作为末页上限。
- 按模型时，「跳过模型页数」只作用于模型列表；「起始页数」作用于每个模型的作品列表。
- 排行榜作品榜和动图榜不使用作品页码设置。

如果末页早于起始页，全站模式会给出警告并只下载起始页。其他模式中，起始页高于对应分页上限时
不会产生有效下载页，请调整配置后重试。

## 推荐配置

插件附带以下配置，可直接导入后运行或继续修改：

| 配置 | 用途 |
| --- | --- |
| 全站趋势（前 5 页） | 快速浏览热门公开作品 |
| 每日全站日榜（前 5 页） | 默认每天 18:00 执行，适合持续更新图库 |
| 趋势模型（每模型 1 页作品） | 遍历趋势模型并下载代表作，下载量较大 |
| 排行榜 · 今日作品 | 下载当天作品榜 |
| 标签示例（原神 / 星铁 / 星原） | 演示一次配置多个标签 codeName |

推荐配置中的页数与定时计划都可以在导入后的运行配置中修改。

## 注意事项

- 插件只下载当前网络环境下可公开访问的媒体；作品被删除、设为私密或详情接口失败时会跳过。
- 全站、标签、模型与排行榜模式会启用安全内容过滤；按作者模式采用 PixAI 作者流的默认过滤结果。
- 同一作品可能同时出现在多个标签、模型或榜单中。组合多个范围时请留意重复内容与总下载量。
- PixAI 接口或图片域名访问失败时，先检查代理与网络；标签模式无结果时再确认 codeName 是否与 URL 完全一致。
- 请遵守 PixAI 的使用规则与作品作者设定的授权范围。
