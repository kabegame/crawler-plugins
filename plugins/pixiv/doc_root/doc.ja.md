# Pixiv クローラー - プラグイン説明

このプラグインは Pixiv からイラストを取得します。ランキング、ブックマーク、作家作品、キーワード検索の4モードに対応しています。

## HTTP ヘッダー設定（必須）

Pixiv API には認証と Referer が必要です。**Cookie は「詳細設定 → HTTP ヘッダー」で設定してください**。プラグイン変数としては注入されません。

### Cookie の取得方法

#### 方法1：ブラウザからコピー

1. ブラウザで [pixiv.net](https://www.pixiv.net) に**ログイン**（未登録の場合は登録）

![home](./images/home.png)

2. 開発者ツール（F12）を開き、ネットワークタブに切り替える（図の赤枠）

![console](./images/console.png)

3. 図の手順で cookie をコピー

![cookie](./images/cookie.png)

4. Kabegame を開く
5. cookie が必要な設定で HTTP ヘッダーを追加

![header](./images/header-config.png)

#### 方法2：Kabegame のサーフページからコピー（より簡単、PC のみ）

1. Kabegame を開き、サーフタブへ

![kabegame-surf](./images/kabegame-surf.png)

2. プラグインクイック入り → Pixiv を選択 → 「サーフ開始」をクリック。Pixiv のウィンドウが開くので、表示に従ってログイン

![surf-pixiv](./images/surf-pixiv.png)

3. ログイン後「サイトの cookie を表示」（ウィンドウは閉じない）をクリックし、表示された cookie をコピー

![cookie-dialog](./images/cookie-dialog.png)

4. 準備完了です。

### ユーザー ID の取得（自分または作家）

Pixiv でそのユーザーのプロフィールを開き、URL の数字部分（中間または末尾）がユーザー ID です。

![user](./images/user.png)

### Cookie が必要な場合

| モード | Cookie |
|--------|--------|
| ランキング（非 R18） | 任意 |
| ランキング（R18） | 必須 |
| ブックマーク | 必須 |
| 作家作品（非 R18） | 任意 |
| 作家作品（R18） | 必須 |
| キーワード検索（非 R18） | 任意 |
| キーワード検索（R18） | 必須 |

## クロールタイプ

- **ランキング**：日/週/月ランキングで指定日の作品を取得
- **ブックマーク**：公開ブックマークを取得
- **作家作品**：指定作家の公開作品を取得
- **キーワード検索**：キーワードで検索して取得

## 設定項目

選択したモードで表示項目が変わります：

- **ランキング**：ランキング種別、コンテンツ種別、開始日（YYYYMMDD）、日付範囲、最大取得数
- **ブックマーク**：ユーザー UID、最大取得数
- **作家**：ユーザー UID、作家 UID、最大取得数
- **キーワード**：検索キーワード、検索モード（セーフ／R18／すべて）、並び順（日付／人気）、最大取得数。**うまく使うと欲しいものだけ取得できます**

## 注意事項

- 403 が出た場合は cookie を再取得してみてください。たまにだけならレート制限の可能性があります。何度か実行するか、サーフページから手動でダウンロードしてください。
- Cookie の有効期限切れ後は再取得が必要です
- キーワードは高度な検索構文に対応（例：`(Lucy OR 边缘行者) AND 5000users`）
- **人気順**は Pixiv Premium が必要です。Premium でない場合は「日付順」を使ってください
- 最大取得数は適切に設定し、Pixiv への負荷を抑えてください
