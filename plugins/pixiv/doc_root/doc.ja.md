# Pixiv クローラー - プラグイン説明

このプラグインは Pixiv からイラストを取得します。ランキング、ブックマーク、作家作品、キーワード検索の4モードに対応しています。

## HTTP ヘッダー設定（必須）

Pixiv API には認証と Referer が必要です。**Cookie は「詳細設定 → HTTP ヘッダー」で設定してください**。プラグイン変数としては注入されません。

### Cookie の取得方法

#### 方法1：ブラウザからコピー

1. ブラウザで [pixiv.net](https://www.pixiv.net) に**ログイン**（未登録の場合は登録）

![home](./images/home.png)

2. 開発者ツール（F12）を開き、ネットワークタブに切り替える（図の赤枠）

![console](./images/console.png)

3. 図の手順で cookie をコピー

![cookie](./images/cookie.png)

4. Kabegame を開く
5. cookie が必要な設定で HTTP ヘッダーを追加

![header](./images/header-config.png)

#### 方法2：Kabegame のサーフページからコピー（より簡単、PC のみ）

1. Kabegame を開き、サーフタブへ

![kabegame-surf](./images/kabegame-surf.png)

2. プラグインクイック入り → Pixiv を選択 → 「サーフ開始」をクリック。Pixiv のウィンドウが開くので、表示に従ってログイン

![surf-pixiv](./images/surf-pixiv.png)

3. ログイン後「サイトの cookie を表示」（ウィンドウは閉じない）をクリックし、表示された cookie をコピー

![cookie-dialog](./images/cookie-dialog.png)

4. 準備完了です。

### ユーザー ID の取得（自分または作家）

Pixiv でそのユーザーのプロフィールを開き、URL の数字部分（中間または末尾）がユーザー ID です。

![user](./images/user.png)

### Cookie が必要な場合

| モード | Cookie |
|--------|--------|
| ランキング（非 R18） | 任意 |
| ランキング（R18） | 必須 |
| ブックマーク | 必須 |
| 作家作品（非 R18） | 任意 |
| 作家作品（R18） | 必須 |
| キーワード検索（非 R18） | 任意 |
| キーワード検索（R18） | 必須 |

## クロールタイプ

- **ランキング**：日/週/月ランキングで指定日の作品を取得
- **ブックマーク**：公開ブックマークを取得
- **作家作品**：指定作家の公開作品を取得
- **キーワード検索**：キーワードで検索して取得

## 設定項目

選択したモードで表示項目が変わります：

- **ランキング**：ランキング種別、コンテンツ種別、開始日、終了日（両端含む。カレンダー選択、タスク変数は `YYYYMMDD`）
- **ブックマーク**：ユーザー UID
- **作家**：ユーザー UID、作家 UID
- **キーワード**：検索キーワード、検索モード（セーフ／R18／すべて）、並び順（日付／人気）。**うまく使うと欲しいものだけ取得できます**

## 最大作品数（`num_artworks`）

**1～1000** の整数で、**4 モードすべて**で使います。数え方は**作品（1 エントリ）**で、保存ファイル数は**複数ページ作品**のためこれを超えうります。

スクリプトは**ストリーミング**です。一覧 API を**ページごと**に取り、各 `illust_id` ごとにすぐ `ajax/illust/{id}/pages` → 原画ダウンロード。`num_artworks` に達したら**打ち切り**、先に必要ページ数を算出して一覧だけ先取りしません（空ページの **404** を避けるため）。

### ざっくりした挙動

1. **ランキング**　日付順に `p=1` から JSON。`contents` の各 ID を**ダウンロードしてから**カウント。失敗（**404** など）でその日のページ送り終了、翌日へ。`contents` が 50 未満ならその日は最終ページ扱い。
2. **ブックマーク**　`limit=48` で 1 ページ取得し、そのページの作品を**すぐ**ダウンロード。上限または末尾まで。
3. **作家**　`profile/all` は**1 回**（ページ分割なし）。キー順に**ダウンロードしながら** `num_artworks` で停止。
4. **キーワード**　検索 `p=1,2,…` でランキングと同様にストリーミング。

## 設定と実行例（スクリプトの流れ）

Cookie・モードはフォームに従います。日付は **`YYYYMMDD`**（ハイフンなし）。

### 例 A：ランキング（ストリーミング・日付ループ）

| 項目 | 例 |
|------|-----|
| 取得元 | ランキング |
| ランキング種別 | 日間（`daily`） |
| コンテンツ | すべて（`all`） |
| 開始日／終了日 | 例：`20240101`～`20240102` |
| 最大作品数 | `120` |

各日、`ranking.php?...&p={p}&format=json` を `p=1` から。各 `illust_id` について **その作品の** `pages` → `urls.original` を終えてから 1 と数え、**120** でタスク全体終了。`p=k` でエラー（404 含む）ならその日はこれ以上ページなし。旧来の「`num_artworks` からページ数を逆算して一覧だけ先に全部取る」方式は**廃止**。

---

### 例 B：ブックマーク（ページごとに即ダウンロード）

| 項目 | 例 |
|------|-----|
| 取得元 | ブックマーク |
| ユーザー UID | 例：`12345678` |
| 最大作品数 | `50` |

`offset=0` から `limit=48`。`body.works[].id` を**順に** `pages` まで落とし、**50** 作品で停止、または 48 未満で次なし。

---

### 例 C：作家（一覧 1 回、ダウンロードだけ打ち切り）

| 項目 | 例 |
|------|-----|
| 取得元 | 作家 |
| ログイン UID（`x-user-id`） | 自分のアカウント UID |
| 作家 UID | 例：`87654321` |
| 最大作品数 | `5` |

`profile/all` を 1 回、`body.illusts` のキー順で**最大 5 作品**（各作品は複数ファイルになりうる）。

---

### 例 D：キーワード（検索ページ単位のストリーミング）

| 項目 | 例 |
|------|-----|
| 取得元 | キーワード |
| キーワード | 例：`初音ミク` |
| 検索モード | セーフ（`safe`） |
| 並び | 日付（`date_d`） |
| 最大作品数 | `25` |

`ajax/search/artworks/...` を `p=1,2,…`。`illustManga.data` を**取りながら**ダウンロード。**25** 到達、または 1 ページ **60 未満**で終了。

---

4 つの `source` を網羅。R18／週間／月間は URL の意味だけ変わります。**共通：`num_artworks` が作品上限。ページ分割があるモードはストリーミング（まだ足りなければ次の一覧ページのみ取得）。**

## 注意事項

- 403 が出た場合は cookie を再取得してみてください。たまにだけならレート制限の可能性があります。何度か実行するか、サーフページから手動でダウンロードしてください。
- Cookie の有効期限切れ後は再取得が必要です
- キーワードは高度な検索構文に対応（例：`(Lucy OR 边缘行者) AND 5000users`）
- **人気順**は Pixiv Premium が必要です。Premium でない場合は「日付順」を使ってください
- 最大作品数は適切に設定し、Pixiv への負荷を抑えてください
