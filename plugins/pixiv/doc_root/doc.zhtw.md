# Pixiv 爬蟲 - 外掛說明

本外掛用於從 Pixiv 爬取插畫，支援排行榜、個人收藏、畫師作品、關鍵詞搜尋四種模式。

## HTTP 頭設定（必讀）

Pixiv API 需要認證與 Referer。**Cookie 需在「進階設定 → HTTP 頭」中填寫**，不會作為外掛變數注入。

### 如何取得 Cookie

#### 方法一：透過瀏覽器複製

1. 使用瀏覽器**登入（未登入請先註冊）** [pixiv.net](https://www.pixiv.net)

![home](./images/home.png)

2. 開啟開發者工具（F12），切換到網路標籤（圖中紅框處）

![console](./images/console.png)

3. 依下圖步驟複製你的 cookie

![cookie](./images/cookie.png)

4. 開啟 Kabegame
5. 在需要提供 cookie 的設定下，新增 HTTP 頭

![header](./images/header-config.png)

#### 方法二：透過 Kabegame 暢遊頁面複製（較簡單，但需在電腦上）

1. 開啟 Kabegame，進入暢遊分頁

![kabegame-surf](./images/kabegame-surf.png)

2. 從外掛快速進入 → 選擇 Pixiv → 點擊「開始暢遊」，會彈出 Pixiv 首頁視窗，若提示登入請在此登入

![surf-pixiv](./images/surf-pixiv.png)

3. 登入後點擊「檢視網站 cookie」（勿關閉視窗），會彈出視窗，複製即可

![cookie-dialog](./images/cookie-dialog.png)

4. 愉快使用！

### 如何取得使用者 ID（自己或畫師的）

在 P 站開啟該使用者主頁，網址中間或結尾的數字即為使用者 ID。

## 爬取類型

- **排行榜**：依日榜／週榜／月榜下載指定日期的作品
- **個人收藏**：下載你公開收藏的插畫
- **畫師作品**：下載指定畫師的公開作品
- **關鍵詞搜尋**：依關鍵詞搜尋並下載

## 設定項

依選擇模式，表單會顯示不同設定項：

- **排行榜**：排行榜類型、內容類型、起始日期、結束日期（閉區間；日曆選擇，任務變數為 `YYYYMMDD`）
- **收藏**：使用者 UID
- **畫師**：使用者 UID、畫師 UID
- **關鍵詞**：搜尋關鍵詞、搜尋模式（安全／R18／全部）、排序方式（按日期／按人氣）。**善用可精準爬取喜歡的內容**

## 最大作品數（`num_artworks`）

表單欄位為 **1～1000** 的整數，**四種模式都會用到**。計數單位是 **作品（一條插畫／條目）**，不是最終落盤的圖片張數；漫畫等多頁作品仍會依頁下載多張原圖，因此**檔案數可能大於** `num_artworks`。

腳本採用 **流式**：列表介面 **依頁請求**，每解析出一個作品 ID 就立即請求 `ajax/illust/{id}/pages` 並下載原圖；已達到 `num_artworks` 時 **立即停止**，不再預取後續列表頁，從而避免依目標總數反算頁數造成的空頁 **404**。

### 行為概要

1. **排行榜**  
   依日期由早到晚；每天從 `p=1` 起逐頁請求 `ranking.php?...&format=json`。頁內依序處理 `illust_id`，**每處理完一個作品計 1**。若某一頁請求失敗（如 **404**，表示沒有下一頁），則結束**當天**翻頁並進入下一日（若日期區間內仍未滿則繼續）。若本頁 `contents` 少於 50 筆，視為當日最後一頁。

2. **收藏**  
   每頁 `limit=48`，拉一頁後**立刻下載**本頁各作品，直到達到 `num_artworks` 或書籤用盡。

3. **畫師**  
   列表仍依賴 **單次** `profile/all`（介面無分頁）；取得 `body.illusts` 的 key 後 **依序邊下邊數**，滿 `num_artworks` 即停。

4. **關鍵詞**  
   與排行榜類似：`p=1,2,…` 逐頁搜尋，頁內流式下載，滿額或結果不足一頁時結束。

## 設定執行範例（腳本實際流程）

以下說明任務啟動後的順序；URL 中 Cookie、模式等以表單為準。日期變數為 **`YYYYMMDD`**（無橫線）。

### 範例 A：排行榜（流式、依日翻頁）

| 設定項 | 範例值 |
|--------|--------|
| 爬取類型 | 排行榜 |
| 排行榜類型 | 日榜（`daily`） |
| 內容類型 | 全部（`all`） |
| 起始日／結束日 | 例如 `20240101`～`20240102` |
| 最大作品數 | `120` |

**流程**  
對每個曆日：從 `p=1` 請求  
`https://www.pixiv.net/ranking.php?mode=daily&content=all&date=YYYYMMDD&p={p}&format=json`。  
對 `contents` 中每個 `illust_id`：**先下載完該作品**（`pages` → 各 `urls.original`），再計 1；累計達 `120` 則**整個任務**結束。若 `p=k` 報錯（含 404），該日不再加 `p`；若當日已處理完目前頁且未滿 120，則進入下一日。  
**不再**使用「先依 `num_artworks` 算出固定頁數再整批拉列表」的舊邏輯。

---

### 範例 B：個人收藏（分頁拉書籤，邊下邊停）

| 設定項 | 範例值 |
|--------|--------|
| 爬取類型 | 個人收藏 |
| 使用者 UID | 例如 `12345678` |
| 最大作品數 | `50` |

**流程**  
自 `offset=0` 起每頁 `limit=48` 請求書籤介面；對回傳的 `body.works[].id` **逐個**走 `pages` 下載，直到已處理 **50** 個作品或本頁不足 48 筆（無更多書籤）。

---

### 範例 C：畫師作品（全量清單一次，下載流式截斷）

| 設定項 | 範例值 |
|--------|--------|
| 爬取類型 | 畫師作品 |
| 登入使用者 UID（`x-user-id`） | 你的帳號 UID |
| 畫師 UID | 例如 `87654321` |
| 最大作品數 | `5` |

**流程**  
一次請求 `https://www.pixiv.net/ajax/user/87654321/profile/all?lang=zh`，再依 `body.illusts` 的 key 順序 **最多下載 5 個作品**（每個作品仍可能多圖）。

---

### 範例 D：關鍵詞搜尋（依搜尋頁流式）

| 設定項 | 範例值 |
|--------|--------|
| 爬取類型 | 關鍵詞搜尋 |
| 關鍵詞 | 例如 `初音ミク` |
| 搜尋模式 | 安全（`safe`） |
| 排序 | 按日期（`date_d`） |
| 最大作品數 | `25` |

**流程**  
`p=1,2,…` 請求 `ajax/search/artworks/...`；每頁對 `illustManga.data[].id` **邊下邊數**，滿 **25** 或單頁結果少於 60（通常無下一頁）則停。

---

以上四例對應四種 `source`；R18、週榜／月榜等只影響 URL 中的 `mode`／`content`／`date`。**共同點：以 `num_artworks` 為作品數上限，列表可分頁的模式均為流式（僅在仍需更多作品時才請求下一列表頁）。**

## 注意事項

- 若遇 403，可重新取得 cookie。若僅偶發，可能是被限流，多執行幾次任務，或改在暢遊頁面手動下載。
- Cookie 過期後需重新取得
- 關鍵詞支援進階搜尋語法，如 `(Lucy OR 邊緣行者) AND 5000users`
- **按人氣排序**需 Pixiv Premium 帳戶，非 Premium 請使用「按日期」
- 請合理設定最大作品數，避免對 Pixiv 造成過大負擔
