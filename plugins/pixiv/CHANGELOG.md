# Pixiv 更新日志

## 1.3.2

- 作品详情固定使用 `lang=en`，优先取得 Pixiv 提供的英文标签翻译。
- 没有英文翻译时，key 会把平假名、片假名转成罗马字，把 `ー` / `—` 转成 `-`，仅将剩余的
  非 ASCII 字符编码为 `u-...`；标签显示名仍优先保留 Pixiv 默认原始名（通常为日文）。

## 1.3.1

- 修复没有英文翻译的日文标签未写入、以及日文括号标签被错误折叠为公共 key `()` 的问题；现在会从完整
  默认原始名生成唯一且合法的 key，显示名仍严格按默认日文名、英文翻译、key 的顺序回落。

## 1.3.0

- 下载时把作品标签与作者写入应用的「标签」分区：作品标签位于 `pixiv/tag`，作者位于
  `pixiv/artist`；历史下载图片会通过 metadata 迁移自动补齐。
- 作品标签优先使用英文翻译派生稳定 ASCII key；没有英文翻译时从默认原始名生成确定性的合法 key，
  不再丢弃纯日语标签。显示名保留 Pixiv 默认原始名（通常为日语），缺失时回落到英文翻译或 key。
  作者以 Pixiv UID 作 key、用户名作显示名。
- 移除插件自带的标签浏览（已由应用级标签取代），画廊插件扩展改为按喜欢数 `likes`、收藏数
  `bookmarks`、查看数 `views` 筛选；列表提供累计 `N+` 桶，路径段也支持闭区间与单边区间。
- 最低应用版本提升至 `4.4.1`。
