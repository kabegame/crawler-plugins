# Danbooru 画像掲示板 — プラグイン説明

Danbooru（既定は全年齢サイト `donmai.moe`）から作品をダウンロードキューに取り込み、**投稿ページの全タグを画像のメタデータとして保存**します。
タグはカテゴリごとにアプリの「タグ」（`danbooru/<カテゴリ>`）に登録され、アルバム画面での閲覧や検索でのタグ絞り込みに使えます。

## クロールモード

- **タグ**：`/posts?tags=...` によるタグ検索（一番よく使う）
- **人気ランキング**：`/explore/posts/popular` の日間 / 週間 / 月間
- **全部**：`/posts` のサイト全体の新着
- **ID 範囲**：`/posts?tags=id:A..B order:id -status:deleted` で作品 ID の範囲を検索し、範囲全体を ID の昇順で取得

## 設定項目

- **ソースサイト**：`donmai.moe`（既定・全年齢のみ）または `danbooru.donmai.us`（全体）
- **タグ組み合わせ**：リスト入力。実行時に空白で連結し、タグ内の空白は `_` になります
- **人気ランキング期間**：日間 / 週間 / 月間
- **開始ページ / 終了ページ**：1回あたり最大100ページ
- **1ページあたりの件数**：20 / 50 / 100 / 200
- **レーティング絞り込み**：指定なし / 全年齢(General) / センシティブ(Sensitive) / 際どい(Questionable) / 露骨(Explicit)。ソースサイトが全体のときだけ表示されます。全部・タグモードは `rating:g` のようなメタタグを検索文字列に付加し、これは「タグ2個まで」の制限に**数えられません**。人気ランキングモードはプラグインが作品ごとのレーティングで絞り込みます
- **開始 ID / 終了 ID**：ID 範囲モード用。作品 ID の閉区間（作品ページ `/posts/<id>` の数字）で、差は**最大 5000**。超えると実行を拒否します。ページ数は不要で、削除済み作品は検索側で除外されます。`id:`・`order:`・`status:` メタタグは「タグ2個まで」の制限に数えられません。1ページあたりの件数とレーティング絞り込みも有効で、`donmai.moe` では全年齢のみ取得します
- **画質**
  - **高**：オリジナルの直リンク（数十 MB になる投稿もあります）
  - **中**：サイトのリサイズ版 sample。動画投稿には sample がないためオリジナルに回落します

## メタデータ

各画像は投稿ページから解析したメタデータを持ち、詳細サイドバーは `description.ejs` で描画されます：

- `tags_string`：**全タグ文字列**（絵師 → 著作権 → キャラクター → ジェネラル → メタの順）
- `tags`：タグごとの `name` / `display` / `type` / `count` / 検索リンク / wiki リンク
- `tags_by_type`：カテゴリ別にまとめたタグ名の配列
- `post_id`、`rating`、`score`、`fav_count`、`status`
- `file_size`、`file_ext`、`width`、`height`、`original_href`、`sample_href`
- `uploader_name` / `uploader_href`、`posted_date_iso`、`source_href`
- `commentary`：絵師コメントのタイトルと本文

さらに PathQL provider を登録しているので、ギャラリーで **スコア（score）/ お気に入り数（favorites）/ レーティング（rating）** で絞り込めます。レーティングは General / Sensitive / Questionable / Explicit で分類され、スコアとお気に入り数の一覧には `5+`、`10+` … `1000+` のような「指定値以上」の段階が並び、パスセグメントには範囲指定 `100-500`、`100+`、`-50`（両端を含む）も使えます。

## 注意事項

- **未ログイン／一般アカウントは1回の検索でタグ2個までです。** 3個目を入れると WARN が出て、サイトはほぼ空の結果を返します。
  畅游（Surf）からログインし、アカウントのレベルを上げてください。
- **礼儀正しくクロールしましょう**：1回あたり最大100ページ、終了ページは開始ページ以上である必要があります。
- 既定のソース `donmai.moe` は全年齢の投稿のみを配信します（`rating:e` で検索しても結果は返りません）。`danbooru.donmai.us` は成人向けコンテンツを含み、未ログイン時はサイト既定のルールでフィルタされます。
- 通常はプロキシ環境が必要です。
- 既定のソース `donmai.moe` には Cloudflare の検証があります（全体サイト `danbooru.donmai.us` は不要）。初回（または検証の期限切れ後）は「サーフ」で `donmai.moe` を開いて検証を通過してください。プラグインはサーフの Cookie とブラウザ識別子を引き継ぎ、ブロックされた場合はエラーで案内します。
- mp4 / webm の動画投稿はオリジナルの直リンクからダウンロードします。
