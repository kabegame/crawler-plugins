# 小红书（WebView）使用说明

本插件使用 Kabegame 的 WebView
后端，在真实的小红书网页中读取客户端已经加载的数据，再逐条进入作品详情页下载媒体。网页结构或站点访问策略变化时，抓取结果也可能随之变化。

## 模式说明

- **首页推荐**：打开小红书 `/explore`，读取当前会话下的推荐作品。
- **作者－已发布**：填写作者主页 URL 或 `userId`，读取作者主页的「已发布」列表。
- **作者－收藏**：填写作者主页 URL 或
  `userId`，读取「收藏」列表。此模式需要登录。
- **作者－点赞**：填写作者主页 URL 或
  `userId`，读取「点赞」列表。此模式需要登录。
- **专辑／画板**：填写 `/board/` 专辑链接或专辑 id，读取专辑内的作品。
- **搜索笔记**：填写关键词，读取搜索结果中的笔记类型条目。
- **单作品链接**：填写一个或多个作品链接，以空格或换行分隔。支持作品详情页和
  `xhslink.com` 短链接。

列表模式会按「滚动加载轮数」模拟向页面底部滚动，并在达到「最多抓取条数」后停止。每个列表条目仍会进入详情页，以获取完整图片和视频数据，而不是下载列表缩略图。

## 登录与页面操作
建议先从畅游登录，这样之后爬虫就会自动复用那个登录状态。

WebView 窗口会沿用站点会话
Cookie。作者收藏和点赞在未登录时通常为空；插件检测到空列表后会显示爬虫窗口，请先在窗口内登录，并打开对应的收藏或点赞标签页。登录或切换页面触发重新加载后，插件会继续从任务状态恢复。

若站点要求验证码或其他人工确认，请直接在显示的爬虫窗口中完成。插件不会读取或绕过账号凭据。

## 下载选项

- **图片格式－自动**：从 `sns-img-bd.xhscdn.com`
  下载原图，不使用列表中的压缩缩略图。
- **JPG / PNG / WebP**：使用小红书图片转换地址请求指定格式。
- **下载视频**：从作品的媒体流中优先选择无签名备用 URL，缺失时使用主 URL。
- **下载实况照片视频**：图片带 Live Photo 流时，额外保存一个与静图同名的
  `.mp4`。

## 使用边界

本插件只读取浏览器页面已经提供的数据和可直接访问的媒体地址，不实现 `x-s`、`x-t`
或其他签名绕过，也不会规避验证码、登录或访问控制。

请遵守小红书的服务条款、访问频率限制和适用法律。只下载你有权保存和使用的内容，尊重作者版权与隐私；不要将本插件用于批量转载、侵权传播或其他未经授权的用途。

每张图片下载间隔3秒，每帖子间隔5秒。太快了小心封号！
