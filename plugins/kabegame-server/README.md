# Kabegame 服务器

从另一个 Kabegame 的 Web 服务复制图片：可以是 Web 版（默认 [demo.kabegame.com](https://demo.kabegame.com)），也可以是桌面端在「设置 → 高级」里开启的 Web 服务器（如 `http://127.0.0.1:7490`）。

## 选项

- **模式**
  - **全站**：翻页复制服务器上的全部图片，排序可选：
    - **随机**（默认）：每次运行重新打乱，同一次运行的各页之间不重复；
    - **时间**：最新入库的在前；
    - **ID 升序**：按图片 id 从小到大。
  - **过滤**：粘贴 PathQL 查询，只复制命中的图片。在源服务器（Web 版或桌面端）的画廊、画册或任务详情里打开「高级查询」弹窗，设好条件后复制底部的「路径」，例如 `images://gallery/hide/plugin/pixiv/filter_comb/sort/by-time/desc/1`。路径里的排序会保留，末尾的页码换成下面的分页设置。
- **服务器地址**：Web 服务的根地址，插件通过它的 `/rpc` 接口读取图库。
- **包含隐藏图片**（仅全站）：默认关闭，服务器上被隐藏的图片不复制，也不占分页名额。过滤模式由路径决定（弹窗里的路径通常以 `hide/` 开头）。
- **每页数量**：默认 20，最多 100 张。
- **起始页 / 结束页**：页码范围，一次最多 10 页，超过会拒绝执行；超过最后一页的部分自动跳过。

## 复制的内容

- 图片本体：Web 版从 CDN 下载，桌面端 Web 服务器经同端口的 `/file` 读取。
- 元数据：原样复制，多张图共用的元数据在本地也共用。
- 标签：按服务器上的标签路径原样挂到本地标签画册（例如 `konachan/character/…`）。
- 帖子地址：使用服务器记录的帖子地址；服务器没有时留空，不会填成服务器自己的地址。
- 详情面板：用来源插件自己的详情模板渲染，模板脚本的执行权限与 Kabegame 本身一致。模板和来源插件的私有数据在复制时一并缓存。

## 使用前须知

桌面端 Web 服务器没有鉴权，请只连接你信任的设备。图片版权归原作者所有。
