# AIBooru 更新日志

## 1.0.2

- 任务日志与参数校验错误会跟随 Kabegame 的界面语言显示，支持简体中文、English、日本語、한국어与繁體中文。

## 1.0.1

- 「爬取模式」「人气榜周期」「每页条数」「质量」这几个单选项，以及标签模式的「标签组合」、id 范围模式的「起始 id / 结束 id」改为必填，留空时在启动前就会提示，不再运行后才报错。

## 1.0.0

- 首个版本。支持全部、标签、人气榜（日 / 周 / 月）和 id 范围四种爬取模式，分级过滤默认只抓全年龄。
- 每张图带完整元数据：按 Artist / Model / Copyright / Character / General / Meta 分组的标签及帖数、上传者与审核者、分数（赞 / 踩）、收藏数、浏览数、来源、作者评论、AI 生成参数（prompt、负面词、采样器、种子、步数、CFG、模型）和评论。插件详情面板按 AIBooru 详情页的版式和配色还原。
- 标签按分类写入应用的标签画册 `aibooru/<分类>`，其中 `aibooru/model` 收录生成所用的模型。
- 画廊插件扩展支持按分数、收藏数和分级筛选。
