# 小红书（V8 后端）

抓取小红书作品的图片与视频。本插件不做任何签名绕过，只读取页面本身公开返回的数据。

## 两种模式

### 作品链接

把作品链接粘进「作品链接」框，多个链接用空格或换行分隔。支持四种形态：

- `https://www.xiaohongshu.com/explore/{id}?xsec_token=...`
- `https://www.xiaohongshu.com/discovery/item/{id}?xsec_token=...`
- `https://www.xiaohongshu.com/user/profile/{用户id}/{作品id}?xsec_token=...`
- `https://xhslink.com/xxxx` 短链（自动展开）

从 App 分享出来的链接一般就是短链，直接粘贴即可。

### 首页推荐

反复请求首页推荐流并抓取其中的作品。

推荐流本身不支持翻页，但**每次刷新返回的约 25 条互不重复**，所以本插件用「刷新轮数」代替分页：
刷 5 轮约能拿到 120 条左右，刷 20 轮约 500 条。用「最多抓取作品数」兜住总量。

## 关于登录（Cookie）

插件会自动尝试从**畅游**取用小红书的 Cookie。**没有 Cookie 也能正常运行**：

- 未登录：推荐流返回的是通用推荐，部分作品可能看不全
- 已登录：推荐流返回的是**你的个性化推荐**，内容质量通常更高

想启用登录态，先在应用的「畅游」里访问小红书并登录，之后再运行本插件即可。插件本身读不到 Cookie 明文。

## 图片格式

| 选项 | 说明 |
|---|---|
| 自动（原图） | 站点原图，体积适中，**推荐** |
| JPEG | 转码为 JPEG，体积最小 |
| PNG | 无损，体积最大（约为原图的 1.4 倍） |
| WebP | 转码为 WebP |

注意「自动」拿到的是原图，而非页面上显示的缩略图——两者体积可差 4~5 倍。

## 视频与 Live 图

- 视频作品默认下载视频本体；关闭「下载视频」则只保存封面图。
- Live 图默认只下静态图。勾选「下载 Live 图动态视频」后会额外保存对应的 mp4。

## 能力边界

本插件运行在 V8 后端，没有浏览器窗口，只能读取页面服务端直出（SSR）的数据。因此：

- ✅ 单作品、首页推荐 —— 可用
- ❌ **按作者抓取** —— 作者主页的服务端数据里作品 ID 被抹空，拿不到
- ❌ 搜索、专辑、收藏、点赞 —— 这些页面的数据完全由前端脚本加载，服务端不直出

需要这些维度请使用 **小红书（畅游窗口）** 插件，它运行在真实浏览器里，可以滚动加载。

## 请求频率

「请求间隔」默认 2500 毫秒，实际等待会在此基础上随机浮动（对数正态分布），模拟人类节奏。
抓取量大时建议适当调高，过于频繁的请求可能触发风控。

请遵守小红书的用户协议与相关法律法规，尊重创作者版权，仅将下载内容用于个人学习或欣赏，不要用于商业用途或二次分发。
