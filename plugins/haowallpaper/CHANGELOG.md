# 哲风壁纸更新日志

## 0.4.0

- 相关标签会转换为拼音 key，下载时自动写入 `haowallpaper/tag` 应用标签；另以站内用户 ID 为稳定 key 写入 `haowallpaper/artist` 作者标签。
- `provideLabels` 使用同一套规则，为旧版本下载的图片补齐相关标签与作者标签。
- PathQL Provider 移除旧的 metadata tags 树，改为按下载量、收藏量的累计数值区间浏览；目录与色彩入口保持不变。

## 0.3.0

- 标签集合改为站点搜索定向拉取：多个标签以「、」连接提交站点搜索（按并集返回），不再翻全站列表后逐个在详情页按标签过滤；页码范围对应搜索结果的页码。
- 列表排序固定为站点默认的「昨日热门」（`sortType=3`）。
- 壁纸格式只勾图片或只勾视频时，按站点前端的规则换算成 `wpType` 查询参数（电脑静态 `1`、电脑动态 `3,4`、手机静态 `2`、手机动态 `5,6`），直接拉取对应种类，页码范围也对应该种类的结果；两种都勾时沿用站点默认。
- 修复详情里发布者头像显示为破碎图：站点图片按 Referer 防盗链，改为经宿主代理（`__bridge.fetch`）带站点 Referer 拉取；拉取失败时显示昵称首字。
- 修复总页数识别：站点分页按钮改为链接后，旧逻辑会把总页数误判为 1，导致只爬起始页。

## 0.2.0

- 新增壁纸基本信息、发布者与相关标签的冻结详情展示。
- 新增结构化 metadata 迁移，兼容 `schema 1` 及更早版本的数据。
- 详情模板只使用爬取时保存的结构化字段，不保存页面 HTML，也不动态请求详情接口。
- 新增按目录、标签和色彩浏览的 PathQL Provider。
- 标签超过 100 个时按 `page-N` 分页，每页最多显示 100 个标签。
