# Konachan 動漫壁紙 - 外掛說明

本外掛用於從 `konachan.net` 網站爬取動漫壁紙並加入下載佇列。

## 設定項

- **起始頁面（start_page）**：要爬取的起始頁面（最小值為 1）
- **結束頁面（end_page）**：要爬取的結束頁面。**請保持最多爬取 100 頁**，超過會拒絕執行
- **品質（quality）**：
  - **高（high）**：優先下載高解析度圖片，若不存在則降為中等品質
  - **中（medium）**：下載中等品質圖片（預設）

## 排行榜模式（popular）

- **排行榜類型（popular_scale）**：日榜 / 週榜 / 月榜依自然日、週、月統計；最近 24 小時 / 一週 / 一個月 / 一年是截至現在的滾動區間
- **排行榜日期（popular_date）**：日、週、月榜可以指定日期看往期，留空為當期
- **回溯期數（popular_periods）**：從該日期起往前連抓多少期，一次最多 100 期。站台每期只有一頁、最多 40 張
- **分級過濾**在這個模式下由插件依每張圖的分級篩選（榜單頁不接受搜尋參數）。konachan.net 只顯示全年齡作品，所以同一期在 konachan.net 上通常比 konachan.com 少

## id 範圍模式（id_range）

- **起始 id / 結束 id（id_start / id_end）**：作品 id 閉區間，即作品頁網址 `/post/show/<id>` 裡的數字。兩者都要是正整數，結束 id 不小於起始 id，**最多相差 5000**，否則拒絕爬取
- 依 id 由小到大抓取區間內的全部作品，不需要填頁數；區間裡已刪除的 id 會跳過，所以實際張數通常遠少於區間寬度
- **分級過濾**與「全部」「標籤」模式一樣拼進站台搜尋串

## 使用說明

1. 選擇要爬取的頁面範圍（起始頁到結束頁）
2. 選擇圖片品質偏好
3. 點擊「開始爬取」
4. 外掛會自動造訪列表頁，再進入每個詳情頁下載圖片

## 注意事項

- **請文明爬取**：單次最多 100 頁，超過會拒絕
- **結束頁必須大於等於起始頁**，否則會報錯
- 若選「高」品質但無高解析版本，會自動降為中等品質
- 建議合理設定頁面範圍，避免對伺服器造成過大負擔
