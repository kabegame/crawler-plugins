# Konachan 애니메이션 벽지 - 플러그인 안내

이 플러그인은 `konachan.net`에서 애니메이션 벽지를 가져와 다운로드 큐에 넣습니다.

## 설정 항목

- **시작 페이지(start_page)**: 크롤 시작 페이지 (최소 1)
- **끝 페이지(end_page)**: 크롤 끝 페이지. **한 번에 최대 100페이지**까지. 초과 시 거부됩니다
- **화질(quality)**:
  - **고(high)**: 고해상도 우선, 없으면 중간 화질로 폴백
  - **중(medium)**: 중간 화질 (기본값)

## 랭킹 모드(popular)

- **랭킹 종류(popular_scale)**: 일간 / 주간 / 월간은 달력 기준, 최근 24시간 / 1주 / 1개월 / 1년은 지금까지의 롤링 기간입니다
- **랭킹 날짜(popular_date)**: 일간·주간·월간은 날짜를 지정해 지난 기간을 볼 수 있습니다. 비우면 현재 기간
- **거슬러 올라갈 기간 수(popular_periods)**: 해당 날짜부터 거슬러 올라가며 연속으로 몇 기간을 수집할지. 실행당 최대 100기간이며, 사이트는 기간마다 한 페이지, 최대 40장입니다
- 이 모드에서 **등급 필터**는 플러그인이 작품별로 적용합니다(랭킹 페이지는 검색 파라미터를 받지 않음). konachan.net은 전체 이용가 작품만 보여 주므로 같은 기간이라도 konachan.com보다 적은 것이 보통입니다

## ID 범위 모드(id_range)

- **시작 ID / 끝 ID(id_start / id_end)**: 작품 ID 닫힌 구간으로, 작품 페이지 주소 `/post/show/<id>` 의 숫자입니다. 둘 다 양의 정수여야 하고, 끝 ID는 시작 ID 이상, 차이는 **최대 5000**까지이며 초과하면 실행을 거부합니다
- 범위 안의 작품을 ID 오름차순으로 모두 수집하며 페이지 수는 필요 없습니다. 삭제된 ID는 건너뛰므로 실제 장수는 보통 범위 폭보다 훨씬 적습니다
- **등급 필터**는 전체·태그 모드와 마찬가지로 사이트 검색 문자열에 추가됩니다

## 사용 방법

1. 크롤할 페이지 범위(시작~끝) 선택
2. 이미지 화질 선택
3. 「크롤 시작」 클릭
4. 플러그인이 목록 페이지 → 각 상세 페이지 순으로 이미지를 다운로드합니다

## 주의사항

- **예절 지키기**: 한 번에 최대 100페이지. 초과 시 거부됩니다
- **끝 페이지는 시작 페이지 이상**이어야 합니다. 아니면 오류가 납니다
- 「고」를 선택해도 고해상도가 없으면 자동으로 중간 화질로 내려갑니다
- 서버 부하를 고려해 페이지 범위를 적당히 설정하세요
