# Konachan アニメ壁紙 - プラグイン説明

このプラグインは `konachan.net` からアニメ壁紙を取得し、ダウンロードキューに追加します。

## 設定項目

- **開始ページ（start_page）**：取得開始ページ（最小 1）
- **終了ページ（end_page）**：取得終了ページ。**1回あたり最大100ページ**まで。超過すると拒否されます
- **画質（quality）**：
  - **高（high）**：高解像度を優先、なければ中画質にフォールバック
  - **中（medium）**：中画質（デフォルト）

## ランキングモード（popular）

- **ランキングの種類（popular_scale）**：日間 / 週間 / 月間は暦の区切りで集計、直近24時間 / 1週間 / 1か月 / 1年は現在までのローリング期間です
- **ランキング日付（popular_date）**：日間・週間・月間は日付を指定して過去分を見られます。空欄は当期
- **遡る期数（popular_periods）**：その日付から遡って連続で何期分取得するか。1回最大100期。サイトは1期1ページ、最大40枚です
- このモードでは**レーティング絞り込み**をプラグインが作品ごとに行います（ランキングページは検索パラメータを受け付けません）。konachan.net は全年齢作品しか表示しないため、同じ期でも konachan.com より少なくなるのが普通です

## ID 範囲モード（id_range）

- **開始 ID / 終了 ID（id_start / id_end）**：作品 ID の閉区間で、作品ページ URL `/post/show/<id>` の数字です。どちらも正の整数で、終了 ID は開始 ID 以上、差は**最大 5000** までです。超えると実行を拒否します
- 範囲内の作品を ID の昇順ですべて取得します。ページ数の指定は不要です。削除済みの ID は飛ばすため、実際の枚数は範囲の幅よりかなり少なくなるのが普通です
- **レーティング絞り込み**は全部・タグモードと同じくサイトの検索文字列に付加されます

## 使い方

1. 取得するページ範囲（開始～終了）を指定
2. 画質を選択
3. 「クロール開始」をクリック
4. プラグインがリスト頁→各詳細頁の順で画像をダウンロードします

## 注意事項

- **マナーを守って**：1回最大100ページ。超過は拒否されます
- **終了ページは開始ページ以上**にしてください。そうでないとエラーになります
- 「高」を選んでも高解像度がない場合は自動で中画質になります
- サーバー負荷を考え、ページ範囲は適切に設定してください
