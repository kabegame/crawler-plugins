# Kemono クローラー

このプラグインは `kemono.cr` からクリエイターの投稿と添付ファイルを取得します。成人向けコンテンツが含まれる場合があります。居住地域の法律、サイトの規約、コンテンツの利用許諾に従ってください。

## 5 種類の取得モード

### リンク

次のいずれかの形式で完全な URL を入力します。

- クリエイターの全投稿：`https://kemono.cr/<service>/user/<uid>`
- 単一投稿：`https://kemono.cr/<service>/user/<uid>/post/<pid>`

旧ドメイン `kemono.su`／`kemono.party` のリンクも認識しますが、リクエストは常に現在の `kemono.cr` ドメインへ送信されます。単一投稿を指定した場合は投稿 API を直接呼び出し、クリエイターの一覧全体を巡回せず、ページ範囲も適用されません。

### クリエイター

**クリエイターサービス**を選択し、**クリエイター ID**を入力します。対応サービスは `patreon`、`fanbox`、`gumroad`、`subscribestar`、`dlsite`、`discord`、`fantia`、`boosty`、`afdian` です。

上流の `kemono-scraper` は姉妹サイト Coomer（`onlyfans`、`fansly`）にも対応していますが、これらはアニメ画像ではなく成人向けサブスクリプションコンテンツのため、このプラグインには移植していません。お気に入り一覧に該当項目が含まれていても、自動的にスキップされます。

### お気に入りのクリエイター

現在の Kemono アカウントがお気に入りに登録したクリエイターを読み込み、各クリエイターの投稿を取得します。**2 つのページ範囲が同時に適用されます**。まず**お気に入り作者のページ範囲**で処理するクリエイターを選び、次に**作者ページ範囲**で各クリエイターから取得する投稿ページを決めます。

### お気に入りの投稿

現在の Kemono アカウントがお気に入りに登録した投稿を読み込み、**ページ範囲**で絞り込んでから 1 件ずつダウンロードします。

### タグ

`nsfw`、`wip`、`comic`、`nude` などのサイトタグを入力し、**ページ範囲**に従ってサイト全体からそのタグを持つ投稿を取得します。タグは**大文字と小文字を区別**するため、サイト上の表記と一致させてください。全タグは `kemono.cr/posts/tags` で確認できます。このモードはログイン不要です。

## ページ範囲

対象となるすべてのモードでは、**1 ページ 50 件**単位で取得量を制限します。ページ番号は 1 から始まり、終了ページを `0` にすると最後のページまで取得します。

| モード | 適用されるページ範囲 |
|---|---|
| クリエイター／クリエイターリンク | 作者ページ範囲（投稿一覧） |
| お気に入りのクリエイター | お気に入り作者ページ範囲 **＋** 作者ページ範囲 |
| お気に入りの投稿 | ページ範囲 |
| タグ | ページ範囲 |
| 単一投稿リンク | 適用なし。投稿を直接取得 |

プラグインは**ストリーミング方式**で動作します。一覧全体を先にため込むのではなく、各ページの投稿添付をすべてダウンロードしてから次のページへ進みます。そのため、途中でタスクをキャンセルしても、すでにダウンロードしたファイルは残ります。

お気に入り一覧は API から一括で返されます。そこでプラグインがローカルで 50 件ずつのページに分割し、投稿一覧と同じページ単位になるようにしています。

## お気に入りモードと「畅游」ログイン

お気に入り API にはログイン Cookie が必要です。プラグインは Cookie ファイルを読み取らず、ブラウザーの Cookie も探索しません。先に Kabegame の「畅游（Surf）」で `kemono.cr` を開いてログインしてから、お気に入りモードを実行してください。

畅游にこのサイトの Cookie がない場合、タスクはすぐにログインを求めます。お気に入りや後続の一覧リクエストが `401`／`403` を返した場合は、ログイン状態が失効しています。畅游へ戻って再度ログインしてください。

リンク、クリエイター、タグの 3 モードはログイン不要です。

## 画像ソース：サムネイルとオリジナル

**既定ではサムネイルをダウンロードします。これは意図的な選択です。**

Kemono はオリジナルファイルを `n1`～`n5`、`c1`～`c3` という独立したファイルノードに配置しています。2026-07 のテストでは、多くのネットワーク環境で、プロキシの有無にかかわらずこれらのノードへ **TCP レベルで接続できません**でした。一方、サムネイルホスト `img.kemono.cr` には正常に接続できました。そのため：

- **サムネイル（既定）：**長辺最大 800 px、1 枚約 30～40 KB。`img.kemono.cr` から安定してダウンロードできます。
- **オリジナル：**上記のファイルノードから取得します。ネットワークから接続できれば完全な画質ですが、接続できなければすべて失敗します。

800 px は壁紙用途として明らかな画質低下ですが、オリジナルのノードに到達できない場合、画像を取得できる唯一の経路です。ネットワーク環境が変わった場合は、設定をオリジナルへ戻して試すことができます。

**サムネイルモードでは、圧縮ファイル、動画などの添付を自動的にスキップします。** これらのファイルにはサムネイルがなく、リクエストが必ず 404 になるため、スキップしないと投稿全体で失敗が大量に発生します。

## 添付ファイルについて

投稿の添付は画像とは限らず、動画、音声、圧縮ファイル、その他のファイルの場合もあります。オリジナルモードでは、プラグインがすべての添付を Kabegame へ渡してダウンロードします。プレビューできるかどうかは、Kabegame と現在のプラットフォームが対応するメディア形式によって決まります。

**バナー／メインファイルを含める**は、元のダウンローダーの `--banner` 動作に対応し、投稿の `file` フィールドを添付へ追加します。この設定を無効にしても、画像以外のメインファイルは保持されます。サムネイルモードではサムネイルがないため、引き続きスキップされます。

同じ投稿のすべての添付は、1 つの簡潔な投稿メタデータを共有します。複数の添付には投稿タイトルの後ろに `(1)`、`(2)` などの番号が追加されます。元のダウンローダーと同様に、画像と画像以外の添付は別々に採番されるため、異なる種類のファイルに同じ番号が付く場合があります。
