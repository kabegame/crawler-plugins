# 米游社更新日志

## 0.2.2

- 适配插件变量空值语义：爬取模式改为必选；单帖链接与作者 UID 改为必填，其余可选项留空时按默认值处理。

## 0.2.1

- 画廊细分结果的倒序与分页改用 Kabegame 4.5.1 提供的 `_kb_desc` / `_kb_x<N>x/<page>` 全局解析，移除插件内重复且已失效的分页尾定义。

## 0.2.0

- 配合应用 4.5.1 调整「细分筛选」的内部写法：不再依赖应用投影的 `plugin_metadata` 列，细分条件可以用在高级查询的「或 / 非」组合里。需要应用 4.5.1 及以上。

## 0.1.6

- 优化作者 UID、游戏分区、页码范围、每页条数、评论区图片开关和评论上限的表单宽度。
- 将来源截图迁移为 JPG，并新增搜索、图片列表和图片预览横幅资源。
- 更新中文 README 的截图路径，使文档与当前资源目录保持一致。
- 新增英语、日语、韩语和繁体中文使用文档，并接入插件多语言文档配置。
