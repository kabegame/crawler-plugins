# 米游社（Miyoushe）の画像をアルバムに保存する方法

このガイドでは、米游社で見つけたお気に入りの画像を Kabegame に保存するときの全体的な流れを説明します。順番に読むと、各手順の役割、入力する設定、問題が起きたときの確認先が分かります。

## 1. 投稿の探し方を選ぶ

現在は 3 つの方法があります。いずれか 1 つを選んでください。

### 1. キーワードで検索する

特定の種類の画像を探したいときに使います。

1. **クロールモード**で「キーワード検索」を選択します。
2. **検索キーワード**に「壁紙」「cosplay」「キャラクター名」など探したい言葉を入力します。
3. 必要に応じて**ゲーム分区**（`gids`）を選択します。
   - 「全サイト」を選ぶと、より広い範囲から検索します。
   - 対応するゲーム分区を選ぶと、目的のコミュニティに絞り込みやすくなります。
4. **開始ページ／終了ページ／1ページあたり件数**を設定します。
   - ページ数が多いほど処理時間も長くなるため、まずは小さな範囲で試してください。
   - `page_size` は 1 ページで取得する投稿数です。画像のない投稿はプラグインが除外します。

### 2. 1 件の投稿だけを取得する

投稿 URL がすでに分かっているときに使います。

1. **クロールモード**で「単一投稿 URL」を選択します。
2. **投稿 URL**に米游社の記事リンクをそのまま貼り付けます。
   - プラグインはリンクから `post_id` を抽出します。
   - リンク例：`https://www.miyoushe.com/{ゲーム}/article/{id}`

### 3. 投稿者 UID で取得する

投稿者の UID が分かっているときに使います。

1. **クロールモード**で「ユーザー投稿リスト」を選択します。
2. **投稿者 UID**に米游社ユーザーの UID を入力します。UID は数字の文字列で、投稿者のプロフィール URL から確認できます。

![投稿者プロフィール](./user-page.png)

3. **開始ページ／終了ページ／1ページあたり件数**はキーワード検索モードと同じです。
   - 既定では 1～3 ページを 1 ページ 20 件ずつ取得します。必要に応じて調整してください。
   - まずは 1 ページなど、小さな範囲でテストすることをおすすめします。

## 2. 投稿が見つかった後、画像が保存されるまで

検索で見つけた投稿でも、直接指定した投稿でも、プラグインは次のデータフローで処理します。

1. **投稿詳細を取得（`getPostFull`）**
   - 投稿の主要情報を取得します。
   - 特に、`post.images` と `post.content` 内の対応する画像から本文の画像一覧を取得します。
2. **絵文字セットを取得（`emoticon_set`）**
   - メタデータには、本文（`subject/content`）で実際に使用されている必要な絵文字マッピングだけを保存します。
   - 画像詳細ページを開くと、コメント欄の絵文字表示に使う全絵文字セットを動的に取得します。
3. **コメントを取得（`getPostReplies`）**
   - コメント内容はメタデータに保存しません。
   - 画像詳細ページではコメントを動的に取得します。最初に 20 件を表示し、「さらに読み込む」で追加できます。
   - 取得時のコメント API は、統計とコメント画像のダウンロードだけに使い、設定したコメント上限まで継続して取得します。
4. **画像をダウンロードしてアルバムへ保存**
   - 投稿に画像がある場合、本文画像は必ずダウンロードします。
   - コメント画像は `fetch_comment_images = true` の場合だけダウンロードします。
   - 進捗は本文画像とコメント画像の合計数で均等に配分されます。

---

## 3. ときどき発生する状況

- **投稿に画像がない：**プラグインはその投稿をスキップし、画像のある投稿だけを処理します。
- **API の一時的な異常：**ネットワークを切り替えるか、しばらく待ってから再試行してください。
- API エラーが発生した場合、多くは時間を空けて再試行すると解決します。

## 4. 設定一覧

| 設定 | 表示条件 | 役割 |
| --- | --- | --- |
| クロールモード | 常時 | キーワード検索／単一投稿 URL／ユーザー投稿リスト |
| 投稿 URL | 単一投稿モード | 投稿リンクを貼り付け、`post_id` を自動抽出 |
| 投稿者 UID | ユーザー投稿リスト | 取得する投稿者の UID |
| 検索キーワード | キーワード検索 | 検索するキーワード |
| ゲーム分区 | キーワード検索 | 対応する `gids` 分区を選択（任意） |
| 開始ページ（1 から） | キーワード検索／ユーザー投稿リスト | 取得を始めるページ |
| 終了ページ（含む） | キーワード検索／ユーザー投稿リスト | 取得する最後のページ |
| 1ページあたり件数 | キーワード検索／ユーザー投稿リスト | 1 ページで取得する投稿数 |
| コメント画像をダウンロード | 常時 | オン：本文＋コメント画像、オフ：本文のみ |
| コメント取得上限（`max_comments`） | 常時 | 取得時に読み込むコメントの最大数（既定値 200） |
