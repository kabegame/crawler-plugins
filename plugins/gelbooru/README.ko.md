# Gelbooru 이미지 보드 - 플러그인 설명

이 플러그인은 `gelbooru.com`에서 작품을 크롤링해 다운로드 큐에 넣고, **게시물 페이지의 전체 태그를
이미지 메타데이터에 기록합니다.** 이 사이트에서 가장 값진 것은 태그 체계이며, AI 생성용 프롬프트는
이미지 상세 사이드바에서 바로 복사할 수 있습니다.

## 크롤 모드

- **태그(tags)**: 태그 조합 검색 `index.php?page=post&s=list&tags=...` — 가장 많이 쓰는 모드
- **전체(all)**: 사이트 전체 최신 작품(`tags=all`)
- **태그 목록(tag_list)**: `index.php?page=tags&s=list`의 태그 표를 패턴으로 탐색한 뒤 태그마다 작품을 수집

## 설정 항목

- **태그 조합(mode_tag_value)**: 목록 입력. 실행 시 `+` 로 결합하며 태그 내 공백은 `_` 로 변환됩니다
- **정렬(sort_order)**: 최신 / 높은 점수순 / 최근 업데이트순 / 무작위. 사이트의 `sort:` 메타태그
  (예: `sort:score:desc`)를 일반 태그처럼 검색어에 덧붙이는 방식입니다
- **시작 페이지 / 끝 페이지(start_page / end_page)**: 실행당 최대 100페이지, **페이지당 42개 고정**
- **태그 검색 패턴(tag)**: 태그 목록 모드의 이름 매칭. `*`는 와일드카드 (예: `*genshin*`)
- **태그 카테고리(mode_tag_type)**: 전체 / 일반 / 작가 / 저작권 / 캐릭터 / 메타
- **태그 순서(mode_tag_order)**: 이미지 수 / 이름 / 업데이트 날짜
- **태그 스킵 수 / 크롤할 태그 수 / 태그당 페이지 수**: 태그 목록 모드의 폭과 깊이를 조절합니다
- **화질(quality)**:
  - **고화질**: 원본 파일. `absurdres` 같은 태그에서는 PNG 원본이 20~40MB인 경우가 많아 프록시를 거치면
    전송이 끝나지 않아 다운로드 실패("파일 형식을 지원하지 않음(infer)")로 보일 수 있습니다.
    파싱 오류가 아니라 전송이 끊긴 것이므로 재시도하거나 중간 화질로 전환하세요
  - **중간**: 사이트가 축소한 sample
  - 동영상 게시물은 두 경우 모두 `<video>`의 **mp4** 소스를 받습니다(사이트는 webm도 제공하지만
    데스크톱 호환 사본은 원래 H.264 MP4입니다)

## 메타데이터

모든 이미지에는 게시물 페이지에서 파싱한 메타데이터가 붙고, 상세 사이드바는 `description.ejs`로 렌더링됩니다.

- `tags_string`: **전체 태그 문자열**. 작가 → 캐릭터 → 저작권 → 메타 → 일반 순으로 정렬되며 한 번에 복사 가능
- `tags`: 태그별 `name` / `display` / `type` / `count` / 검색 링크 / wiki 링크
- `tags_by_type`: 카테고리별로 묶은 태그 이름 배열
- `post_id`, `rating`, `score`, `md5`, `file_ext`, `width`, `height`
- `uploader_name` / `uploader_href`, `posted_date_text`, `source_text` / `source_href`
- `original_href`, `sample_href`, `video_href`, `has_sound`, `has_children`

함께 PathQL provider도 등록하므로 갤러리에서 **태그 카테고리 → 태그** 2단계로 탐색할 수 있습니다.

## 주의 사항

- **페이지당 42개는 사이트가 고정한 값입니다.** 비로그인 상태에서는 URL의 `limit` 파라미터가 무시되므로
  (계정 설정 항목) "페이지당 개수" 설정이 없습니다. 페이지 이동은 페이지 번호가 아니라 `pid` 오프셋입니다.
- **태그 표에는 카테고리 필터가 없습니다.** 카테고리를 고르면 가져온 뒤 필터링하므로, 좁은 카테고리일수록
  지정한 태그 수를 채우는 데 더 많은 페이지가 필요합니다.
- **예의 있게 크롤하세요**: 실행당 최대 100페이지이며, 끝 페이지는 시작 페이지 이상이어야 합니다.
- 성인 콘텐츠가 포함되어 있으며, 비로그인 상태에서는 사이트 기본 필터가 적용됩니다.
- 보통 사용 가능한 프록시가 필요합니다.
- mp4 / webm 동영상 게시물이 있으며, 플러그인은 원본 파일을 직접 내려받습니다.

즐겁게 사용하세요~
