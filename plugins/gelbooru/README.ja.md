# Gelbooru 画像掲示板 - プラグイン説明

このプラグインは `gelbooru.com` から作品をクロールしてダウンロードキューに入れ、**投稿ページの
全タグを画像メタデータに書き込みます**。このサイトで最も価値があるのはタグ体系で、AI 生成用の
プロンプトは画像詳細サイドバーからそのままコピーできます。

## クロールモード

- **タグ（tags）**：タグ組み合わせで検索 `index.php?page=post&s=list&tags=...`。最もよく使います
- **全部（all）**：サイト全体の新着（`tags=all`）
- **タグ一覧（tag_list）**：`index.php?page=tags&s=list` のタグ表をパターンで参照し、タグごとに作品を取得

## 設定項目

- **タグ組み合わせ（mode_tag_value）**：リスト入力。実行時に `+` で連結し、タグ内の空白は `_` に変換します
- **並び順（sort_order）**：新着 / 高スコア順 / 更新順 / ランダム。サイトの `sort:` メタタグ
  （例：`sort:score:desc`）を通常のタグと同じように検索文字列へ付加する実装です
- **開始ページ / 終了ページ（start_page / end_page）**：1 回あたり最大 100 ページ、**1 ページ 42 件固定**
- **タグ検索パターン（tag）**：タグ一覧モードの名前マッチ。`*` はワイルドカード（例：`*genshin*`）
- **タグカテゴリ（mode_tag_type）**：任意 / ジェネラル / 絵師 / 著作権 / キャラクター / メタ
- **タグ順序（mode_tag_order）**：画像数 / 名称 / 更新日
- **タグスキップ数 / クロールするタグ数 / タグごとのページ数**：タグ一覧モードの広さと深さを調整します
- **画質（quality）**：
  - **高**：オリジナル。`absurdres` などのタグでは PNG のオリジナルが 20〜40MB になることが多く、
    プロキシ経由だと転送しきれずダウンロード失敗（「ファイル形式が未対応（infer）」）になる場合があります。
    解析エラーではなく転送が途中で切れただけなので、再試行するか画質「中」に切り替えてください
  - **中**：サイトのリサイズ版 sample
  - 動画投稿はどちらでも `<video>` の **mp4** ソースを取得します（サイトは webm も配信しますが、
    デスクトップの互換コピーはもともと H.264 MP4 です）

## メタデータ

各画像には投稿ページから解析したメタデータが付き、詳細サイドバーは `description.ejs` で描画されます。

- `tags_string`：**全タグ文字列**。絵師 → キャラクター → 著作権 → メタ → ジェネラルの順で、ワンクリックコピー可
- `tags`：タグごとの `name` / `display` / `type` / `count` / 検索リンク / wiki リンク
- `tags_by_type`：カテゴリごとにまとめたタグ名の配列
- `post_id`、`rating`、`score`、`md5`、`file_ext`、`width`、`height`
- `uploader_name` / `uploader_href`、`posted_date_text`、`source_text` / `source_href`
- `original_href`、`sample_href`、`video_href`、`has_sound`、`has_children`

あわせて PathQL provider を登録するので、ギャラリーで **タグカテゴリ → タグ** の 2 階層でも辿れます。

## 注意事項

- **1 ページ 42 件はサイト側の固定値です。** 未ログインでは URL の `limit` パラメータが効かない
  （アカウント設定のため）ので「1ページあたりの件数」設定はありません。ページ送りはページ番号ではなく
  `pid` オフセットです。
- **タグ表にはカテゴリ絞り込みがありません。** カテゴリを選んだ場合は取得後に絞り込むため、
  絞り込みが強いほど指定件数を集めるのに多くのページが必要です。
- **礼儀正しくクロールしてください**：1 回あたり最大 100 ページ、終了ページは開始ページ以上にしてください。
- 成人向けコンテンツを含みます。未ログイン時はサイト既定のフィルタが適用されます。
- 通常はプロキシが必要です。
- mp4 / webm の動画投稿があり、プラグインは元ファイルを直接ダウンロードします。
