# nekos.moe 插件说明

本插件从 [nekos.moe](https://nekos.moe)（开源的猫娘图库，前后端源码在 [GitHub](https://github.com/Nekos-moe)）按搜索结果翻页抓取原图。

## 选项

- **排序**：最新 / 最多点赞 / 最早，与站点搜索页一致。
- **NSFW 内容**：仅全年龄（默认）/ 仅 NSFW / 全部。
- **每页数量**：1–50，站点单次最多返回 50 张。
- **起始页 / 结束页**：页码范围，到最后一页时自动结束。站点最多跳过 2500 张，所以每页 50 张时最多翻到第 51 页。

## 抓取内容

- 原图（`/image/<id>`）。
- 元数据：上传者、审核者、上传时间、画师、点赞与收藏数、NSFW 标记与标签。
- 标签画册：画师挂到 `nekos-moe/artist`，其余标签挂到 `nekos-moe/tag`。

## 使用前须知

- 站点对搜索接口限流（每 10 秒 5 次），插件会自动放慢翻页速度，触发限流时按服务端要求等待后重试。
- 站点从 2020 年起不再新增图片，现有约 800 张。
- 内容版权归原作者所有；请遵守站点服务条款，合理设置页数与使用频率。
