# anime-pictures 插件说明

从 [anime-pictures.net](https://anime-pictures.net) 按标签与页面范围批量下载壁纸。

## 按标签下载想要的图片

1. **打开任务配置**  
   在 Kabegame 中新建或编辑「爬取任务」，选择源为 **anime-pictures**。

2. **填写参数**

   | 参数       | 说明 |
   |------------|------|
   | **起始页面** | 从第几页开始爬（从 0 开始）。 |
   | **结束页数** | 爬到第几页为止（包含该页）。单次任务建议不超过 100 页。 |
   | **标签**     | 站点搜索标签，只下载带该标签的图片；留空则按当前列表页爬取（不限定标签）。 |

3. **获取标签名**  
 
在 [anime-pictures.net](https://anime-pictures.net) 找到喜欢的图片

![scsho](./banners/scsho.png)

在此截图的左上角可以看到”原神”、“胡桃(原神)”等一系列标签。选择你喜欢的一个（比如"胡桃(原神)"）

![hutao](./banners/hutao.png)

把这里的 "胡桃(原神)" 填入标签，然后把你想要的起始结束页数填入，即可愉快玩耍啦

4. **示例**

   - 只下载「原神」相关图，第 1～5 页：  
     **起始页面**：`1`，**结束页数**：`5`，**标签**：`原神` 或 `Genshin Impact` 等站点支持的标签。
   - 只下载某角色（如 コロンビーナ）的图：  
     **标签**：`コロンビーナ(原神)`（以站点实际标签为准）。
   - 不按标签、只按页数爬当前列表：  
     **标签**留空，设置**起始页面**和**结束页数**即可。

5. **运行任务**  
   保存配置后运行任务，插件会按页面顺序打开列表、进入每张图并下载大图；进度条会随已处理图片数量更新。

## 注意事项

- 单次任务起始页到结束页不超过 100 页。
- 结束页不能小于起始页。
- 标签需与站点一致（含语言、括号等），否则可能无结果。
