# anime-pictures 플러그인 안내

[anime-pictures.net](https://anime-pictures.net)에서 태그와 페이지 범위로 벽지를 일괄 다운로드합니다.

## 태그로 원하는 이미지 받기

1. **작업 설정 열기**  
   Kabegame에서 「크롤 작업」을 새로 만들거나 편집하고, 소스를 **anime-pictures**로 선택합니다.

2. **매개변수 설정**

   | 매개변수 | 설명 |
   |----------|------|
   | **시작 페이지** | 몇 페이지부터 크롤할지(0부터). |
   | **끝 페이지** | 몇 페이지까지 크롤할지(해당 페이지 포함). 작업당 100페이지 이내 권장. |
   | **태그** | 사이트 검색 태그. 해당 태그가 붙은 이미지만 다운로드. 비우면 태그 없이 목록만 크롤. |

3. **태그 이름 찾기**  
   [anime-pictures.net](https://anime-pictures.net)에서 마음에 드는 이미지를 열면 왼쪽 위에 태그(예: 「原神」「胡桃(原神)」)가 보입니다. 원하는 태그를 **태그**란에 그대로 넣고, 시작·끝 페이지를 설정한 뒤 실행하면 됩니다.

![scsho](./banners/scsho.png)
![hutao](./banners/hutao.png)

4. **예시**

   - 원신 관련만 1~5페이지: **시작** `1`, **끝** `5`, **태그** `原神` 또는 `Genshin Impact`(사이트 표기와 동일하게).
   - 특정 캐릭터(예: コロンビーナ)만: **태그** `コロンビーナ(原神)`(사이트 실제 태그와 동일하게).
   - 태그 없이 페이지만: **태그** 비우고 시작·끝 페이지만 설정.

5. **실행**  
   저장 후 실행하면, 플러그인이 목록 페이지를 순서대로 열고 각 이미지 페이지에서 큰 이미지를 다운로드합니다. 진행률은 처리한 이미지 수로 갱신됩니다.

## 주의사항

- 한 작업의 시작~끝은 100페이지 이내로.
- 끝 페이지는 시작 페이지 이상이어야 합니다.
- 태그는 사이트 표기와 완전히 일치(언어·괄호 포함)해야 결과가 나올 수 있습니다.
