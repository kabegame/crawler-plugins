# anime-pictures プラグイン説明

[anime-pictures.net](https://anime-pictures.net) からタグとページ範囲で壁紙を一括ダウンロードします。

## タグで欲しい画像を取得

1. **タスク設定を開く**  
   Kabegame で「クロールタスク」を新規作成または編集し、ソースに **anime-pictures** を選択。

2. **パラメータを設定**

   | パラメータ | 説明 |
   |------------|------|
   | **開始ページ** | 何ページ目から取得するか（0始まり）。 |
   | **終了ページ** | 何ページ目まで取得するか（その頁を含む）。1タスクあたり100ページ以内推奨。 |
   | **タグ** | サイトの検索タグ。そのタグが付いた画像のみ取得。空欄ならタグ指定なしでリストを取得。 |

3. **タグ名の調べ方**  
   [anime-pictures.net](https://anime-pictures.net) で気になる画像を開く。左上にタグ（例：「原神」「胡桃(原神)」）が表示されます。使いたいタグを選び、**タグ**欄にそのまま入力し、開始・終了ページを設定して実行。

![scsho](./scsho.png)
![hutao](./hutao.png)

4. **例**

   - 原神関連のみ、1～5ページ：**開始** `1`、**終了** `5`、**タグ** `原神` または `Genshin Impact`（サイト表記に合わせる）。
   - 特定キャラ（例：コロンビーナ）のみ：**タグ** `コロンビーナ(原神)`（サイトの実際のタグに合わせる）。
   - タグなしでページのみ：**タグ**を空欄にし、開始・終了ページを設定。

5. **実行**  
   保存して実行すると、プラグインがリスト頁を順に開き、各画像頁から大サイズをダウンロード。進捗は処理した画像数で更新されます。

## 注意事項

- 1タスクの開始～終了は100ページ以内に。
- 終了ページは開始ページ以上にしてください。
- タグはサイト表記と完全一致（言語・括弧含む）にしないと結果が出ない場合があります。
