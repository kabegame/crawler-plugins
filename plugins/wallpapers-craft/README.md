# wallpapers-craft 壁纸

本插件从 [WallpapersCraft](https://wallpaperscraft.com)（wallpaperscraft.com）抓取壁纸列表与下载链接，方便在 Kabegame 里批量浏览或下载。

## 适用场景

- 想按网站上的**分类目录**浏览（如 Anime、Nature 等）。
- 想按**标签**筛选（与网站标签页一致）。
- 需要限定**排序**或**分辨率**，减少无关结果。

## 使用前须知

- 内容版权归原网站及作者所有，请遵守其服务条款与使用习惯，合理控制抓取频率与页数。
- **结束页数**会与网站实际分页上限取较小值，避免超出站点范围。

## 选项说明

### 模式

- **目录选择**：从下方「目录」里选一个固定分类，与网站 `/catalog/...` 对应。
- **标签输入**：在「标签」里填写标签名，与网站 `/tag/...` 对应。若**留空**，则抓取全站汇总列表（相当于 `/all`），范围较大，建议配合页数限制使用。

### 目录（仅「目录选择」模式）

与网站分类一致，例如 3D、Abstract、Anime、Nature、Technologies（网站路径为 hi-tech）等，任选其一即可。

### 标签（仅「标签输入」模式）

填写网站上的标签英文标识（与标签页 URL 一致）。留空表示不按标签过滤，抓取 `/all`。

### 排序方式

- **默认**：站点默认顺序。
- **下载数量**：按热度/下载量相关排序。
- **日期**：按时间相关排序。

### 分辨率类别与具体分辨率

- **不指定**：不按分辨率过滤，列表与网站默认一致。
- **移动 / 苹果 / 全屏 / 宽屏**：先选类别，再在对应选项里选具体分辨率（如 1920×1080、3840×2160 等）。插件会只抓取该分辨率路径下的列表页。

### 起始页数 / 结束页数

从第几页抓到第几页（含两端），均为正整数，上限以插件配置为准。若网站总页数更少，实际只会抓到网站最后一页为止。

## 简要使用建议

1. 初次使用可选 **目录选择** + 常用分类（如 Anime），**结束页数**先设小一些试跑。
2. 需要某标签时改用 **标签输入**，标签名与浏览器打开该标签页时地址栏中的片段一致更稳妥。
3. 只要某种桌面宽度壁纸时，再打开 **分辨率类别** 并选对分辨率，可缩小列表噪音。
