# WallpapersCraft 壁紙

本プラグインは [WallpapersCraft](https://wallpaperscraft.com) の壁紙一覧とダウンロードリンクを取得し、Kabegame 内で一括閲覧・ダウンロードしやすくします。

## 向いている用途

- サイトの**カタログ分類**（Anime、Nature など）で見たい。
- **タグ**で絞り込みたい（サイトのタグページと同じ）。
- **並び順**や**解像度**を指定して無関係な結果を減らしたい。

## 利用前の注意

- 著作権はサイトおよび作者に帰属します。利用規約を守り、取得頻度とページ数は適切に抑えてください。
- **終了ページ**はサイト実際のページ上限と比較して小さい方に制限されます。

## オプション説明

### モード

- **カタログ選択**：下の「カタログ」から固定カテゴリを選びます。サイトの `/catalog/...` に対応します。
- **タグ入力**：「タグ」にタグ名を入力します。サイトの `/tag/...` に対応します。**空欄**の場合はサイト全体の一覧（`/all` に相当）となり範囲が広いため、ページ数制限の併用を推奨します。

### カタログ（「カタログ選択」のみ）

サイト分類と同じです。3D、Abstract、Anime、Nature、Technologies（サイトパスは hi-tech）などから選択します。

### タグ（「タグ入力」のみ）

タグページの URL と一致する英字スラッグを入力します。空欄はタグなしで `/all` 相当です。

### 並び順

- **デフォルト**：サイト既定の順序。
- **ダウンロード数**：人気・ダウンロード数に基づく並び。
- **日付**：時系列に基づく並び。

### 解像度カテゴリと具体解像度

- **指定なし**：解像度で絞り込まず、サイト既定の一覧と同じです。
- **モバイル / Apple / フルスクリーン / ワイド**：まずカテゴリを選び、続けて具体解像度（1920×1080、3840×2160 など）を選びます。その解像度パス下の一覧のみ取得します。

### 開始ページ / 終了ページ

何ページ目から何ページ目まで（両端含む）を正の整数で指定します。上限はプラグイン設定に従います。サイトの総ページ数が少ない場合は最後のページで止まります。

## 使い方のヒント

1. 初回は **カタログ選択** とよく使う分類（例：Anime）、**終了ページ**を小さめにして試す。
2. 特定タグは **タグ入力** に切り替え、ブラウザのアドレスバーのスラッグと一致させると確実です。
3. 特定のデスクトップ幅だけ欲しい場合は **解像度カテゴリ** と解像度を指定してノイズを減らせます。
