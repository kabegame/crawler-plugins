# WallpapersCraft 배경화면

이 플러그인은 [WallpapersCraft](https://wallpaperscraft.com)에서 배경화면 목록과 다운로드 링크를 가져와 Kabegame에서 일괄 탐색·다운로드하기 쉽게 합니다.

## 이럴 때 쓰면 좋음

- 사이트 **카탈로그 분류**(Anime, Nature 등)로 보고 싶을 때.
- **태그**로 필터링하고 싶을 때(사이트 태그 페이지와 동일).
- **정렬**이나 **해상도**로 범위를 줄이고 싶을 때.

## 사용 전 참고

- 저작권은 사이트 및 저작자에게 있습니다. 이용 약관을 지키고 요청 빈도와 페이지 수를 적절히 조절하세요.
- **끝 페이지**는 사이트 실제 페이지 수와 비교해 더 작은 값으로 제한됩니다.

## 옵션 설명

### 모드

- **카탈로그 선택**: 아래 「카탈로그」에서 고정 분류를 고릅니다. 사이트 `/catalog/...`에 대응합니다.
- **태그 입력**: 「태그」에 태그 이름을 입력합니다. 사이트 `/tag/...`에 대응합니다. **비워 두면** 전체 요약 목록(`/all`에 해당)으로 범위가 넓으므로 페이지 수 제한을 권장합니다.

### 카탈로그(「카탈로그 선택」 모드만)

사이트 분류와 동일합니다. 3D, Abstract, Anime, Nature, Technologies(사이트 경로는 hi-tech) 등.

### 태그(「태그 입력」 모드만)

태그 페이지 URL과 같은 영문 식별자를 입력합니다. 비우면 태그 없이 `/all`에 해당합니다.

### 정렬 방식

- **기본값**: 사이트 기본 순서.
- **다운로드 수**: 인기·다운로드 수 기준 정렬.
- **날짜**: 시간 기준 정렬.

### 해상도 범주와 구체 해상도

- **지정 안 함**: 해상도로 필터하지 않으며 사이트 기본 목록과 같습니다.
- **모바일 / Apple / 풀스크린 / 와이드**: 먼저 범주를 고른 뒤 구체 해상도(1920×1080, 3840×2160 등)를 선택합니다. 해당 해상도 경로의 목록만 가져옵니다.

### 시작 페이지 / 끝 페이지

몇 페이지부터 몇 페이지까지(양끝 포함) 양의 정수로 지정합니다. 상한은 플러그인 설정을 따릅니다. 사이트 총 페이지가 더 적으면 마지막 페이지에서 멈춥니다.

## 사용 팁

1. 처음에는 **카탈로그 선택** + 자주 쓰는 분류(예: Anime), **끝 페이지**를 작게 두고 시험 실행.
2. 특정 태그는 **태그 입력**으로 전환하고 브라우저 주소창의 조각과 맞추면 안전합니다.
3. 특정 데스크톱 폭만 필요하면 **해상도 범주**와 해상도를 지정해 목록 노이즈를 줄이세요.
