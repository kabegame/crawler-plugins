# anihonet 動漫壁紙 - 外掛說明

本外掛用於從 `anihonetwallpaper.com` 的每日排行抓取壁紙並加入下載佇列。

## 關鍵規則（手機/桌面判定）

- **手機壁紙**：圖片 URL 的**檔名**（URL 最後一段路徑）包含 `Android`（不分大小寫）
- **桌面壁紙**：不包含 `Android`

> 例：`xxx_Android_xxx.jpg` 視為手機壁紙；`xxx_PC_xxx.jpg` 視為桌面壁紙。

## 設定項

- **起始頁面（start_page）**：從第幾頁開始抓取（1–5）
- **結束頁數（end_page）**：抓取到第幾頁為止（1–5）
- **壁紙類型（wallpaper_type）**：單選，可選「桌面壁紙」（imgpc）或「手機壁紙」（sp）
- **排行榜週期（ranking_period）**：單選，可選日榜（daily）、週榜（weekly）、月榜（monthly）、年榜（annual）

## 使用建議

- 只要手機壁紙：壁紙類型選「手機壁紙」
- 只要桌面壁紙：壁紙類型選「桌面壁紙」
