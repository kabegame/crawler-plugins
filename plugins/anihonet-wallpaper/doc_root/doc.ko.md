# anihonet 애니메이션 벽지 - 플러그인 안내

이 플러그인은 `anihonetwallpaper.com`의 일일 랭킹에서 벽지를 가져와 다운로드 큐에 넣습니다.

## 규칙 (휴대폰/데스크톱 구분)

- **휴대폰 벽지**: 이미지 URL의 **파일명**(URL 마지막 경로)에 `Android`가 포함됨(대소문자 무시)
- **데스크톱 벽지**: `Android`가 포함되지 않음

> 예: `xxx_Android_xxx.jpg`는 휴대폰 벽지, `xxx_PC_xxx.jpg`는 데스크톱 벽지로 처리됩니다.

## 설정 항목

- **시작 페이지(start_page)**: 가져오기 시작 페이지 (1–5)
- **끝 페이지(end_page)**: 가져오기 끝 페이지 (1–5)
- **벽지 유형(wallpaper_type)**: 단일 선택. **데스크톱**(imgpc) 또는 **휴대폰**(sp)
- **랭킹 기간(ranking_period)**: 단일 선택. 일간(daily), 주간(weekly), 월간(monthly), 연간(annual)

## 사용 팁

- 휴대폰 벽지만: 벽지 유형에서 「휴대폰」 선택
- 데스크톱 벽지만: 벽지 유형에서 「데스크톱」 선택
