# anihonet アニメ壁紙 - プラグイン説明

このプラグインは `anihonetwallpaper.com` のデイリーランキングから壁紙を取得し、ダウンロードキューに追加します。

## ルール（スマホ/デスクトップの判定）

- **スマホ壁紙**：画像 URL の**ファイル名**（URL の最後のパス部分）に `Android` が含まれる（大文字小文字無視）
- **デスクトップ壁紙**：`Android` が含まれない

> 例：`xxx_Android_xxx.jpg` はスマホ壁紙、`xxx_PC_xxx.jpg` はデスクトップ壁紙として扱われます。

## 設定項目

- **開始ページ（start_page）**：取得開始ページ（1–5）
- **終了ページ（end_page）**：取得終了ページ（1–5）
- **壁紙タイプ（wallpaper_type）**：単一選択。「デスクトップ」（imgpc）または「スマホ」（sp）
- **ランキング期間（ranking_period）**：単一選択。日間（daily）、週間（weekly）、月間（monthly）、年間（annual）

## 使い方のヒント

- スマホ壁紙だけ：壁紙タイプで「スマホ」を選択
- デスクトップ壁紙だけ：壁紙タイプで「デスクトップ」を選択
