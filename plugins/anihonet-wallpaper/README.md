# anihonet 动漫壁纸

从 [anihonetwallpaper.com](https://anihonetwallpaper.com) 收集动漫与游戏壁纸的 Kabegame 插件，支持手机壁纸和桌面壁纸。

## 爬取模式

插件提供三种爬取模式，默认为「排行榜」。选择模式后，Kabegame 只会显示该模式需要的配置项。

### 排行榜

按排行榜周期、壁纸子类和页码范围抓取壁纸。

- 排行榜周期：日榜、周榜、月榜、年榜。
- 排行榜子类：综合、手机壁纸、高质量图片、高质量 PC 壁纸、PC 壁纸。
- 起始页面和结束页数均可设置为 `1`～`5`，默认抓取第 `1`～`5` 页。

例如，选择「日榜」和「手机壁纸」时，对应路径为 `ranking-daily-sp`。

### 单个作品

从插件内置的动漫、游戏作品列表中选择一个作品进行抓取。列表项对应站点的 `images/`、`category/` 或 `tag/` 路径。

选择「单个作品」模式后，在「作品」配置项中直接选择目标作品即可。

### 主题模式（一覧检索）

在站点的作品标题一览页中，以「主题关键字」匹配链接文案，进入第一个包含该字符串的主题，再按指定页码范围抓取。

- 主题关键字默认为空。建议输入与站点一致的日语原文，并注意大小写。
- 主题列表起始页默认为 `1`，最小值为 `1`。
- 主题列表结束页默认为 `10`，最小值为 `1`，并包含结束页。
- 如果站点已无下一页，任务会提前结束。

## 使用示例

### 抓取日榜高质量 PC 壁纸

1. 将「爬取模式」设为「排行榜」。
2. 将「排行榜周期」设为「日榜」。
3. 将「排行榜子类」设为「高质量 PC 壁纸」。
4. 设置起始页面和结束页面后运行任务。

### 抓取指定作品

1. 将「爬取模式」设为「单个作品」。
2. 在「作品」中选择目标动漫或游戏。
3. 运行任务。

### 按主题关键字抓取

1. 将「爬取模式」设为「主题模式（一覧检索）」。
2. 输入与站点链接文案一致的主题关键字。
3. 设置主题列表的起始页和结束页后运行任务。

## 开发

```bash
npm run build
```

构建产物入口为 `dist/main.js`。
