# anihonet 動漫壁紙

從 [anihonetwallpaper.com](https://anihonetwallpaper.com) 收集動漫與遊戲壁紙的 Kabegame 外掛，支援手機壁紙和桌面壁紙。

## 爬取模式

外掛提供三種爬取模式，預設為「排行榜」。選擇模式後，Kabegame 只會顯示該模式需要的設定項目。

### 排行榜

依排行榜週期、壁紙子類和頁碼範圍爬取壁紙。

- 排行榜週期：日榜、週榜、月榜、年榜。
- 排行榜子類：綜合、手機壁紙、高品質圖片、高品質 PC 壁紙、PC 壁紙。
- 起始頁面和結束頁數皆可設為 `1`～`5`，預設爬取第 `1`～`5` 頁。

例如，選擇「日榜」和「手機壁紙」時，對應路徑為 `ranking-daily-sp`。

### 單個作品

從外掛內建的動漫、遊戲作品清單中選擇一個作品進行爬取。清單項目對應網站的 `images/`、`category/` 或 `tag/` 路徑。

選擇「單個作品」模式後，在「作品」設定項目中選擇目標作品，並以「作品列表起始頁」和「作品列表結束頁」指定爬取範圍。預設爬取第 `1`～`10` 頁；外掛會在日誌中輸出輸入範圍和網站實際範圍，輸入範圍超過網站末頁時會發出警告。

### 搜尋

透過網站原生搜尋 URL 依關鍵字爬取搜尋結果，可控制排列方向、排序方式與頁碼範圍。

- 搜尋關鍵字會作為 URL 的 `s` 參數；可輸入作品名、角色名等網站可搜尋內容。
- 排列方向對應 `order=DESC|ASC`，預設為降冪。
- 排序方式對應 `orderby=post_date|rand`，預設依發布日期；隨機排序時方向不影響結果。
- 搜尋起始頁與結束頁預設為 `1`～`10`，結束頁包含在爬取範圍內。
- 外掛會讀取網站實際總頁數，略過超出末頁的範圍並寫入 warning。

## 使用範例

### 爬取日榜高品質 PC 壁紙

1. 將「爬取模式」設為「排行榜」。
2. 將「排行榜週期」設為「日榜」。
3. 將「排行榜子類」設為「高品質 PC 壁紙」。
4. 設定起始頁面和結束頁面後執行任務。

### 爬取指定作品

1. 將「爬取模式」設為「單個作品」。
2. 在「作品」中選擇目標動漫或遊戲。
3. 設定作品列表的起始頁和結束頁後執行任務。

### 搜尋壁紙

1. 將「爬取模式」設為「搜尋」。
2. 輸入搜尋關鍵字，選擇排列方向與排序方式。
3. 設定搜尋起始頁和結束頁後執行任務。

## 開發

```bash
npm run build
```

建置產物入口為 `dist/main.js`。
