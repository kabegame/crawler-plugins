# anihonet 動漫壁紙

從 [anihonetwallpaper.com](https://anihonetwallpaper.com) 收集動漫與遊戲壁紙的 Kabegame 外掛，支援手機壁紙和桌面壁紙。

## 爬取模式

外掛提供三種爬取模式，預設為「排行榜」。選擇模式後，Kabegame 只會顯示該模式需要的設定項目。

### 排行榜

依排行榜週期、壁紙子類和頁碼範圍爬取壁紙。

- 排行榜週期：日榜、週榜、月榜、年榜。
- 排行榜子類：綜合、手機壁紙、高品質圖片、高品質 PC 壁紙、PC 壁紙。
- 起始頁面和結束頁數皆可設為 `1`～`5`，預設爬取第 `1`～`5` 頁。

例如，選擇「日榜」和「手機壁紙」時，對應路徑為 `ranking-daily-sp`。

### 單個作品

從外掛內建的動漫、遊戲作品清單中選擇一個作品進行爬取。清單項目對應網站的 `images/`、`category/` 或 `tag/` 路徑。

選擇「單個作品」模式後，在「作品」設定項目中直接選擇目標作品即可。

### 主題模式（一覽搜尋）

在網站的作品標題一覽頁中，以「主題關鍵字」比對連結文案，進入第一個包含該字串的主題，再依指定頁碼範圍爬取。

- 主題關鍵字預設為空。建議輸入與網站一致的日語原文，並注意大小寫。
- 主題列表起始頁預設為 `1`，最小值為 `1`。
- 主題列表結束頁預設為 `10`，最小值為 `1`，且包含結束頁。
- 如果網站已無下一頁，任務會提前結束。

## 使用範例

### 爬取日榜高品質 PC 壁紙

1. 將「爬取模式」設為「排行榜」。
2. 將「排行榜週期」設為「日榜」。
3. 將「排行榜子類」設為「高品質 PC 壁紙」。
4. 設定起始頁面和結束頁面後執行任務。

### 爬取指定作品

1. 將「爬取模式」設為「單個作品」。
2. 在「作品」中選擇目標動漫或遊戲。
3. 執行任務。

### 依主題關鍵字爬取

1. 將「爬取模式」設為「主題模式（一覽搜尋）」。
2. 輸入與網站連結文案一致的主題關鍵字。
3. 設定主題列表的起始頁和結束頁後執行任務。

## 開發

```bash
npm run build
```

建置產物入口為 `dist/main.js`。
