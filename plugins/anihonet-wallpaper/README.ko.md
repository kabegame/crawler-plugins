# anihonet 애니메이션 벽지

[anihonetwallpaper.com](https://anihonetwallpaper.com)에서 애니메이션과 게임 벽지를 수집하는 Kabegame 플러그인입니다. 모바일 및 데스크톱 벽지를 모두 지원합니다.

## 수집 모드

세 가지 수집 모드를 제공하며 기본값은 **랭킹**입니다. 모드를 선택하면 Kabegame에는 해당 모드에 필요한 설정만 표시됩니다.

### 랭킹

랭킹 기간, 랭킹 하위 종류 및 페이지 범위에 따라 벽지를 수집합니다.

- 랭킹 기간: 일간, 주간, 월간, 연간.
- 랭킹 하위 종류: 종합, 모바일, 고품질 이미지, 고품질 PC, PC 벽지.
- 시작 페이지와 끝 페이지는 모두 `1`～`5`로 설정할 수 있으며, 기본적으로 `1`～`5`페이지를 수집합니다.

예를 들어 **일간**과 **모바일**을 선택하면 `ranking-daily-sp` 경로를 사용합니다.

### 작품 지정

플러그인에 내장된 애니메이션 및 게임 작품 목록에서 수집할 작품 하나를 선택합니다. 각 항목은 사이트의 `images/`, `category/` 또는 `tag/` 경로에 대응합니다.

**작품 지정** 모드를 선택한 후 **작품** 설정에서 원하는 작품을 선택하고 **작품 목록 시작 페이지**와 **작품 목록 끝 페이지**로 수집 범위를 지정하세요. 기본 범위는 `1`～`10`페이지입니다. 플러그인은 입력 범위와 사이트에서 감지한 실제 범위를 로그에 출력하며, 입력 범위가 사이트의 마지막 페이지를 넘으면 경고합니다.

### 검색

사이트의 기본 검색 URL을 사용하여 키워드, 정렬 방향, 정렬 기준, 페이지 범위를 지정하고 검색 결과를 수집합니다.

- 검색 키워드는 URL의 `s` 매개변수가 됩니다. 작품명, 캐릭터명 등을 입력할 수 있습니다.
- 정렬 방향은 `order=DESC|ASC`에 대응하며 기본값은 내림차순입니다.
- 정렬 기준은 `orderby=post_date|rand`에 대응하며 기본값은 게시일입니다. 무작위 정렬에서는 방향이 결과에 영향을 주지 않습니다.
- 검색 시작 및 끝 페이지의 기본값은 `1`～`10`이며 끝 페이지도 수집 범위에 포함됩니다.
- 사이트의 실제 마지막 페이지를 감지하고 초과 범위를 건너뛰며 warning을 기록합니다.

## 사용 예시

### 일간 랭킹의 고품질 PC 벽지 수집

1. **수집 모드**를 **랭킹**으로 설정합니다.
2. **랭킹 기간**을 **일간**으로 설정합니다.
3. **랭킹 하위 종류**를 **고품질 PC**로 설정합니다.
4. 시작 페이지와 끝 페이지를 설정한 후 작업을 실행합니다.

### 지정한 작품 수집

1. **수집 모드**를 **작품 지정**으로 설정합니다.
2. **작품**에서 원하는 애니메이션 또는 게임을 선택합니다.
3. 작품 목록의 시작 페이지와 끝 페이지를 설정한 후 작업을 실행합니다.

### 벽지 검색

1. **수집 모드**를 **검색**으로 설정합니다.
2. 검색 키워드를 입력하고 정렬 방향과 기준을 선택합니다.
3. 검색 시작 및 끝 페이지를 설정한 후 작업을 실행합니다.

## 개발

```bash
npm run build
```
