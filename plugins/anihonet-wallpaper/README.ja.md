# anihonet アニメ壁紙 - プラグイン説明

[anihonetwallpaper.com](https://anihonetwallpaper.com) から壁紙を取得し、ダウンロードキューに追加します。**ランキング**と**作品タイトル一覧（アニメ・ゲーム）**の2モードに対応。互換のため既定は**ランキング**です。

## 取得モード（crawl_mode）

| 値 | 説明 |
|----|------|
| **ranking**（既定） | 期間別ランキング一覧 → 各作品の詳細ページでダウンロード |
| **anime_game** | [作品タイトル一覧](https://anihonetwallpaper.com/anime-game-wallpaper) で行を選択 → テーマ一覧 → 作品詳細 → 原画リンク |

**anime_game** では **anime_game_rows** で あ・か・さ…わ 行（ページ上の `h3` の `id`：a, ka, sa, …）を選択します。

## ランキングモード

1. **開始/終了ページ**と**ランキング期間**でランキング URL を開く（例：`ranking-daily-imgpc/1`）。
2. 一覧はページ上の全 `<a href>` を順に開きます（ナビ等が含まれる場合があります）。
3. 詳細では **`a.button:not(.add)`** の `href` をダウンロードボタンとして使用（クラストークン `add` を持つものは除外。`add-dl` とは別）。

**進捗（タスク全体 100%）**：**一覧ページ均等 → ページ内各リンク均等 → 詳細内各画像均等**。スキップ後もその画像分を加算。`a` が 0 件のページはページ分を一度に加算、ボタン 0 の詳細はその作品分を一度に加算。

## 作品タイトル一覧モード

1. 一覧ページで選択行のテーマ入口 `<a href>` を解析。
2. **テーマ一覧**では **`.itiran:last-of-type > a`** の `href` を作品詳細へ（ブラウザの `$$('.itiran:last-of-type > a')` と同趣旨）。
3. 詳細では原画に **`a.button.add-dl`** を使用。

**進捗（タスク全体 100%）**：**テーマ（各一覧入口）均等 → テーマ内作品均等 → 作品内画像均等**。フィルタでスキップしてもその画像分を消費。

## 壁紙タイプとフィルタ

- **wallpaper_type**：`imgpc` はデスクトップ画像のみ、`sp` はモバイルのみ。画像 URL の**ファイル名**に `Android` が含まれるか（大文字小文字無視）で判定。
- **原画**：URL に **`resize`** が含まれるものはサムネとして**取得しません**。

## 設定一覧

| キー | 内容 | 表示 |
|------|------|------|
| **crawl_mode** | `ranking` / `anime_game` | 常時 |
| **anime_game_rows** | 行の複数選択 | anime_game のみ |
| **start_page / end_page** | 1–5 | ranking のみ |
| **ranking_period** | daily / weekly / monthly / annual | ranking のみ |
| **wallpaper_type** | imgpc / sp | 常時 |

## ヒント

- スマホ壁紙のみ：壁紙タイプで「スマホ」。
- デスクトップのみ：「デスクトップ」。
- 一覧モードは件数が大きくなりがちなので行を絞る。ログの `[anihonet]` でページと試行状況を確認できます。
