# ManyACG 插件说明

从 [ManyACG](https://manyacg.top)（二次元图库，作品来自 Pixiv 与 Twitter）抓取作品原图。每张图附带完整元数据（标题、作者、简介、标签、来源链接、尺寸），并按作者和标签建立标签画册。

## 使用前须知

- 内容版权归原作者所有，请合理设置页数与使用频率。
- 站点含 R-18 内容；默认只抓全年龄，请按需调整「内容分级」。
- 图片是站点提供的全尺寸 webp（与源站标注的宽高一致），站点不提供原始 jpg/png。

## 四种互斥模式

选定一种模式后，只有该模式列出的条件会生效，其余条件会被站点忽略，所以表单里只显示当前模式可用的项。

| 模式 | 可用条件 | 说明 |
| --- | --- | --- |
| **筛选** | 标签、作者、关键词（可同时叠加，取交集） | 按入库时间从新到旧。三个条件都留空就是「最新」 |
| **语义搜索** | 关键词（必填） | 按语义相近程度找图，不要求字面匹配。站点最多返回 1000 条（20 页） |
| **相似作品** | 参考作品 | 找与某个作品画风或角色相近的作品，没有天然终点，请把页数范围取小一些 |
| **随机** | 数量（1–200） | 随机抽取，不能翻页，每次结果都不同 |

「内容分级」对四种模式都生效：全年龄 / 仅 R-18 / 混合。

## 条件怎么填

- **标签**：完整的标签名，只能填一个，如 `原神`、`genshin_impact`。站点不支持多标签组合，填多个会搜不到结果。
- **作者**：粘贴作者页链接（`manyacg.top/artist/…`）或 24 位作者 ID。Pixiv / Twitter 的用户 ID 不能用。作者 ID 可以在作品详情的「作者」按钮链接里看到。
- **关键词**：匹配标题、简介和标签。
- **参考作品**：粘贴作品页链接（`manyacg.top/artwork/…`）或 24 位作品 ID。
- **页数**：每页 50 个作品；站点没有更多结果时会提前结束。同一任务内重复出现的作品（语义搜索的相邻页会有少量重复）只下载一次。

## 元数据与标签

- 每个作品的多张图共用一份元数据；详情面板还原站点详情页的版式：标题、作者与来源按钮、简介（链接可点击）、标签、入库时间、各图尺寸。
- 标签画册：作者归在 `manyacg/artist`（以平台 + UID 作 key，改名后不会分裂），站点标签归在 `manyacg/tag`。站点标签中英日文混杂，显示名始终是站点原文，key 按下面的顺序生成：纯英文标签直接作 key；含汉字的转成拼音（如 `原神` → `yuan-shen`，与哲风壁纸同款，不保证多音字，同音不同字的标签会合并）；假名、韩文、emoji 等无法转拼音的，确定性编码成 `u-…`。
