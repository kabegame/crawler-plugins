# Danbooru 이미지 보드 — 플러그인 설명

Danbooru(기본값은 전체 이용가 사이트 `donmai.moe`)의 작품을 다운로드 큐에 담고, **게시물 페이지의 전체 태그를 이미지 메타데이터로 저장**합니다.
태그는 분류별로 앱의 「태그」(`danbooru/<분류>`)에 등록되어 앨범 화면에서 탐색하거나 검색에서 태그로 필터링할 수 있습니다.

## 크롤 모드

- **태그**: `/posts?tags=...` 태그 검색 (가장 많이 쓰는 모드)
- **인기 순위**: `/explore/posts/popular` 의 일간 / 주간 / 월간
- **전체**: `/posts` 의 사이트 전체 최신 작품

## 설정 항목

- **소스 사이트**: `donmai.moe`(기본값, 전체 이용가만) 또는 `danbooru.donmai.us`(전체)
- **태그 조합**: 목록 입력. 실행 시 공백으로 결합하며 태그 내 공백은 `_` 로 바뀝니다
- **인기 순위 기간**: 일간 / 주간 / 월간
- **시작 페이지 / 끝 페이지**: 실행당 최대 100페이지
- **페이지당 개수**: 20 / 50 / 100 / 200
- **등급 필터**: 제한 없음 / 전체 이용가(General) / 민감(Sensitive) / 애매함(Questionable) / 노골적(Explicit). 소스 사이트가 전체일 때만 표시됩니다. 전체·태그 모드는 `rating:g` 같은 메타태그를 검색 문자열에 붙이며, 이는 「태그 최대 2개」 제한에 **포함되지 않습니다**. 인기 순위 모드는 플러그인이 작품별 등급으로 거릅니다
- **화질**
  - **고화질**: 원본 직링크 (수십 MB인 게시물도 있습니다)
  - **중간**: 사이트가 축소한 sample. 동영상 게시물은 sample 이 없어 원본으로 대체됩니다

## 메타데이터

모든 이미지는 게시물 페이지에서 파싱한 메타데이터를 가지며, 상세 사이드바는 `description.ejs` 로 렌더링됩니다:

- `tags_string`: **전체 태그 문자열** (작가 → 저작권 → 캐릭터 → 일반 → 메타 순)
- `tags`: 태그별 `name` / `display` / `type` / `count` / 검색 링크 / wiki 링크
- `tags_by_type`: 카테고리별로 묶은 태그 이름 배열
- `post_id`, `rating`, `score`, `fav_count`, `status`
- `file_size`, `file_ext`, `width`, `height`, `original_href`, `sample_href`
- `uploader_name` / `uploader_href`, `posted_date_iso`, `source_href`
- `commentary`: 작가 코멘트의 제목과 본문

또한 PathQL provider 를 등록하므로 갤러리에서 **점수(score) / 즐겨찾기 수(favorites) / 등급(rating)** 으로 필터링할 수 있습니다. 등급은 General / Sensitive / Questionable / Explicit 으로 나뉘며, 점수와 즐겨찾기 수 목록에는 `5+`, `10+` … `1000+` 같은 「이 값 이상」 구간이 나오며, 경로 세그먼트에는 범위 표기 `100-500`, `100+`, `-50`(양 끝 포함)도 쓸 수 있습니다.

## 주의 사항

- **사이트는 비로그인/일반 계정의 검색당 태그를 2개로 제한합니다.** 세 번째 태그를 넣으면 WARN 이 뜨고
  사이트는 대개 빈 결과를 반환합니다. 畅游(Surf)에서 로그인하고 계정 등급을 올리세요.
- **예의 있게 크롤하세요**: 실행당 최대 100페이지, 끝 페이지는 시작 페이지 이상이어야 합니다.
- 기본 소스 `donmai.moe` 는 전체 이용가 게시물만 제공합니다(`rating:e` 로 검색해도 결과가 없습니다). `danbooru.donmai.us` 는 성인 콘텐츠를 포함하며, 비로그인 상태에서는 사이트 기본 규칙으로 필터링됩니다.
- 보통 프록시 네트워크가 필요합니다.
- 기본 소스 `donmai.moe` 에는 Cloudflare 검증이 있습니다(전체 사이트 `danbooru.donmai.us` 는 필요 없음). 처음 사용할 때(또는 검증이 만료된 뒤)에는 「서핑」에서 `donmai.moe` 를 열어 검증을 통과하세요. 플러그인은 서핑의 Cookie와 브라우저 식별자를 이어받으며, 차단되면 오류로 안내합니다.
- mp4 / webm 동영상 게시물은 원본 직링크로 다운로드합니다.

즐겁게 사용하세요~
