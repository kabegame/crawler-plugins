# Danbooru 更新日志

## 1.0.0

首个版本。

- 四种爬取模式：标签、人气榜（日/周/月）、全部、标签列表
- 源站可切换 `danbooru.donmai.us` / `safebooru.donmai.us`
- 质量分高（原图直链）/ 中（站点 sample），视频帖自动回落原文件
- 每页条数可选 20 / 50 / 100 / 200
- **全量标签元数据**：`tags_string` 直接可用作 AI 生图 prompt，侧栏一键复制；
  另存每个标签的分类、作品数和站内链接
- 详情侧栏模板 `description.ejs`：按 作家 / 版权 / 角色 / 通用 / 元信息 分组着色，
  附统计信息与画师评论
- PathQL provider：画廊里按 标签分类 → 标签 两级浏览已下载的图

祝你使用愉快～
