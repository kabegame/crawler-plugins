# wallspic プラグイン

本プラグインは [wallspic.com](https://wallspic.com) の壁紙一覧を取得し原寸に近い画像をダウンロードします。Kabegame でアルバムまたはタグ単位の一括収集向けです。

## 向いている用途

- **アルバムモード**：サイトのアルバム分類（Anime、Nature、Technology など）で一覧を見る。
- **タグモード**：タグページを取得（サイトの `/tag/...` と同じ）。
- **並び順**、**端末／解像度**、**ページ範囲**を限定したい場合。

## 利用前の注意

- 著作権はサイトおよび作者に帰属します。利用規約を守り、ページ数と頻度は適切に設定してください。
- **終了ページ**はスクリプトが読み取ったサイト側の最大ページと比較して小さい方に制限されます。

## オプション説明

### モード

- **アルバム**：下の「アルバムカテゴリ」を使用。パスは `/album/{スラッグ}`。**すべてのカテゴリ**はトップの一覧です。
- **タグ**：「タグキーワード」にタグ名（タグ URL の英字スラッグ）を入力。**空欄**はトップ一覧（範囲が広いのでページ制限推奨）。

### アルバムカテゴリ（アルバムモードのみ）

wallspic のアルバムと一致（Brands、Anime、Games、Nature など）。

### タグキーワード（タグモードのみ）

例：`anime`。ブラウザのタグページ URL のタグ部分と一致させます。

### 並び順

- **New**：既定（新着。パスに `popular` を付けない）。
- **Popular**：人気（パスに `popular` を含む）。

### 解像度モード

- **すべての壁紙**：解像度で絞り込まない。
- **モバイル／デスクトップ**：サイトのモバイル／デスクトップ用パスを使用。
- **指定解像度**：**解像度プリセットグループ**（Ultra HD / Apple / Android / Widescreen）を選び、続けて具体サイズを選ぶ。一覧 URL に対応するスラッグが付きます。

### 開始ページ／終了ページ

何ページから何ページまで（両端含む）。実効上限はプラグインの max とサイトのページ数です。

## ヒント

1. 初回は **アルバム**＋よく使うカテゴリ、**終了ページ**は小さめに。
2. 特定タグは **タグ**モードで URL スラッグと一致させる。
3. 特定解像度だけ欲しい場合は **指定解像度**でグループとサイズを選ぶ。
