# wallspic 插件说明

本插件从 [wallspic.com](https://wallspic.com) 抓取壁纸列表并下载原图，适合在 Kabegame 中按专辑或标签批量收集。

## 适用场景

- **专辑模式**：按网站「专辑」分类（如 Anime、Nature、Technology）浏览列表。
- **标签模式**：按标签页抓取（与站点 `/tag/...` 一致）。
- 需要限定 **排序**、**设备/分辨率**，或控制 **页码范围**。

## 使用前须知

- 内容版权归原网站及作者所有；请遵守服务条款，合理设置页数与使用频率。
- **结束页数**会与脚本解析到的站点最大页数取较小值，避免无效请求。

## 选项说明

### 模式

- **专辑模式（Album）**：使用下方「专辑分类」；路径为 `/album/{分类}`。选 **All categories** 时从站点首页列表抓取。
- **标签模式（Tag）**：在「标签关键词」填写标签名（英文 slug，与标签 URL 一致）。**留空**时从首页列表抓取（范围大，建议限制页数）。

### 专辑分类（仅专辑模式）

与 wallspic 站点专辑一致，例如 Brands、Anime、Games、Nature 等；任选其一。

### 标签关键词（仅标签模式）

例如 `anime`。须与浏览器打开该标签页时地址栏中的标签段一致。

### 排序

- **New**：默认（新图优先，对应路径中不附加 `popular`）。
- **Popular**：热门排序（URL 中会加入 `popular` 段）。

### 分辨率模式

- **All wallpapers**：不按分辨率过滤。
- **Mobile / Desktop**：使用站点对应的移动或桌面壁纸路径。
- **Specific resolution**：先选 **具体分辨率分组**（Ultra HD / Apple / Android / Widescreen），再在该组下选择具体尺寸；插件会把对应 slug 拼进列表 URL。

### 起始页数 / 结束页数

从第几页抓到第几页（含两端）。实际上限受插件 `max` 与站点分页共同约束。

## 使用建议

1. 初次使用可选 **专辑模式** + 常见分类，**结束页数**设小一些试跑。
2. 追某标签时用 **标签模式**，关键词与 URL 一致最稳妥。
3. 只要某种分辨率壁纸时，开启 **Specific resolution** 并选对分组与尺寸，可减少无关条目。
