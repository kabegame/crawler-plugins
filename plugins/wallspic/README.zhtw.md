# wallspic 外掛說明

本外掛從 [wallspic.com](https://wallspic.com) 擷取桌布清單並下載原圖，適合在 Kabegame 中依專輯或標籤批次收集。

## 適用情境

- **專輯模式**：依網站「專輯」分類（如 Anime、Nature、Technology）瀏覽清單。
- **標籤模式**：依標籤頁擷取（與站點 `/tag/...` 一致）。
- 需要限定 **排序**、**裝置／解析度**，或控制 **頁碼範圍**。

## 使用前須知

- 內容版權歸原網站及作者所有；請遵守服務條款，合理設定頁數與使用頻率。
- **結束頁數**會與腳本解析到的站點最大頁數取較小值，避免無效請求。

## 選項說明

### 模式

- **專輯模式（Album）**：使用下方「專輯分類」；路徑為 `/album/{分類}`。選 **All categories** 時從站點首頁清單擷取。
- **標籤模式（Tag）**：在「標籤關鍵字」填寫標籤名（英文 slug，與標籤 URL 一致）。**留空**時從首頁清單擷取（範圍大，建議限制頁數）。

### 專輯分類（僅專輯模式）

與 wallspic 站點專輯一致，例如 Brands、Anime、Games、Nature 等。

### 標籤關鍵字（僅標籤模式）

例如 `anime`。須與瀏覽器開啟該標籤頁時網址列中的標籤段一致。

### 排序

- **New**：預設（新圖優先，路徑中不附加 `popular`）。
- **Popular**：熱門排序（URL 中會加入 `popular` 段）。

### 解析度模式

- **All wallpapers**：不依解析度過濾。
- **Mobile / Desktop**：使用站點對應的行動或桌面桌布路徑。
- **Specific resolution**：先選 **具體解析度分組**（Ultra HD / Apple / Android / Widescreen），再於該組選具體尺寸；外掛會把對應 slug 拼進清單 URL。

### 起始頁數／結束頁數

從第幾頁擷取到第幾頁（含兩端）。實際上限受外掛 `max` 與站點分頁共同約束。

## 使用建議

1. 初次使用可選 **專輯模式**＋常見分類，**結束頁數**設小一點試跑。
2. 追某標籤時用 **標籤模式**，關鍵字與 URL 一致最穩妥。
3. 只要某種解析度桌布時，開啟 **Specific resolution** 並選對分組與尺寸，可減少無關項目。
