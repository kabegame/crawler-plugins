# 米游社（Miyoushe）怎麼把圖片收進畫冊

下面說明的是：**當你想把米游社裡喜歡的圖片收進 Kabegame 時，整體流程會怎麼進行**。照順序閱讀，基本上就能知道每一步在做什麼、要填哪些參數，以及遇到問題時該去哪裡查看。

## 一、先選好「怎麼找貼文」

目前有三種用法，請選擇其中一種：

### 1. 依關鍵字搜尋（找一類圖片時使用）

1. **爬取模式**選擇「關鍵字搜尋」。
2. **搜尋關鍵字**填入想搜尋的詞，例如「壁紙」「cosplay」「角色名稱」等。
3. **遊戲分區**（`gids`）依需要選擇：
   - 選擇「全站」會在更大的範圍中搜尋。
   - 選擇對應遊戲分區時，更容易聚焦到需要的討論區。
4. **起始頁／結束頁／每頁筆數**：
   - 翻頁越多，處理時間越長，建議先用小範圍測試。
   - `page_size` 是每頁取得多少篇貼文，程式會過濾沒有圖片的貼文。

### 2. 只爬取一篇貼文（已知貼文連結時使用）

1. **爬取模式**選擇「單篇貼文 URL」。
2. **貼文 URL**直接貼上米游社文章連結：
   - 外掛只需要從連結中擷取 `post_id`。
   - 連結範例：`https://www.miyoushe.com/{遊戲}/article/{id}`

### 3. 依作者 UID 爬取（知道作者 UID 時使用）

1. **爬取模式**選擇「作者貼文列表」。
2. **作者 UID**填入米游社使用者 UID。這是一串數字，可從作者個人頁面 URL 取得。

![作者個人頁面](./user-page.png)

3. **起始頁／結束頁／每頁筆數**與關鍵字搜尋模式相同：
   - 預設爬取第 1～3 頁，每頁 20 篇；可依需要調整。
   - 建議先用小範圍（例如 1 頁）測試。

## 二、找到貼文後，圖片是怎麼收進來的

無論是搜尋出來的，還是直接指定的，程式都會經過下面這套資料流程：

1. **取得貼文詳情（`getPostFull`）**
   - 取得貼文主體資訊。
   - 重點是取得內文圖片清單，包括 `post.images` 與 `post.content` 中對應的圖片。
2. **取得表情集合（`emoticon_set`）**
   - metadata 中只儲存內文（`subject/content`）實際使用到的必要表情對照。
   - 開啟圖片詳情頁後，會再動態取得完整表情集合，用於留言區表情顯示。
3. **取得留言（`getPostReplies`）**
   - metadata 不再儲存留言內容。
   - 圖片詳情頁會動態取得留言，首屏 20 筆，可點選「載入更多」。
   - 爬取時，留言 API 僅用於統計與下載留言圖片，並依留言上限持續取得。
4. **下載圖片並寫入畫冊**
   - 內文圖片：只要貼文確實有圖片，就一定會下載。
   - 留言圖片：僅在 `fetch_comment_images = true` 時下載。
   - 進度條會依內文圖片＋留言圖片的總數平均分配。

## 三、偶爾可能遇到的情況

- **貼文沒有圖片：**程式會跳過該貼文，只處理有圖片的貼文。
- **API 偶發異常：**可以嘗試切換網路，或稍等後重試。
- 遇到 API 異常時，稍後重試通常可以解決。

## 四、參數一覽

| 名稱 | 顯示時機 | 作用 |
| --- | --- | --- |
| 爬取模式 | 始終 | 關鍵字搜尋／單篇貼文 URL／作者貼文列表 |
| 貼文 URL | 單篇貼文模式 | 貼上貼文連結，自動擷取 `post_id` |
| 作者 UID | 作者貼文列表 | 需要爬取的作者 UID |
| 搜尋關鍵字 | 關鍵字搜尋 | 搜尋內容（關鍵字） |
| 遊戲分區 | 關鍵字搜尋 | 選擇對應 `gids` 分區（可選） |
| 起始頁（從 1 起） | 關鍵字搜尋／作者貼文列表 | 從第幾頁開始爬取 |
| 結束頁（含） | 關鍵字搜尋／作者貼文列表 | 爬取到哪一頁（包含該頁） |
| 每頁筆數 | 關鍵字搜尋／作者貼文列表 | 每頁取得多少篇貼文 |
| 下載留言區圖片 | 始終 | 開啟：內文＋留言圖片；關閉：僅內文 |
| 留言取得上限（`max_comments`） | 始終 | 爬取階段最多取得多少筆留言（預設 200） |
