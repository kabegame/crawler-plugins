# 米游社（miyoushe）怎么把图收进画册

下面说的是：**你想从米游社把喜欢的图弄进 Kabegame 时，整体上会怎么走**。照这个顺序看，你基本就知道每一步在干嘛、要填哪些参数、遇到问题往哪看。

## 一、先选好「怎么找帖子」

目前有三种用法（三选一）：

### 1. 按关键词搜（找一类图时用）

1. **爬取模式** 选「关键词搜索」。
2. **搜索关键词** 填你想搜的词（比如“壁纸”“cosplay”“角色名”等）。
3. **游戏分区**（`gids`）按需选：
   - 选“全站”就会在更大范围里搜
   - 选对应游戏分区时，更容易聚焦到你要的板块哦
4. **起始页 / 结束页 / 每页条数**：
   - 翻页越多，处理耗时也越久（建议先小范围试一试）
   - `page_size` 是每页拉多少条帖子（程序会过滤“没图”的帖子）

### 2. 只抓一篇帖子（你已知帖子链接时用）

1. **爬取模式** 选「单帖子 URL」。
2. **帖子 URL** 直接粘贴米游社文章链接：
   - 插件只需要从链接里提取 `post_id`
   - 链接示例形如：`https://www.miyoushe.com/{游戏}/article/{id}`

### 3. 按作者 UID 抓（你知道作者 UID 时用）

1. **爬取模式** 选「作者帖子列表」。
2. **作者 UID** 填米游社用户 UID（数字串，可从作者主页 URL 获取）。

![user-page](./user-page.png)

3. **起始页 / 结束页 / 每页条数** 同关键词搜索模式：
   - 默认抓第 1～3 页，每页 20 条；视需要调整
   - 建议先小范围（1 页）测试

## 二、找到帖子以后，图是怎么被收进来的

不管是搜出来的，还是你指定的，程序都会走下面这套“数据流”：

1. **拉帖子详情（getPostFull）**
   - 拿到帖子主体信息
   - 关键是拿到正文图片列表（`post.images` / `post.content` 里对应的图片）
2. **拉表情集合（emoticon_set）**
   - 元数据里只保存正文（`subject/content`）里实际用到的必要表情映射
   - 图片详情页打开后会再动态拉全量表情，用于评论区表情展示
3. **拉评论（getPostReplies）**
   - 元数据不再保存评论内容
   - 图片详情页会动态拉评论（首屏 20 条，可点“加载更多”）
   - 爬取时评论接口仅用于统计/下载评论图片（按评论上限持续拉取）
4. **下载图片并写入画册**
   - 正文图片：总是下载（前提是该帖子确实有图片）
   - 评论图片：仅在 `fetch_comment_images = true` 时下载
   - 进度条会按正文图 + 评论图的总数做均分

---

## 三、偶尔可能会遇到的情况

- **帖子没配图**：程序会跳过这条帖子（只处理“有图片”的帖子）。
- **接口偶发异常**：可以尝试换网络或稍等后重试。
 - 如遇接口异常：稍等后重试通常可以解决。

## 四、参数一览

| 名称 | 何时出现 | 作用 |
| --- | --- | --- |
| 爬取模式 | 始终 | 关键词搜索 / 单帖子 URL / 作者帖子列表 |
| 帖子 URL | 单帖子模式 | 粘贴帖子链接，自动提取 `post_id` |
| 作者 UID | 作者帖子列表时 | 需要爬取的作者 UID |
| 搜索关键词 | 关键词搜索时 | 搜什么（关键字） |
| 游戏分区 | 关键词搜索时 | 选择对应 `gids` 分区（可选） |
| 起始页（从 1 起） | 关键词搜索 / 作者帖子列表时 | 从第几页开始抓 |
| 结束页（含） | 关键词搜索 / 作者帖子列表时 | 抓到哪一页（包含） |
| 每页条数 | 关键词搜索 / 作者帖子列表时 | 每页拉多少条帖子 |
| 下载评论区图片 | 始终 | 打开后：正文 + 评论图；关闭：仅正文 |
| 评论拉取上限（`max_comments`） | 始终 | 爬取阶段最多拉取多少条评论（默认 200） |
