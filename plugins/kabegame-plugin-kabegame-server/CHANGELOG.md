# 更新日志

## 0.2.3

- 任务日志与参数校验错误会跟随 Kabegame 的界面语言显示，支持简体中文、English、日本語、한국어与繁體中文。

## 0.2.2

- 过滤模式的 PathQL 路径改为必填；模式、排序也不能清空，留空时不再启动任务。
- 可选项留空时按未填写处理：清空「每页数量」按默认 20 张，而不是每页 1 张。

## 0.2.1

- 适配 Kabegame 4.5.1 起的新 PathQL 续接语法（`_kb_fc` / `_kb_desc` / `_kb_x<N>x`）：运行前自动探测服务器版本，新旧服务器都能复制，修复连 4.5.1+ 服务器时每页都报 `path not found`。
- 过滤模式同时识别两种写法的分页尾；粘贴的路径来自另一版本的服务器时，自动改写组合与倒序段。

## 0.2.0

- 每页数量默认 20、最多 100；一次最多 10 页，超过则拒绝执行。
- 新增「过滤」模式：粘贴「高级查询」弹窗里的 PathQL 路径，按其排序分页复制命中的图片。
- 「全站」模式新增排序：随机（默认，每次运行自动生成种子）、时间（最新在前）、ID 升序。

## 0.1.0

- 按服务器图片 id 升序分页复制图片（每页最多 1000 张），连同元数据、标签与帖子地址。
- 详情面板执行来源插件自己的详情模板，并缓存来源插件的私有数据。
