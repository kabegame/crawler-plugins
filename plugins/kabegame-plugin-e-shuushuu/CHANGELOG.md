# 更新日志

## 0.3.2

- 「模式」「排行范围」，以及搜索 URL 模式的「搜索 URL」改为必填，留空时在启动前就会提示，不再运行后才报错。

## 0.3.1

- 新增元数据搜索：上传者名与头衔、发布日期（年 / 月 / 日分别可搜）、标签、ID、收藏数、来源和评论都能被「元数据」范围搜到，历史图片会在升级后自动补上。

## 0.3.0

- 新增「搜索 URL」模式：粘贴站点搜索页（`/search?…`）的地址，按起止页抓取，结果与网页显示一致。

## 0.2.0

- 新增「排行榜」模式：与站点 Top Rated 的四个范围（全部时间 / 今年 / 本月 / 本周）一致，最多 20 页。
- 评论随列表接口一并返回，不再逐张请求评论。

## 0.1.0

- 主页翻页抓取原图，附带完整元数据、分类标签画册与还原源站样式的详情模板。
