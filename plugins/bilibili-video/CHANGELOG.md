# bilibili 视频更新日志

## 0.2.0

- 新增「番剧 / 剧集」模式：支持单集（`ep21495`）、整季（`ss26801`）、剧集页（`md24097891`）或对应完整链接，类型自动识别。
- 整季按正片列表批量下载（不含 PV / 花絮），用「起始集数」定位、「最多下载数」截断；单集也支持声优节目、预告等花絮的独立 ep 页。
- 大会员专享集在无权观看时明确跳过并提示（试看片段不入库）；地区限制内容直接报错说明原因。
- 把番剧链接误填进「单个视频」时，会提示切换到「番剧」模式而不是笼统报错。

## 0.1.0

- 首个版本：单个视频（BV/av 号，多分 P）、UP 主投稿、合集 / 系列 / 收藏夹、关键词搜索四种模式；DASH 音视频分离流分块下载后合流为 MP4 入库。
