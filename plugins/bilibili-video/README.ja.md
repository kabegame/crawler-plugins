# bilibili 動画

bilibili の動画をダウンロードします。分離された映像・音声ストリームを分割取得し、MP4 に結合してライブラリへ保存します。

## 使用例：アニメをダウンロードする

ここでは『有頂天家族』第1期（`ss507`）の最初の3話をダウンロードします。

1. bilibili で対象のアニメを開き、右側の「本編」リストにダウンロードしたい話が含まれていることを確認します。
   ブラウザのアドレスバーからアニメの URL をコピーします。この例では
   [https://www.bilibili.com/bangumi/play/ss507](https://www.bilibili.com/bangumi/play/ss507) を使用します。

   ![bilibili のアニメ再生ページと本編リスト](banners/bangumi-page.jpg)

2. Kabegame でダウンロードタスクを新規作成し、ソースに「bilibili 動画」を選んでプラグインを設定します。

   - 「モード」は「アニメ / エピソード」を選択します。
   - 「アニメの URL または ID」に完全な URL を貼り付けます。`ss507` だけを入力してもかまいません。
   - 「開始話数」を `1`、「最大本数」を `3` にすると、本編の第1話から3話分をダウンロードします。
   - 「画質上限」は `1080P` を選び、再生互換性を高めるため「H.264 を優先」を有効のままにします。
   - 「待機秒数」と「リトライ回数」は、初期値の `10` と `1` のままで使用できます。

   出力ディレクトリと出力アルバムは必要に応じて選択してください。空欄の場合は Kabegame の既定の場所を使用します。

   ![アニメをダウンロードするためのプラグイン設定](banners/bangumi-params.jpg)

3. タスクを開始します。プラグインが本編リストを読み込み、最初の3話を順番にダウンロードし、分離された
   映像・音声ストリームを MP4 に結合してギャラリーへ追加します。完了すると、ソースページに3本の動画が表示されます。

   ![ダウンロードされた3話分のアニメ](banners/downloads.jpg)

4. 動画を選択すると、詳細を開いてそのまま再生できます。サムネイルだけが表示されて再生できない場合は、
   ダウンロード時に「H.264 を優先」が有効だったか確認してください。HEVC と AV1 の対応状況はプラットフォームによって異なります。

   ![Kabegame でダウンロード済みのアニメを再生](banners/view.jpg)

## モード

### 単一動画

「動画 ID または URL」に次のいずれかを入力します。

- `BV13x41117TL`
- `av1074402`
- `https://www.bilibili.com/video/BV13x41117TL`

複数パートの動画は「パート番号」で対象を選択します。`0` を入力すると全パートをダウンロードします。

### 投稿者の動画

「投稿者 UID またはマイページ URL」に UID（`3985676`）またはプロフィール URL
（`https://space.bilibili.com/3985676`）を入力します。リストは1ページ30本で、「開始ページ / 終了ページ」で範囲を指定します。

**「最大本数」の初期値は 5**です。これは意図的に控えめな設定です。1ページには30本あり、1080P の動画は
1本で数百 MB になるため、1ページだけで数 GB に達することがあります。範囲を確認してから増やしてください。

このモードでは、各投稿の **P1 だけをダウンロード**します。そうしないと、23パートある投稿から一度に23ファイルが作成されます。

### コレクション / シリーズ / お気に入り

「リストページ URL」に完全な URL を貼り付けます。**種類は自動判別**されます。

| 種類 | URL の形式 |
| --- | --- |
| コレクション | `space.bilibili.com/<UID>/lists/<ID>`（または `?type=season`） |
| コレクション（旧形式） | `space.bilibili.com/<UID>/channel/collectiondetail?sid=<ID>` |
| シリーズ | `space.bilibili.com/<UID>/lists/<ID>?type=series` |
| シリーズ（旧形式） | `space.bilibili.com/<UID>/channel/seriesdetail?sid=<ID>` |
| お気に入り | `space.bilibili.com/<UID>/favlist?fid=<ID>` |
| お気に入り（短縮 URL） | `bilibili.com/medialist/detail/ml<ID>` |

コレクションとシリーズには **space の完全な URL** が必要です。API が投稿者 UID とリスト ID の両方を必要とするため、
ID だけでは取得できません。

お気に入りの API はページ分けをせず、全項目を一度に返します。このモードでは「開始ページ」を1ページ30件として
開始位置に換算し、「最大本数」で件数を制限します。音声や記事など動画以外の項目は通知を出してスキップします。
非公開のお気に入りを取得するには、Kabegame のサーフで**所有者本人として**ログインしてください。

このモードでも各投稿の P1 だけをダウンロードします。

### キーワード検索

「検索キーワード」を入力します。`search.bilibili.com` の**動画**タブと同等です。並び順
（関連度 / 再生数 / 新着 / 弾幕数 / お気に入り数）と再生時間を指定できます。検索結果は1ページ20件です。

**再生時間フィルターの併用を推奨します。** 1080P 動画は1時間で 1 GB を超えることがあり、検索では長時間動画も
簡単に対象になります。ライブ配信やアニメなど通常投稿以外の結果は自動的に除外され、ページをまたぐ重複投稿も取り除かれます。

このモードでも各投稿の P1 だけをダウンロードします。

### アニメ / エピソード

「アニメの URL または ID」に次のいずれかを入力します。**種類は自動判別**されます。

| 種類 | 形式 |
| --- | --- |
| 単一エピソード | `ep21495` または `bilibili.com/bangumi/play/ep21495` |
| シーズン全体 | `ss26801` または `bilibili.com/bangumi/play/ss26801` |
| 作品ページ | `md24097891` または `bilibili.com/bangumi/media/md24097891` |

アニメには、通常投稿とは完全に別の PGC 再生 API を使用します。WBI 署名は不要です。

- **単一エピソード（`ep`）**：その1話だけをダウンロードします。特典映像、PV、キャスト番組などの
  セクション項目にも個別の `ep` ページがあり、同様に対応しています。
- **シーズン全体（`ss` / `md`）**：PV や特典映像を除く**本編リスト**を一括ダウンロードします。
  「開始話数」で開始位置を指定し、「最大本数」で件数を制限します。作品ページ（`md`）は先に対応するシーズンへ変換されます。

次のコンテンツは使用不能なファイルを保存せず、明示的にスキップまたはエラーとして処理されます。

- **プレミアム会員限定エピソード**：視聴権限がない場合、API は6分間のプレビューしか返しません。プレビューはライブラリへ
  追加せず、その話を通知付きでスキップします。プレミアム会員の場合は、先に Kabegame のサーフで bilibili にログインしてください。
- **地域制限**：香港・マカオ・台湾または海外限定のコンテンツを対象外の地域から取得すると、エラーを表示します。
- 無料エピソードと解放済みエピソードは通常どおりダウンロードし、画質の選択規則も通常動画と同じです。

## 画質とログイン

bilibili で利用できる画質はログイン状態によって変わります。

| 状態 | 利用できる画質 |
| --- | --- |
| 未ログイン | プレビュー経由でも通常は 1080P を取得可能 |
| ログイン済み | 安定して 1080P を取得可能 |
| プレミアム会員 | 4K / HDR / Dolby |

Cookie は **Kabegame のサーフ**から取得します。4K や HDR が必要な場合は、先にサーフで bilibili にログインしてから
このプラグインを実行してください。「画質上限」は、その設定を超えない範囲で利用可能な最高画質を選ぶため、実際の画質が
設定より低くなる場合があります。

「H.264 を優先」は初期状態で有効です。`avc1` コーデックを優先し、ギャラリーで直接再生しやすくします。無効にすると
画質が優先され、HEVC や AV1 になることがあります。プラットフォームによっては、ライブラリへ追加後にサムネイルだけが
表示され、直接再生できない場合があります。

## 待機時間とリトライ

「待機秒数」（初期値 10）は、動画間、リストのページ間、失敗後のリトライ前に適用されます。
「リトライ回数」（初期値 1）は1本の動画が失敗したときの再試行上限で、`0` にすると再試行しません。

投稿者一覧 API の不正利用対策は再生 API よりはるかに厳しく、待機時間を短くすると簡単に制限されます。
`412` / `-401` / `-352` が返された場合、この種のブロックは再試行しても効果がないため、プラグインはタスクを直ちに
終了します。時間を置いて再試行するか、先に Kabegame のサーフで bilibili にログインしてください。コレクション、
シリーズ、お気に入りの API は署名が不要で、制限も比較的緩やかです。

## 制限事項

- **講座とライブ配信には対応していません**（`/cheese/`、`live.bilibili.com`）。これらは別の再生 API を使用します。
  本プラグインが処理するのは通常投稿とアニメです。
- **非表示モードのコレクションはスキップします。** 投稿者一覧では中の動画が展開されず、必要なコレクション API は
  現在未対応です。警告を記録してスキップします。
- 映像と音声は元のコーデックのまま stream copy で結合し、再エンコードしないため、所要時間の大部分は通信時間です。
