# bilibili 동영상

bilibili 동영상을 다운로드합니다. 분리된 영상·음성 스트림을 청크 단위로 받아 MP4로 병합한 뒤 라이브러리에 저장합니다.

## 사용 예시: 애니메이션 다운로드

아래에서는 《유정천 가족》 시즌 1(`ss507`)의 처음 3화를 다운로드합니다.

1. bilibili에서 다운로드할 애니메이션을 열고, 오른쪽의 「본편」 목록에 원하는 화가 있는지 확인합니다.
   브라우저 주소 표시줄에서 애니메이션 링크를 복사합니다. 이 예시에서는
   [https://www.bilibili.com/bangumi/play/ss507](https://www.bilibili.com/bangumi/play/ss507)을 사용합니다.

   ![bilibili 애니메이션 재생 페이지와 본편 목록](banners/bangumi-page.jpg)

2. Kabegame에서 새 다운로드 작업을 만들고 소스로 「bilibili 동영상」을 선택한 다음 플러그인을 설정합니다.

   - 「모드」는 「애니메이션 / 에피소드」를 선택합니다.
   - 「애니메이션 URL 또는 ID」에 전체 링크를 붙여 넣습니다. `ss507`만 입력해도 됩니다.
   - 「시작 화수」를 `1`, 「최대 개수」를 `3`으로 설정하면 본편 1화부터 3화를 다운로드합니다.
   - 「최대 화질」은 `1080P`를 선택하고, 재생 호환성을 위해 「H.264 우선」을 켜 둡니다.
   - 「간격(초)」과 「재시도 횟수」는 기본값인 `10`과 `1`을 그대로 사용해도 됩니다.

   필요에 따라 출력 디렉터리와 출력 앨범을 선택합니다. 비워 두면 Kabegame 기본 위치를 사용합니다.

   ![애니메이션 다운로드용 플러그인 설정](banners/bangumi-params.jpg)

3. 작업을 시작합니다. 플러그인이 본편 목록을 읽고 처음 3화를 순서대로 다운로드한 뒤, 분리된 영상·음성
   스트림을 MP4로 병합하여 갤러리에 추가합니다. 작업이 끝나면 소스 페이지에서 다운로드된 동영상 3개를 볼 수 있습니다.

   ![다운로드된 애니메이션 3화](banners/downloads.jpg)

4. 동영상을 선택하면 상세 화면을 열어 바로 재생할 수 있습니다. 썸네일만 표시되고 재생되지 않는다면 다운로드할 때
   「H.264 우선」이 켜져 있었는지 확인하세요. HEVC와 AV1 지원 여부는 현재 플랫폼에 따라 다릅니다.

   ![Kabegame에서 다운로드한 애니메이션 재생](banners/view.jpg)

## 모드

### 단일 동영상

「동영상 ID 또는 URL」에 다음 중 하나를 입력합니다.

- `BV13x41117TL`
- `av1074402`
- `https://www.bilibili.com/video/BV13x41117TL`

여러 파트로 구성된 동영상은 「파트 번호」로 원하는 파트를 선택합니다. `0`을 입력하면 모든 파트를 다운로드합니다.

### 업로더 영상

「업로더 UID 또는 홈 URL」에 UID(`3985676`)나 프로필 링크(`https://space.bilibili.com/3985676`)를
입력합니다. 목록은 페이지당 업로드 30개이며 「시작 페이지 / 끝 페이지」로 범위를 지정합니다.

**「최대 개수」 기본값은 5**로 의도적으로 보수적으로 설정되어 있습니다. 한 페이지에 동영상이 30개 있고 1080P
동영상 하나가 수백 MB에 이를 수 있어, 한 페이지만으로도 몇 GB가 될 수 있습니다. 범위를 확인한 뒤 값을 늘리세요.

이 모드는 각 업로드에서 **P1만 다운로드**합니다. 그렇지 않으면 파트가 23개인 업로드 하나에서 파일 23개가 한꺼번에 생성됩니다.

### 컬렉션 / 시리즈 / 즐겨찾기

「목록 페이지 URL」에 전체 링크를 붙여 넣으면 **유형을 자동으로 인식**합니다.

| 유형 | URL 형식 |
| --- | --- |
| 컬렉션 | `space.bilibili.com/<UID>/lists/<ID>`(또는 `?type=season`) |
| 컬렉션(이전 형식) | `space.bilibili.com/<UID>/channel/collectiondetail?sid=<ID>` |
| 시리즈 | `space.bilibili.com/<UID>/lists/<ID>?type=series` |
| 시리즈(이전 형식) | `space.bilibili.com/<UID>/channel/seriesdetail?sid=<ID>` |
| 즐겨찾기 | `space.bilibili.com/<UID>/favlist?fid=<ID>` |
| 즐겨찾기(짧은 링크) | `bilibili.com/medialist/detail/ml<ID>` |

컬렉션과 시리즈에는 **전체 space 링크**가 필요합니다. API가 업로더 UID와 목록 ID를 모두 요구하므로 ID만으로는 요청할 수 없습니다.

즐겨찾기 항목 API는 페이지 구분 없이 모든 항목을 한 번에 반환합니다. 이 모드에서는 「시작 페이지」를 페이지당 30개로
환산해 시작 위치를 정하고, 「최대 개수」로 결과를 제한합니다. 오디오나 게시물처럼 동영상이 아닌 항목은 안내와 함께
건너뜁니다. 비공개 즐겨찾기를 가져오려면 Kabegame 서프에서 **소유자 계정으로** 로그인해야 합니다.

이 모드도 각 업로드에서 P1만 다운로드합니다.

### 키워드 검색

「검색 키워드」를 입력합니다. `search.bilibili.com`의 **동영상** 탭과 같습니다. 정렬
(관련도 / 조회 수 / 최신 / 댓글 수 / 즐겨찾기 수)과 길이 필터를 선택할 수 있으며 검색 결과는 페이지당 20개입니다.

**길이 필터를 함께 사용하는 것을 권장합니다.** 1080P 동영상은 1시간에 1GB를 넘을 수 있고, 검색 결과에는 긴 동영상이
쉽게 포함됩니다. 라이브 방송이나 애니메이션처럼 일반 업로드가 아닌 결과는 자동으로 제외되며, 페이지 사이의 중복 업로드도 제거됩니다.

이 모드도 각 업로드에서 P1만 다운로드합니다.

### 애니메이션 / 에피소드

「애니메이션 URL 또는 ID」에 다음 중 하나를 입력하면 **유형을 자동으로 인식**합니다.

| 유형 | 형식 |
| --- | --- |
| 단일 에피소드 | `ep21495` 또는 `bilibili.com/bangumi/play/ep21495` |
| 전체 시즌 | `ss26801` 또는 `bilibili.com/bangumi/play/ss26801` |
| 작품 페이지 | `md24097891` 또는 `bilibili.com/bangumi/media/md24097891` |

애니메이션에는 일반 업로드와 완전히 별개인 PGC 재생 API를 사용하며 WBI 서명이 필요하지 않습니다.

- **단일 에피소드(`ep`)**: 해당 화만 다운로드합니다. 메이킹 영상, PV, 성우 프로그램 같은 섹션 항목에도
  개별 `ep` 페이지가 있으며 동일하게 지원됩니다.
- **전체 시즌(`ss` / `md`)**: PV나 메이킹 영상을 제외한 **본편 목록**을 일괄 다운로드합니다.
  「시작 화수」로 시작 위치를 지정하고 「최대 개수」로 수를 제한합니다. 작품 페이지(`md`)는 먼저 대응하는 시즌으로 변환됩니다.

다음 콘텐츠는 사용할 수 없는 파일을 저장하지 않고 명확하게 건너뛰거나 오류로 처리합니다.

- **대회원 전용 에피소드**: 시청 권한이 없으면 API가 6분 미리보기만 반환합니다. 미리보기는 라이브러리에 추가하지 않고
  해당 화를 안내와 함께 건너뜁니다. 대회원이라면 먼저 Kabegame 서프에서 bilibili에 로그인하세요.
- **지역 제한**: 홍콩·마카오·대만 또는 해외 한정 콘텐츠를 지원되지 않는 지역에서 요청하면 오류를 표시합니다.
- 무료 에피소드와 잠금 해제된 에피소드는 정상적으로 다운로드하며, 화질 선택 규칙은 일반 동영상과 같습니다.

## 화질과 로그인

bilibili에서 사용할 수 있는 화질은 로그인 상태에 따라 달라집니다.

| 상태 | 사용 가능한 화질 |
| --- | --- |
| 로그아웃 | 미리보기 경로로도 일반적으로 1080P 이용 가능 |
| 로그인 | 안정적으로 1080P 이용 가능 |
| 대회원 | 4K / HDR / Dolby |

쿠키는 **Kabegame 서프**에서 가져옵니다. 4K나 HDR이 필요하다면 먼저 서프에서 bilibili에 로그인한 뒤 이 플러그인을
실행하세요. 「최대 화질」은 설정한 등급을 넘지 않는 범위에서 사용할 수 있는 가장 높은 화질을 선택하므로 실제 결과는 더 낮을 수 있습니다.

「H.264 우선」은 기본으로 켜져 있습니다. `avc1` 코덱을 우선해 갤러리에서 바로 재생할 수 있도록 합니다. 끄면 화질을
우선하므로 HEVC나 AV1을 받을 수 있습니다. 플랫폼에 따라 이런 파일은 라이브러리에 저장된 뒤 썸네일만 표시되고 바로 재생되지 않을 수 있습니다.

## 간격과 재시도

「간격(초)」(기본값 10)은 동영상 사이, 목록 페이지 사이, 실패 후 재시도 전에 적용됩니다.
「재시도 횟수」(기본값 1)는 동영상 하나가 실패했을 때의 재시도 상한이며 `0`이면 재시도하지 않습니다.

업로더 목록 API의 남용 방지 정책은 재생 API보다 훨씬 엄격해서 간격을 줄이면 쉽게 차단될 수 있습니다.
`412` / `-401` / `-352`가 반환되면 이런 차단은 재시도해도 의미가 없으므로 플러그인이 작업을 즉시 종료합니다.
나중에 다시 시도하거나 먼저 Kabegame 서프에서 bilibili에 로그인하세요. 컬렉션·시리즈·즐겨찾기 API는 서명이 필요하지 않아 제한이 더 느슨합니다.

## 제한 사항

- **강의와 라이브 방송은 지원하지 않습니다**(`/cheese/`, `live.bilibili.com`). 이 콘텐츠는 다른 재생 API를 사용합니다.
  이 플러그인은 일반 업로드와 애니메이션을 처리합니다.
- **숨김 모드 컬렉션은 건너뜁니다.** 업로더 목록에서 내부 동영상을 펼칠 수 없고 필요한 컬렉션 API는 아직 지원하지
  않습니다. 플러그인이 경고를 기록하고 건너뜁니다.
- 영상과 음성을 원본 코덱 그대로 stream copy로 병합하고 다시 인코딩하지 않으므로 소요 시간은 대부분 네트워크 전송 시간입니다.
