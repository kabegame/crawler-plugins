# Safebooru 更新日志

## 1.0.2

- 任务日志与参数校验错误会跟随 Kabegame 的界面语言显示，支持简体中文、English、日本語、한국어与繁體中文。

## 1.0.1

- 「爬取模式」「质量」，以及标签模式的「标签组合」、id 范围模式的「起始 id / 结束 id」改为必填，留空时在启动前就会提示，不再运行后才报错。

## 1.0.0

首个版本。

- 三种爬取模式：标签、全部、id 范围
- 走站点官方 dapi：一页一次请求拿到帖子与带分类的全量标签（`fields=tag_info`），页码与网页列表一致（每页 42 张）
- 「最新发布」排序可以翻过站点第 4762 页的翻页上限（用 `id:<` 游标接续或跳转定位）；其他排序越界时报错并提示可用的排序
- 排序可选最新 / 高分 / 最近更新 / 随机（站点的 `sort:` 元标签），标签组合支持 `width:>=1920` 等元标签
- id 范围模式按 `id:>=A id:<=B` 闭区间、id 升序抓完整个区间，两个 id 最多相差 5000
- 质量分高（原图）/ 中（站点 sample）
- 元数据含全量标签、发布时间、上传者、来源、评分；有评论的帖子附带评论
- 标签按分类写入应用的「标签」分区：`safebooru/<分类>/<标签>`
- 详情模板 `description.ejs` 还原站点详情页侧栏与评论区
